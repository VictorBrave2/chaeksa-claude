# 세 고전 관점 채점

독자가 깊이를 원할 때 쓴다. 기본 채점(오행·유통·통근·충·조후)만으로 충분한 글이 많으니
**매번 쓰지는 않는다.** 쓰기로 했으면 한계도 같이 밝혀야 한다.

---

## 세 관점은 서로 다른 것을 본다

- **자평진전(子平眞詮)** — 격의 짜임. 월령에서 격을 잡고 성격(成格)인지 파격(破格)인지
- **적천수(滴天髓)** — 기운의 균형과 흐름. 중화와 유통
- **궁통보감(窮通寶鑑)** — 계절의 한난조습. 조후

실측 결과 **셋의 상관계수가 거의 0**이다. 2026년 9월 360개 후보로 재보니:

```
자평진전 ↔ 적천수     -0.18   ← 음의 상관
자평진전 ↔ 궁통보감    0.14
적천수  ↔ 궁통보감    0.23

360개 중 세 관점이 비슷하게 평가한 경우  24건 (6.7%)
평균 편차                                36점
```

**그래서 셋을 평균 내면 안 된다.** 값어치는 어디서 갈리는지에 있다.
평균을 내는 순간 그 정보가 사라지고 아무것도 아닌 숫자가 남는다.

순위를 낼 때는 **최저 점수 기준**으로 정렬한다. 한 관점만 높고 나머지가 낮으면
"세 고전이 모두 인정한 자리"가 아니기 때문이다.

---

## 구현

### 자평진전

월지 지장간 중 천간에 투출한 것으로 격을 잡는다(정기 > 중기 > 여기).
투출이 없으면 정기로.

**월령 정기가 비겁이면 격을 세우지 않는다.** 건록격(비견) 또는 양인격(겁재)으로 부르고,
재·관·식상 중 무엇을 쓰는지로 본다. 천간에 관성이 투출하면 가장 좋다.

성격/파격 판정:

| 격 | 성격 | 파격 |
|---|---|---|
| 정관 | 재 또는 인이 관을 도움 (둘 다면 상격) | 상관견관 / 관살혼잡 |
| 재성 | 식상생재 또는 재생관 | 비겁 3개 이상 (겁탈) |
| 정인 | 관인상생 | 재가 천간에 투출해 인을 극함 |
| 식신 | 식신생재 또는 식신제살 | 편인이 있음 (효신탈식) |
| 편관 | 식신제살 또는 살인상생 | 제화 없이 재가 살을 생함 |
| 상관 | 상관생재 또는 상관패인 | 정관이 있음 (상관견관) |
| 편인 | 재로 편인을 제함 | 식신이 있음 |

성격이면 92점, 격이 천간에 투출했으면 +8. 파격이면 52점, 투출이면 −4.

### 적천수

```
중화도 = 1 - min(1, |강약값 - 0.5| × 2.6)
유통   = 목→화→토→금→수→목 사슬에서 끊기지 않는 최대 칸수 (0~5)
충     = 지지 간 충 개수

점수 = 중화도×48 + (유통/5)×38 + (충 없으면 14, 있으면 14 - 충×7)
```

### 궁통보감 — 여기가 반쪽이다

원전에는 일간별·월별 용신을 지정한 표가 있는데 **판본마다 다르다.**
기억으로 채우면 근거가 아니라 추측이 된다. 그래서 **원리 수준으로만** 구현했다.

계절과 일간으로 필요한 오행을 정한다. 가을(申酉월) 예:

| 일간 | 필요 | 왜 |
|---|---|---|
| 金 | 火·水 | 가을 金은 왕하다. 火로 단련하고 水로 씻는다 |
| 木 | 火·水 | 金이 왕해 木을 극한다. 火로 金을 제하고 水로 화한다 |
| 水 | 土·火 | 金生水로 넘친다. 土로 막고 火로 따뜻하게 |
| 火 | 木 | 가을 火는 쇠한다. 木으로 살려야 한다 |
| 土 | 火·水 | 土가 金에 설기된다. 火로 생하고 水로 윤택하게 |

겨울(亥子丑)이면 火, 여름(巳午未)이면 水가 축이 된다.

**세력까지 본다.** 필요 오행이 천간에 투출하면 1점, 지지에만 있으면 0.5점.
존재만 보면 대부분 만점이 나와 변별력이 사라진다.

```
점수 = 30 + (충족/필요)×58
       - (계절 반대 오행이 0이면 10)
       - (한 오행이 4개 이상 쏠리면 10)
```

**이 한계는 글에 반드시 밝힌다.** 밝히지 않으면 나머지 주장도 같이 의심받는다.

## 글로 쓸 때

세 관점이 갈리는 사례를 **양방향으로** 넣는다. 한쪽만 넣으면
"어느 한 고전이 까다롭다"로 읽힌다.

실제로 나온 사례:

```
2026/9/7 甲申일    자평 100 (편관격 식신제살 — 교과서적 성격)
                   적천  29 (유통 2/5, 신약 — 격을 감당할 몸이 없다)

2026/9/12 己丑일   적천  98 (유통 5/5 중화 — 이 달 1위)
                   자평  52 (식신격에 편인 — 효신탈식 파격)
```

착지점은 정직하게.
