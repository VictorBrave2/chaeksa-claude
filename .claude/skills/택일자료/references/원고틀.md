# 월별 글 틀

**월별 글은 `tools_wolbyeol.py` 가 쓴다**(궁통보감 편은 `tools_gungtong.py`). 옛 방식 — `naver-NN-주제.txt` 원고에 ■ ▸ 표시를 달고
에디터에서 서식을 다시 잡던 것, 「정리하면」 순위 절, 통근 · 신강 반전 사례 — 은 그만뒀다.
여기 적은 것은 생성기가 내는 순서와, 손으로 고칠 때 지킬 것이다.

---

## 종합 글이 나오는 순서 (`tools_wolbyeol.py`)

```
제목(h2)       왜 {해}년 {월}월 출산택일은 이 시각인가요 — 모든 날 모든 시각
제목 대안(alt)  복사할 때 빠진다
답 첫 줄        「답부터 드리면, 이달은 ○일 ○○:○○ …입니다.」 + 왜(궁통보감이 찾는 글자가 천간에 다 있는 시각)
명식 카드       으뜸 낮 시각 → 으뜸 → 걸리지 않는 낮 시각 순으로 많아야 석 장
전부 계산       「점수와 순위는 매기지 않았습니다」 + 09-18 고침 상자
먼저 — 출산 날짜는 의사가 정합니다    ← 옛 글에서 가져옴
보는 법         세 고전에게 하나씩 · 두 고전으로 거르고 적천수는 참고 · 으뜸 · 시계 시각 · 남아 여아 같음
이달은 이만큼 남습니다   전체 · 궁통 걸림 · 자평 걸림 · 둘 다 걸리지 않음 · 그 가운데 낮
이달의 으뜸 자리 · 왜 이 시각인가요
왜 이달은 이 글자를 찾나요     절기로 달이 바뀌면 두 벌
두 고전에 걸리지 않는 낮 자리   날짜순 · 적천수 흐름 한 줄씩(마흔 곳이 넘으면 날마다 한 줄)
{월}월 1~10일 · 11~20일 · 21일~말일   하루 열두 시진 전부. 걸리지 않는 곳은 굵게
이달의 절기                   ← 옛 글에서 가져옴
이달에서 눈여겨볼 것 · 시계 시각을 꼭 확인하세요
다섯 겹 중 첫 겹              대운 · 수술 시간 · 가족 · 최종은 보고서(99,000원)
부모 사주 하나로 못 쓰는 날이 이만큼 갈립니다   ← 옛 글에서 가져옴
기준을 밝힙니다 · 직접 확인해보실 수 있습니다(시뮬레이터 링크) · 신청서
해시태그                     ← 옛 글에서 가져옴
```

「옛 글에서 가져옴」 넷은 생성기가 그 달 기존 파일에서 그대로 옮긴다. 새 달이면 손으로 그달 것으로 고친다(SKILL.md 「글을 짠다」).

## 손으로 고칠 때

- **의료 면책은 언제나 맨 앞 쪽**이다. 이사 · 계약 택일이면 「계약 · 법률 판단이 먼저」로 바꾼다
- **한 문단 한 호흡.** 45자가 넘으면 폰에서 서너 줄로 접힌다. 마침표마다 `<p>` 를 나눈다
- **표 금지.** 비교는 `<blockquote>` 안 `▸` 줄로
- 여러 달에 두루 고칠 말은 **생성기에서** 고친다. 파일을 손으로 고치면 다음에 돌릴 때 사라진다
- 값 · 신청서 링크 · 보고서 안내는 건드리지 않는다(토스 결제 심사 중)
- 다 고치고 `python tools_form.py` — 새 막힘이 없는지

```
산모의 상태, 아기의 크기와 자세, 태반 위치, 병원 수술 일정.
이런 의학적 판단이 언제나 먼저입니다. 명리 택일은 그 다음입니다.
의학적 판단을 뒤집는 용도로 쓰시면 안 됩니다.
```

## 해시태그

10~11개. 셋으로 나눠 고른다. 옛 글의 `<p class="tag">` 를 생성기가 그대로 옮기므로 새 달이면 달 이름만 바꾼다.

- **검색어** — `#출산택일 #제왕절개택일 #2026년10월출산`
- **주제어** — `#아기사주 #궁통보감 #진태양시`
- **넓은 말** — `#사주 #만세력 #명리학`

날짜가 들어간 태그(`#2026년10월출산`)가 검색 유입에 제일 잘 걸린다.
