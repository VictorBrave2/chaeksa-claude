# 블로그 원고 틀

지금까지 쓴 글들에서 실제로 통한 구조다. 순서를 바꿔도 되지만
**의료 면책은 언제나 맨 앞**이고 **정직성 문단은 링크 직전**에 둔다.

원고는 `marketing/naver-NN-주제.txt` 로 저장한다. NN 은 발행 순번.

---

## 절 구성

```
[제목]
[제목 대안]            ← 두 개 주고 고르게 한다

─────
도입 3~5줄            ← 독자가 처한 상황을 그대로 되뇌어준다

■ 먼저 반드시 밝힐 것   ← 의료 면책. 절대 생략 금지
■ (예시 설정)          ← 가상 사례일 때만. "실제 상담 내용이 아닙니다"
■ 무엇을 보는가 1~5    ← 기준 하나에 절 하나
■ 정리하면             ← 순위. 인용구로
■ 시각 창              ← 진태양시. 이 자료의 핵심
■ 정직하게 덧붙일 것    ← 한계 3가지
■ 직접 확인해보시려면   ← chaeksa.kr 링크
마무리 + 댓글 유도
#해시태그 10~11개

═══
[네이버 에디터 적용 안내]   ← 붙여넣은 뒤 지우라고 명시
```

## 문장

### 도입

독자가 이미 겪고 있는 상황을 먼저 말한다. 설명부터 시작하지 않는다.

> 제왕절개를 앞두면 병원에서 이렇게 말합니다.
> "이 주에서 이 주 사이, 이 요일들이 가능합니다."
> 보통 서너 개 후보를 받게 됩니다.

### 기준 절

각 절은 **왜 이걸 보는지**부터 말하고 숫자를 낸다. 숫자만 던지면 안 읽힌다.

> 흔히 신강하면 튼튼하다고 생각합니다.
> 그런데 신강·신약보다 먼저 볼 것이 있습니다.
> 일간이 지지에 뿌리를 내리고 있는가. 이것을 통근이라고 합니다.

### 반전 지점

계산에서 나온 반전을 반드시 문장으로 만든다. 이게 글의 값어치다.

> 15일은 강약으로 보면 신강 0.62로 넷 중 가장 셉니다.
> 그런데 뿌리는 2곳뿐이고 유통은 2/5입니다.
> 물이 많아서 세 보일 뿐, 받쳐주는 땅이 없습니다.
> **숫자가 커 보인다고 튼튼한 것이 아닙니다.**

### 마무리

댓글을 부르는 문장으로 닫는다. 첫 글에서 이 형태로 실제 상담이 들어왔다.

> 후보를 받으셨는데 판단이 어려우시면 댓글로 남겨주세요.
> 날짜와 시간, 태어날 지역만 알려주시면 계산해서 알려드리겠습니다.

## 의료 면책 (그대로 쓴다)

```
■ 먼저 반드시 밝힐 것

출산 날짜는 의사가 정합니다.

산모의 상태, 아기의 크기와 자세, 태반 위치, 병원 수술 일정.

이런 의학적 판단이 언제나 먼저입니다.

명리 택일은 그 다음입니다.

의사가 "이 주 중에 하시죠"라고 했을 때,
그 범위 안에서 어느 날 어느 시간이 나은지 고르는 참고자료입니다.

의학적 판단을 뒤집는 용도로 쓰시면 안 됩니다.
```

이사·계약 택일이면 의료 면책 대신 **"계약·법률 판단이 먼저"** 로 바꾼다.

## 정직성 문단 (매번 상황에 맞게 다시 쓴다)

늘 들어가는 세 가지.

1. **채점 비중은 내가 정했다** — 유통을 몇 점으로 볼지는 고전에 없다
2. **대운은 성별로 갈린다** — 원국이 같아도 흐름은 다르다
3. **유파에 따라 기준이 다르다** — 격국 우선, 조후 우선이 따로 있다

세 고전을 썼으면 하나 더.

4. **궁통보감은 원리 수준 구현이다** — 원전의 120칸 조후용신표가 아니다.
   판본마다 다르고, 기억으로 채우면 근거가 아니라 추측이 된다.

닫는 문장은 늘 같은 취지로.

> 그래서 이 자료는 정답이 아니라 '이 기준으로는 이렇게 나왔다'입니다.
> 기준을 공개하는 이유가 그것입니다.

## 에디터 적용 안내 블록

원고 맨 아래에 붙인다. 사용자가 붙여넣은 뒤 지운다.

```
═══════════════════════════════════
[네이버 에디터 적용 안내 — 붙여넣기 후 이 부분은 지우세요]

1. ───── 자리에 '구분선' (가장 얇은 실선)
2. ■ 줄 → 소제목 (본문 ∨ → 소제목, 또는 19px + B). ■ 기호는 지우세요
3. ▸ 목록 묶음 → 인용구(66) 두 번째 스타일. 표 기능 쓰지 마세요 (모바일에서 깨짐)
4. 굵게 처리할 문장
   · (계산에서 나온 반전 문장)
   · (독자가 기억해야 할 한 줄)
5. '먼저 반드시 밝힐 것' 문단은 절대 빼지 마세요
6. 문단을 합치지 마세요. 지금 끊긴 그대로
7. 대표 이미지는 따로 만든 것을 쓰세요
```

굵게 처리할 문장은 **3~5개만** 고른다. 많으면 아무것도 안 굵어진 것과 같다.

## 해시태그

10~11개. 셋으로 나눠 고른다.

- **검색어** — `#출산택일 #제왕절개택일 #2026년10월출산`
- **주제어** — `#아기사주 #통근 #진태양시`
- **넓은 말** — `#사주 #만세력 #명리학`

날짜가 들어간 태그(`#2026년10월출산`)가 검색 유입에 제일 잘 걸린다.
