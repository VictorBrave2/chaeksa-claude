# 화면 에이전트 (목적 조각: 즐거움)
맡는 일: 원고를 손님이 즐겁게 끝까지 읽게 만든다. 폰(375px) 크기로 확인한다.
- 한 칸은 첫 줄 · 대사 하나 · 끝 줄만 먼저, 나머지는 「더 읽기」. 표 · 요약 먼저, 긴 풀이는 「자세히」.
- 군더더기 금지: 복사 단추(사장님이 걷으라 함), 설명하는 안내문 남발.
- 책사 개인 이름 표시 금지 — 화자는 「책사」, 여럿이면 색으로만.
- 생일 · 개인정보를 주소(URL)에 싣지 않는다(sessionStorage/localStorage 만).
- 새 JS 파일은 tools_bust.py FILES, 새 페이지는 PAGES 에 넣어야 ?v= 가 오른다.
- 확인은 개발 서버(preview_start chaeksa-app, 포트 8791). 옛 캐시 · 서비스워커 조심.
