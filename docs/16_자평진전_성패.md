# 자평진전 격국 성패 — 상담 지침

**출처** 『子平眞詮評註』 卷三 「九. 論用神成敗救應」
청 심효첨 원저 · 민국 서락오 평주 · https://www.ncc.com.tw/fate/paleo/bg/bg_033.htm

**2026-08-28 원문 대조 완료.** 앞판은 기억으로 쓴 것이라 틀린 데가 여럿이었다.
아래는 원문을 보고 고친 것이다. 원문은 맨 뒤 부록에 그대로 실었다.

우리 엔진은 지금 **섰다 / 깨졌다 두 칸**이다. 원문은 넷이다.

```
섰다        격이 온전히 섰다
깨졌다      격이 깨졌다
띠었다      섰는데 안에 기신을 띠었다      성중유패
구제됐다    깨졌는데 구해주는 것이 있다     패중유성
```

**「섰는데 기신을 띠었으면 반드시 그 기신 탓이고,
깨졌는데 살아났으면 오로지 구제 덕이다」**

우리 엔진에는 뒤의 두 칸이 없다. 「상관견관이면 깨졌다」에서 끝나고
인수가 구제하는 경우를 안 본다.

---

## 원문 대조로 잡은 내 오류

| | 내가 쓴 것 | 원문 |
|---|---|---|
| **상관격 깨졌다** | 패인인데 **인이 가볍고 일간이 약하다** | **상관이 가볍고 일간이 왕하다**(傷輕身旺) — **정반대였다** |
| **칠살격 섰다** | 「살이 무거우면 식신을 돕고 식신이 무거우면 살을 돕는다」 | 원문은 **身強七煞逢制** 한 줄뿐. 그 문장이 없다 |
| **재격 섰다** | 재격이 인을 **차되**(佩印) | 인이 **투출하되**(透印) 자리가 맞고 **서로 극하지 않는다**(兩不相剋) |
| **상관격 띠었다** | 상관생재인데 **칠살이 투출** | **재가 합거된다**(財又逢合) |
| **양인격 섰다** | `(?)` 상관을 안 본다 / 양인을 안 충한다 | **不見傷官** — 상관을 안 본다가 맞다 |
| 띠었다 | 셋을 빠뜨림 | 透煞以生印而又透財 · 佩印而印又遭傷 · 透財而逢煞 |
| 구제 | 하나를 빠뜨림 | 逢煞而食神制煞以生財，或存財而合煞 |

**칠살격 「가벼운 쪽을 돕는다」는 이 판본에 없다.** 서락오 평주에
「신살이 양쪽으로 팽팽해야 성격을 허락한다」(必身煞兩停者，方許成格)는 있다.
다른 판본이거나 다른 책일 수 있으니 확인이 필요하다.

## 1. 정관격

**상신** 재 또는 인

| | |
|---|---|
| **섰다** | 관이 재와 인을 만나고, 형충파해가 없다 |
| **깨졌다** | 관이 상관에게 극당한다 · 형충을 만난다 |
| **띠었다** | 관이 재를 만났는데 상관도 같이 있다 |
| | 관이 투출했는데 합거된다 |
| **구제** | 상관을 만났는데 **인수가 투출해 풀어준다** |
| | 관살혼잡인데 **살이 합거되어 맑아진다** |
| | 형충이 있는데 **회합이 그것을 풀어준다** |

**평주가 더 말하는 것**
- 일간이 왕하고 관이 가벼우면 **재로 관을 생하고**, 일간이 약하고 관이 무거우면 **인으로 관을 돌린다**
- 재와 인을 겸해 쓸 때는 **둘이 서로 걸리지 않아야** 한다
- 형충파해 중 **충이 가장 무겁다.** 충은 곧 극이다. 형·파·해는 헤아려 보되 **반드시 파격은 아니다**

> 지금 코드 `!상관 && !편관 && (재성 || 인성)`
> 구제를 안 보므로 **인수 있는 상관견관을 깨진 것으로 죽인다.**
>
> 형충은 우리가 안 쓰기로 했다(B1). 평주도 「형·파·해가 반드시 파격은 아니다」라 하니
> 충만 보는 우리 방침과 크게 어긋나지 않는다.

## 2. 재격

**상신** 식상(생재) · 관(재생관) · 인(신강할 때)

| | |
|---|---|
| **섰다** | 재가 관을 생해 관이 왕하다 |
| | 재가 식신의 생을 만나는데 일간이 강하고 비겁을 띠었다 |
| | 재격에 **인이 투출하되 자리가 맞아 둘이 서로 극하지 않는다** |
| **깨졌다** | 재는 가벼운데 비겁이 무겁다 |
| | 재가 칠살을 투출시킨다 — 재생살 |
| **띠었다** | 재가 관을 생하는데 **상관을 만나거나 합거된다** |
| **구제** | 겁재를 만났는데 **식신이 투출해 흘려보낸다** |
| | **관을 생해 그 관이 겁재를 제한다** |
| | 칠살을 만났는데 **식신이 살을 제하고 재를 생한다** |
| | 또는 **재를 남기고 살을 합거한다** |

**평주가 자리를 못박는다**

> 연간에 인이 투출하고 시간에 재가 투출하면, 가운데 비겁이 끼어 서로 걸리지 않는다.
> 관성이 끼면 재왕생관이 되어 역시 걸리지 않는다.

**즉 재와 인은 떨어져 있으면 되고 붙으면 안 된다.**
사장님이 「투간한 재 옆에 인이 붙으면 깨진다」고 하신 것이 이 대목이다.
원문의 **兩不相剋**(둘이 서로 극하지 않는다)이 그 조건이다.

> 지금 코드 `비겁<3 && (식상 || 관성)`
> 「비겁 3개」는 원문의 **재는 가볍고 비겁은 무겁다**(무게 비교)를 개수로 바꾼 근사다.
> **자리 조건이 통째로 없다.** 표본 1200 중 재격 229건에서 18건이 재·인 인접인데
> 지금 엔진은 그 18건을 전부 성격으로 준다.

## 3. 인격

**상신** 관(관인상생) · 식상(일간과 인이 둘 다 왕할 때 설기)

| | |
|---|---|
| **섰다** | 인이 가벼운데 살을 만난다 — 살인상생 |
| | 관과 인이 둘 다 온전하다 |
| | 일간과 인이 둘 다 왕해 **식상으로 빼낸다** |
| | 인이 많은데 재를 만나되 **그 재의 뿌리가 얕다** |
| **깨졌다** | 인이 가벼운데 재를 만난다 — 재극인 |
| | 일간이 강하고 인이 무거운데 살까지 투출한다 |
| **띠었다** | 인이 식신을 투출시켜 빼내는데 **재까지 드러난다** |
| | 살을 투출시켜 인을 생하는데 **재까지 투출해 인을 없애고 살만 남긴다** |
| **구제** | 재를 만났는데 **겁재가 그 재를 제한다** |
| | 또는 **재를 합거해 인을 남긴다** |

**평주가 더 말하는 것**
- 일간이 강하고 인이 왕하면 인을 더 못 쓴다. **식상으로 빼내는 것이 가장 좋다**
- 인이 너무 많으면 **인을 덜어내는 것**이 용이다 — 토가 많으면 금이 묻히고 물이 많으면 나무가 뜬다
- 원국의 재가 뿌리가 없으면 재로 인을 못 깬다. 반대로 **재가 너무 왕해 인이 상하면 비겁으로 재를 없애고 인을 돕는다**

> 지금 코드 `!정재투출 && !편재투출 && 관성`
> **인격에서 겁재가 구제라는 것을 전혀 안 본다.**

## 4. 식신격

**상신** 재(식신생재) · 칠살(식신제살)

| | |
|---|---|
| **섰다** | 식신이 재를 생한다 |
| | 식신이 살을 띠었는데 **재가 없다** |
| | 식신을 버리고 살을 취하되 **인이 투출한다** |
| **깨졌다** | 식신이 편인을 만난다 — 효신탈식 |
| | 재를 생하는데 **살까지 드러난다** |
| **띠었다** | 식신이 살과 인을 띠었는데 **재까지 만난다** |
| **구제** | 편인을 만났는데 **칠살을 취해 도리어 격을 이룬다** |
| | 또는 **재를 생해 식신을 보호한다** |

**평주가 더 말하는 것**
- 칠살이 투출하면 식신으로 살을 제하는 것이 용이다. **재가 살을 편들까 꺼리므로 재가 없어야 아름답다**
- 살이 왕한데 인이 투출하면 식신을 버리고 살을 취해 **인으로 살을 돌린다**. 이때는 **더 이상 식신격으로 안 본다**
- 효신이 식신을 뺏는 판이면 **기식취살이 진짜가 된다**

> 지금 코드 `!편인 && (재성 || 편관)`
> **효신탈식을 무조건 깨진 것으로 죽인다.**

## 5. 칠살격 (편관)

**상신** 식신(제살) · 인(살인상생)

| | |
|---|---|
| **섰다** | **일간이 강하고 칠살이 제함을 만난다** — 원문은 이 한 줄뿐이다 |
| **깨졌다** | 칠살이 재를 만났는데 제함이 없다 — 재생살 |
| **띠었다** | 칠살이 식신의 제를 만났는데 **인이 또 온다** (인이 식신을 제해버린다) |
| **구제** | 인이 와서 살을 보호하는데, **재를 만나 인을 없애고 식신을 남긴다** |

**평주가 채우는 것**

> 일간이 강하고 살이 약하거나, 살이 강하고 일간이 약하면 **둘 다 제복을 용으로 못 쓴다.
> 반드시 신살이 양쪽으로 팽팽해야 성격을 허락한다**(必身煞兩停者，方許成格).

> **확인 필요** — 「살이 무거우면 식신을 돕고 식신이 무거우면 살을 돕는다」는
> 이 판본 원문에 없다. 평주의 「身煞兩停」이 취지는 같으나 문장이 다르다.
> 다른 판본이거나 다른 책일 수 있다.
>
> 지금 코드 `식신 || 인성` — **성격 조건만 있고 깨지는 조항이 통째로 없다.**

## 6. 상관격

**상신** 재(상관생재) · 인(상관패인)

| | |
|---|---|
| **섰다** | 상관이 재를 생한다 |
| | 상관패인인데 **상관이 왕하고 인에 뿌리가 있다** |
| | 상관이 왕하고 일간이 약한데 **살과 인이 투출한다** |
| | 상관이 살을 띠었는데 **재가 없다** |
| **깨졌다** | **금수상관이 아닌데 관을 본다** — 상관견관 |
| | 재를 생하는데 **살까지 띤다** |
| | 패인인데 **상관이 가볍고 일간이 왕하다** |
| **띠었다** | 상관이 재를 생하는데 **그 재가 합거된다** |
| | 인을 찼는데 **그 인이 상한다** |
| **구제** | 칠살이 투출했는데 **그 살이 합거된다** |

**금수상관은 관을 반긴다.** 겨울 금 일간이 그렇다.
평주 — 금이 차고 물이 얼어 **조후가 급하므로** 관을 봐도 된다. 그 밖에는 다 꺼린다.

**평주가 못박는 것**

> 일간이 왕해 상관을 쓸 때는 본래 인을 찰 필요가 없다.
> **상관이 가벼운데 인을 보면 상관이 인에게 제압당해 그 빼어남을 펴지 못하므로 격이 깨진다.**

> **내가 정반대로 썼던 자리다.** 「인이 가볍고 일간이 약하다」가 아니라
> **「상관이 가볍고 일간이 왕하다」**이다.
>
> 지금 코드 `!정관 && (재성 || 인성)`

## 7. 양인격

**상신** 관 또는 살

| | |
|---|---|
| **섰다** | 관살이 투출하고 재·인이 드러나며 **상관을 보지 않는다** |
| **깨졌다** | 관살이 없다 |
| **띠었다** | 관이 투출했는데 상관을 본다 · 살이 투출했는데 그 살이 합거된다 |
| **구제** | 관살을 쓰는데 상관·식신이 있으면 **인을 거듭 두어 보호한다** |

**평주가 더 말하는 것**
- 양인은 관살로 제하는 것이 가장 아름답다. **양인이 왕하고 살이 강하면 위엄과 권세가 드러난다**
- 인은 양인을 불리고 재는 살을 생하므로 **재와 인이 함께 보이면 길하다. 단 서로 걸리지 않아야 한다**
- 양인이 왕하면 식상으로 빼낼 수도 있으나, **관살로 제할 때는 식상을 겸해 못 쓴다.**
  그래서 **상관을 안 보는 것**이 성격의 조건이다

> `(?)` 가 해소됐다 — **不見傷官**(상관을 안 본다)이 맞고 「양인을 안 충한다」가 아니다.
>
> 지금 코드 `관·재·식상 중 하나라도 투출하면 성격`
> **원문은 관살이라야 한다.** 재나 식상만으로 성격을 주는 것은 근거가 없다.

## 8. 건록·월겁격

**상신** 관(재인이 따름) · 재(식상을 만남) · 살(제복이 있음)

| | |
|---|---|
| **섰다** | 관이 투출하고 재·인을 만난다 |
| | 재가 투출하고 식상을 만난다 |
| | 살이 투출했는데 **제복을 만난다** |
| **깨졌다** | 재관이 없는데 살과 인이 투출한다 |
| **띠었다** | 관을 쓰는데 상관을 만난다 · 재를 쓰는데 살이 투출한다 |
| **구제** | 관을 쓰는데 상관을 만났으나 **그 상관이 합거된다** |
| | 재를 쓰는데 살을 띠었으나 **그 살이 합거된다** |

**평주가 못박는 것**

> 건록·월겁은 **그 자체를 용으로 쓸 수 없고** 따로 부억(扶抑)의 신을 취해 용으로 삼는다.
> 곧 취한 것의 격과 같아진다.

관이 투출하면 관격과 같고, 재가 투출하면 재격과 같고, 살이 투출하면 살격과 같다.

> 지금 코드 `관·살·재·식상 중 하나라도 투출하면 성격` — 너무 헐겁다.

---

## 편인격은 자평진전에 따로 없다

원문 여덟 격에 편인격이 없다 — 정관·재·인수·식신·칠살·상관·양인·건록월겁이다.
편인은 **효신**으로 등장해 식신격을 깨는 요인으로만 나온다.

우리 코드에는 편인격이 있고 `!식신 && 재성`으로 판정한다.
**원문에 없는 격을 우리가 만들어 쓰고 있다.**

## 원문이 스스로 그은 선

> 팔자 중의 성패구응은 천변만화하여 말로 다할 수 없다.
> 위에 늘어놓은 변화는 월령 용신에 대해 보통의 방식을 든 것일 뿐이다.
> 맹자가 이르기를 **「큰 목수는 남에게 규구(자와 곱자)를 줄 수는 있어도
> 솜씨를 줄 수는 없다」** 하였으니, 배우는 이가 익숙해진 뒤라야 스스로 묘오가 생긴다.

> 같은 여덟 글자라도 **자리와 차례가 조금만 달라지면 곧 변화가 생겨**
> 성격이 되기도 하고 패격이 되기도 하며, 구응이 되기도 하고 안 되기도 하니
> 같이 논할 수 없고, 예를 들어 다 밝힐 수도 없다.

**저자와 주석가 본인들이 이것을 완결된 판정 절차로 내놓지 않았다.**
「규구는 줄 수 있어도 솜씨는 못 준다」가 그 말이다.

자평진전을 유료 상담으로 넘긴 결정이 이 문장과 어긋나지 않는다.
규칙으로 다 박을 수 있는 물건이었으면 원문이 그렇게 쓰였을 것이다.

## 합거는 이미 우리에게 있다

「합거되어 맑아진다 / 합거되어 못 쓴다」가 **아홉 번** 나온다.

```
정관격  띠었다  관이 투출했는데 합거된다
정관격  구제    관살혼잡인데 살이 합거되어 맑아진다
재격    띠었다  관이 합거된다
재격    구제    재를 남기고 살을 합거한다
인격    구제    재를 합거해 인을 남긴다
상관격  띠었다  재가 합거된다
상관격  구제    살이 합거된다
양인격  띠었다  살이 합거된다
건록격  구제    상관이 합거된다 · 살이 합거된다
```

평주가 실제 예까지 든다 — 갑목이 유월에 나 정화가 투출해 격이 깨졌는데
임수가 또 투출하면 **정임합**으로 정화가 유금 관성을 못 상한다.

**오늘 넣은 합거가 바로 이 판정에 쓰인다.** 없으면 성패를 못 가린다.
격은 원국 기준이라 운의 합거는 안 쓰고, 운으로 맑아지는 것은
체용 층에서 「올해는 격이 맑아진다」로 따로 말한다.

# 부록 — 원문

『子平眞詮評註』 卷三 「九. 論用神成敗救應」 (심효첨 원문만, 서락오 평주는 뺌)

**총론**
> 用神專尋月令，以四柱配之，必有成敗。

**何謂成**
> 官逢財印，又無刑衝破害，官格成也。
> 財生官旺，或財逢食生而身強帶比，或財格透印而位置妥貼，兩不相剋，財格成也。
> 印輕逢煞，或官印雙全，或身印兩旺而用食傷洩氣，或印多逢財而財透根輕，印格成也。
> 食神生財，或食帶煞而無財，棄食就煞而透印，食格成也。
> 身強七煞逢制，煞格成也。
> 傷官生財，或傷官佩印而傷官旺，印有根，或傷官旺、身主弱而透煞印，或傷官帶煞而無財，傷官格成也。
> 陽刃透官煞而露財印，不見傷官，陽刃格成也。
> 建祿月劫，透官而逢財印，透財而逢食傷，透煞而遇制伏，建祿月劫之格成也。

**何謂敗**
> 官逢傷剋刑沖，官格敗也；
> 財輕比重，財透七煞，財格敗也；
> 印輕逢財，或身強印重而透煞，印格敗也；
> 食神逢梟，或生財露煞，食神格敗也；
> 七煞逢財無制，七煞格敗也；
> 傷官非金水而見官，或生財生帶煞，或佩印而傷輕身旺，傷官格敗也；
> 陽刃無官煞，刃格敗也；
> 建祿月劫，無財官，透煞印，建祿月劫之格敗也。

**成中有敗 · 帶忌**
> 成中有敗，必是帶忌；敗中有成，全憑救應。
> 何謂帶忌？如正官逢財而又逢傷；透官而又逢合；財旺生官而又逢傷逢合；
> 印透食以洩氣，而又遇財露；透煞以生印，而又透財，以去印存煞；
> 食神帶煞印而又逢財；七煞逢食制而又逢印；
> 傷官生財而財又逢合；佩印而印又遭傷，透財而逢煞，是皆謂之帶忌也。

**敗中有成 · 救應**
> 何謂救應？如官逢傷而透印以解之，雜煞而合煞以清之，刑沖而會合以解之；
> 財逢劫而透食以化之，生官以制之，逢煞而食神制煞以生財，或存財而合煞；
> 印逢財而劫財以解之，或合財而存印；
> 食逢梟而就煞以成格，或生財以護食；
> 煞逢食制，印來護煞，而逢財以去印存食；
> 傷官生財透煞而煞逢合；
> 陽刃用官煞帶傷食，而重印以護之；
> 建祿月劫用官，遇傷而傷被合，用財帶煞而煞被合，是謂之救應也。

**맺음**
> 八字妙用，全在成敗救應，其中權輕權重，甚是活潑。
> 學者從此留心，能於萬變中融以一理，則於命之一道，其庶幾乎！
