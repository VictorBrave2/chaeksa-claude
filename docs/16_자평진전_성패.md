# 자평진전 성패구응 — 검수용 초안

지금 엔진은 **성격 / 파격 두 칸**이다. 원전은 넷이다.

```
成格        격이 섰다
敗格        격이 깨졌다
成中有敗    섰는데 기신을 띠었다     「必是帶忌」
敗中有成    깨졌는데 구제가 있다     「全憑救應」
```

자평진전이 「論用神成敗救應」에서 지면을 제일 많이 쓴 대목이 뒤의 둘인데
우리 엔진에는 그게 아예 없다. 「상관견관이면 파격」에서 끝나고,
인수가 구제하는 경우를 안 본다.

`references/세고전.md`의 표가 두 칸뿐이었던 것이 원인이다.
**근거 문서가 얕으면 코드도 딱 그만큼 얕다** — 지장간 때와 같은 모양이다.

---

## 검수 표시

| | 뜻 |
|---|---|
| ◎ | 원문에 명시된 것으로 기억한다. 거의 확신 |
| ○ | 원문 취지에서 유도했다. 검수 필요 |
| △ | **기억이 흐리다. 반드시 확인해 주셔야 한다** |

**△ 는 코드로 안 옮긴다.** 사장님이 쳐내거나 고쳐주시기 전까지는 넣지 않는다.

---

## 먼저 — 상신(相神)이라는 것

자평진전의 핵심은 **격이 아니라 상신**이다. 격은 월령이 정해주는 것이고,
그 격을 **쓸 수 있게 만드는 글자**가 상신이다.

    격    월령이 준다.       고를 수 없다
    상신  격을 완성시킨다.   여기서 사주가 갈린다

지금 엔진은 「상신이 있냐 없냐」만 보고 **무엇이 상신인지 말해주지 않는다.**
상담에서 정작 필요한 것이 그것이다 — 「당신의 격은 정관이고, 그 격을 세우는 것은
월간 甲(정인)입니다」까지 나와야 쓸 물건이 된다.

**그러니 판정만 고칠 게 아니라 상신을 내놓게 해야 한다.**

## 1. 정관격

| | | |
|---|---|---|
| 상신 | 재 또는 인 | ◎ |
| 成格 | 관이 재·인을 만나고 형충파해가 없다. 재와 인이 둘 다면 상격 | ◎ |
| 敗格 | 상관에게 극당하거나(상관견관) 형충을 만난다 | ◎ |
| 帶忌 | 관이 재를 만났는데 **상관도 같이** 있다 · 관이 투출했는데 **합거**된다 | ◎ |
| 救應 | 상관을 만났는데 **인수가 투출해 상관을 제한다** | ◎ |
| 救應 | 칠살이 섞였는데(관살혼잡) **살이 합거되어 맑아진다** | ◎ |
| 救應 | 형충이 있는데 **회합(육합·삼합)이 그것을 풀어준다** | ○ |

> 官逢財印, 又無刑冲破害, 官格成也 / 官逢傷剋刑冲, 官格敗也
> 官逢傷而透印以解之, 雜煞而合煞以清之, 刑冲而會合以解之

**지금 코드**: `!상관 && !편관 && (재성 || 인성)`
**빠진 것**: 형충 조항 · 帶忌 셋 · 救應 셋. 구제를 안 보므로 **인수 있는 상관견관을 파격으로 죽인다.**

## 2. 재격

| | | |
|---|---|---|
| 상신 | 식상(생재) 또는 관(재생관) 또는 인(신강할 때) | ◎ |
| 成格 | 재가 관을 생해 관이 왕하다 · 식신이 재를 생하는데 일간이 비겁으로 강하다 | ◎ |
| 成格 | 재격에 인을 차되 자리가 서로 안 부딪친다(位置妥貼) | ○ |
| 敗格 | 재는 가벼운데 비겁이 무겁다(財輕比重) | ◎ |
| 敗格 | 재가 칠살을 투출시킨다(財透七殺) — 재생살 | ◎ |
| 帶忌 | 재가 관을 생하는데 **상관이 같이 있다** · 관이 **합거**된다 | ◎ |
| 救應 | 겁재를 만났는데 **식신이 투출해 겁재를 화(化)한다** | ◎ |
| 救應 | 겁재를 만났는데 **관을 생해 그 관이 겁재를 제한다** | ◎ |

> 財生官旺 … 財格成也 / 財輕比重, 財透七殺, 財格敗也
> 財逢劫而透食化之, 生官以制之

**지금 코드**: `비겁<3 && (식상 || 관성)`
**빠진 것**: 재투칠살 파격 · 帶忌 · 救應 둘. 「비겁 3개」는 원문의 **財輕比重**(무게 비교)을 **개수**로 바꾼 것이라 근사다.

## 3. 인격 (정인)

| | | |
|---|---|---|
| 상신 | 관(관인상생) 또는 식상(신인양왕일 때 설기) | ◎ |
| 成格 | 인이 가벼운데 살을 만난다(印輕逢殺) · 관인이 둘 다 온전하다 | ◎ |
| 成格 | 일간과 인이 둘 다 왕해 **식상으로 설기**한다 | ◎ |
| 成格 | 인이 많은데 재를 만나되 **그 재의 뿌리가 얕다**(財透根輕) | ○ |
| 敗格 | 인이 가벼운데 재를 만난다(印輕逢財) — 재극인 | ◎ |
| 敗格 | 일간이 강하고 인이 무거운데 **살까지 투출한다** | ○ |
| 帶忌 | 인이 식신을 투출시켜 설기하는데 **재까지 드러난다** | ◎ |
| 救應 | 재를 만났는데 **겁재가 그 재를 제한다** | ◎ |
| 救應 | 재를 만났는데 **합으로 그 재가 없어진다(合財以去之)** | ◎ |

> 印輕逢殺, 或官印雙全 … 印格成也 / 印輕逢財 … 印格敗也
> 印逢財而劫財以解之, 合財以去之

**지금 코드**: `!정재투출 && !편재투출 && 관성`
**빠진 것**: 신인양왕 설기 성격 · 財透根輕 · 帶忌 · 救應 둘. **인격에서 겁재가 구제라는 것을 전혀 안 본다.**

## 4. 식신격

| | | |
|---|---|---|
| 상신 | 재(식신생재) 또는 칠살(식신제살) | ◎ |
| 成格 | 식신이 재를 생한다 | ◎ |
| 成格 | 식신이 살을 띠었는데 **재가 없다**(食帶殺而無財) | ◎ |
| 成格 | 식신을 버리고 살을 취하되 **인이 투출한다**(棄食就殺而透印) | ○ |
| 敗格 | 식신이 편인(梟神)을 만난다 — 효신탈식 | ◎ |
| 敗格 | 재를 생하는데 **살까지 드러난다**(生財露殺) | ◎ |
| 帶忌 | 식신이 살과 인을 띠었는데 **재까지 만난다** | ◎ |
| 救應 | 편인을 만났는데 **칠살이 투출해 도리어 격을 이룬다** | ◎ |
| 救應 | 편인을 만났는데 **재를 생해 식신을 보호한다(生財以護食)** | ◎ |

> 食神生財 … 食格成也 / 食神逢梟, 或生財露殺, 食格敗也
> 食逢梟而透煞以成格, 或生財以護食

**지금 코드**: `!편인 && (재성 || 편관)`
**빠진 것**: 生財露殺 파격 · 帶忌 · 救應 둘. **효신탈식을 무조건 파격으로 죽인다.**

## 5. 칠살격 (편관)

| | | |
|---|---|---|
| 상신 | 식신(제살) 또는 인(살인상생) | ◎ |
| 成格 | 살이 식신의 제를 만난다 · 일간이 무겁고 살이 가볍다 | ◎ |
| 成格 | **살이 무겁고 식신이 가벼우면 식신을 돕고, 식신이 무겁고 살이 가벼우면 살을 돕는다** | ◎ |
| 成格 | 살과 식신이 나란한데 **인을 생한다** | ○ |
| 敗格 | **살이 재를 만났는데 제함이 없다**(殺逢財而無制) — 재생살 | ◎ |
| 帶忌 | 칠살이 식신의 제를 만났는데 **인이 또 온다**(인이 식신을 제해버린다) | ◎ |
| 救應 | 인이 와서 살을 보호하는데, **운이 재로 가 인을 없애고 식신을 남긴다** | ◎ |

> 살과 식신은 서로 견주어 가벼운 쪽을 돕는다 — 2026-08-28 사장님 교정.
> 초안은 반쪽만 옮겨적어 「제살이 모자란데 살을 돕는다」로 앞뒤가 안 맞았다.
>
> 殺逢食制 … 殺格成也 / 殺逢財而無制, 殺格敗也
> 煞逢食制, 印來護煞, 而反行財運以去印存食

**지금 코드**: `식신 || 인성` — **성격 조건만 있고 파격 조항이 통째로 없다.**
**빠진 것**: 재생살 파격 · 帶忌 · 救應. 오늘 「뿌리 얻은 칠살이라야 진짜로 친다」고 정한 것과도 아직 안 이어져 있다.

## 6. 상관격

| | | |
|---|---|---|
| 상신 | 재(상관생재) 또는 인(상관패인) | ◎ |
| 成格 | 상관이 재를 생한다 | ◎ |
| 成格 | 상관패인인데 **상관이 왕하고 인에 뿌리가 있다** | ◎ |
| 成格 | 상관이 왕하고 일간이 약한데 **살과 인이 투출한다** | ○ |
| 成格 | 상관이 살을 띠었는데 **재가 없다** | ◎ |
| 敗格 | **금수상관이 아닌데 관을 본다**(非金水而見官) — 상관견관 | ◎ |
| 敗格 | 재를 생하는데 **그 재의 뿌리가 얕다** | ○ |
| 敗格 | 패인인데 **인이 가볍고 일간이 약하다** | ○ |
| 敗格 | 상관이 살을 띠었는데 **재까지 만난다** | ◎ |
| 帶忌 | 상관생재인데 **칠살이 같이 온다** | ◎ |
| 救應 | 관을 보았는데 **그 관이 합거된다**(傷官生財透煞而煞逢合 계열) | ◎ |

**금수상관희견관(金水傷官喜見官)** — 겨울 금 일간의 상관은 관을 반긴다. 조후 때문이다. ◎
지금 엔진은 이 예외를 **전혀 안 본다.**

**지금 코드**: `!정관 && (재성 || 인성)`
**빠진 것**: 금수 예외 · 뿌리 조건 · 帶忌 · 救應.

## 9. 편인격은 자평진전에 따로 없다

우리 코드에는 편인격이 있고 `!식신 && 재성`으로 판정한다.
자평진전은 편인을 **효신(梟神)**으로 보아 인격 안에서 다루거나,
식신격의 파격 요인으로 등장시킨다. **격으로 따로 세우지 않는다.** ○

인격에 합치는 것이 맞는지 사장님 판정이 필요하다.

---

## 합거는 이미 있다

**救應 조항 중 「합거되어 맑아진다」가 여러 격에 걸쳐 나온다.**
정관격의 합살이청, 인격의 합재이거지, 상관격의 살봉합, 건록격의 상관피합.

오늘 넣은 `natalHap` / 체용의 층별 합거가 **바로 그 판정에 쓰인다.**
격 성패를 4칸으로 넓히면 오늘 작업이 여기서 값을 한다.

다만 격 판정은 **원국 기준**이라 운의 합거는 안 쓴다.
운으로 합이 되어 격이 맑아지는 것은 **체용 층에서 따로 말해야 한다** — 「올해는 격이 맑아진다」. ○

## C. 輕重을 비교로 옮긴다

원문에 경중 비교가 열 군데 넘게 나온다. 지금 코드는 이걸 **개수**로 근사했다 —
「비겁 3개 이상이면 財輕比重」식이다. 오늘 천간의 힘을 재게 됐으니 비교로 바꾼다.

**절대 경계는 만들지 않는다.** 「旺이란 몇 점 이상」을 정하는 순간 지어낸 값이 된다.

| 원문 | 비교 |
|---|---|
| 財輕比重 | 재성의 힘 < 비겁의 힘 |
| 印輕逢殺 | 인성의 힘 < 칠살의 힘 |
| 印輕逢財 | 인성의 힘 < 재성의 힘 |
| 身重殺輕 | 일간의 힘 > 칠살의 힘 |
| 殺重食輕 | 칠살의 힘 > 식신의 힘 |
| 傷官旺身主弱 | 상관의 힘 > 일간의 힘 |
| 印輕身弱 (상관패인) | 인성의 힘 < 상관의 힘 |
| 傷官旺印有根 | 상관의 힘 > 일간의 힘 **AND** 인성이 통근 |

**십신의 힘** = 그 십신에 해당하는 천간들의 힘 합. 힘은 `stemPower` 하나로 낸다.

### 그러려면 일간의 힘을 재야 한다

지금 우리는 **일간의 힘을 안 잰다.** 일간은 주체라 강약 계산의 `stems` 에서 빼놓았고,
그래서 「身重」「身弱」을 견줄 상대가 없다.

일간도 같은 규칙으로 재면 된다 — `stemPower(일간, 지지자리)`.
강약 계산은 그대로 두고, **견주기용으로만 따로 낸다.**

    壬申 甲辰 丁卯 庚子
      일간 丁  申 목욕 .50×1.0 / 辰 쇠 .62×2.0 / 卯 병 .20×1.0 / 子 절 .05×1.5
               → 1.24
      칠살 —   (壬은 정관이라 칠살 아님)
      정관 壬  2.45          관 2.45 > 일간 1.24   →  官重身輕

강약 0.33(신약)과 방향이 같다. **다른 축을 새로 만드는 게 아니라 같은 자에서 뽑는다.**

### 남는 것 하나 — 根輕

「財透根輕」「印有根」의 **有根은 이진**이라 지금도 잴 수 있다(통근 여부).
그런데 **根輕**은 「뿌리가 있되 얕다」라서 경계가 필요하다.

    제 기본안 — 십이운성 표의 자연스러운 마디를 쓴다. 새 숫자를 안 만든다.
      根深   장생 .55 이상 (장생·관대·건록·제왕)
      根輕   그 아래 (목욕 .50 · 쇠 .62?… 순서가 안 맞는다)

**여기서 걸린다.** 우리 세기표는 쇠(.62)가 장생(.55)보다 높다.
「생왕(生旺)이냐 쇠절(衰絶)이냐」는 단계 이름의 문제이고 우리 표는 세기의 문제라
두 축이 안 겹친다. **사장님 판정이 필요한 자리다.**
