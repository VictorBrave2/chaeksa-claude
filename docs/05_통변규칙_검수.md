# 통변 규칙 검수 가이드

## 지금 무엇이 들어 있나
- 규칙 세트 **85개** (강약 구분 60 + 폴백 25)
- 경쟁 가설 **170개**, 판별 질문 **255개**
- 구성: 6도메인(직업·사업 / 재물 / 관계 / 건강 / 학업 / 이동) × 5십신그룹(비겁·식상·재성·관성·인성) × 강약

## 어떤 전제로 썼나 (검수가 필요한 지점)
자평 명리의 통설을 기준으로 했다. 학파에 따라 갈리는 부분은 아래와 같다.

| 항목 | 지금 택한 관점 | 다른 관점 |
|---|---|---|
| 신강·신약 | 월령·통근·비겁/인성 세력으로만 판정 | 십이운성·지장간 비중을 달리 보는 방식 |
| 재성 | 신강에서 취용, 신약에서 부담 | 재성 자체를 항상 길로 보는 방식 |
| 관성 | 신강에서 귀(貴), 신약에서 살(殺) | 관살 혼잡 여부를 먼저 보는 방식 |
| 신살 | **쓰지 않음** (백호·괴강·도화 등 미적용) | 신살을 주요 판단 근거로 쓰는 방식 |
| 조후 | 巳午未 / 亥子丑 생만 보정 | 궁통보감식으로 12월령 전부 조후 우선 |
| 진태양시 | 기본 적용(경도 보정) | 표준시 그대로 쓰는 방식 |

## 검수하는 법
1. `chaeksa.kr` → 상담 탭에서 도메인별로 질문을 넣어본다
2. "지금 보이는 구조"를 펼쳐 계산이 맞는지 확인
3. 가설 문장이 명리적으로 어색하면 **그 문장 그대로** 알려주면 규칙을 고친다
4. 판별 질문이 두 가설을 실제로 가르지 못하면 알려달라 (우도비 조정 필요)

## 고칠 때 보는 곳
- 직업·사업: `app/tongbyeon.js` 내 `R('career', ...)`
- 재물·관계: `app/rules-wealth-love.js`
- 건강·학업·이동: `app/rules-health-study-move.js`

각 규칙의 구조:
```
theme  주제 한 줄
lead   첫 문장 (책사가 상담을 여는 말)
H      가설: id, 제목, 사전확률, 근거, 현실신호[], 실행과제, 관측지표
Q      판별질문: id, 질문, {가설id: {y:우도비, n:우도비}}
```
우도비가 1보다 크면 "예"가 그 가설을 지지, 작으면 반증한다.
