# 작업판

사장님 말은 받는 즉시 여기 적고 담당을 붙인다. 닫을 때는 **증거**(커밋 · 시험 수 · 라이브 확인)를 적는다. 「했다」만으로는 안 닫는다.
목적 조각: **엔진**(보이지 않는 심장) · **한 사람**(공주님 한 사람을 위한 느낌) · **즐거움**(여는 것 자체가 즐거운) · **수익**.
담당: 총괄(메인 세션) · 엔진 `chaeksa-engine` · 작가 `chaeksa-writer` · 검수 `chaeksa-reviewer` · 화면 `chaeksa-screen` · 시험·배포 `chaeksa-qa` · 수익 `chaeksa-revenue` · 유입 `chaeksa-inflow` · 상담 답변 `chaeksa-consult` · 블로그 `chaeksa-blog` · 사장님.
원고 한 편의 길: 작가 → 검수 → 화면 → 시험·배포 → 사장님 검수.
