# 정통사주 웹툰 — 뼈대 v1 (2026-09-26 동결 — 사장님 「그럴싸하게 바꾸고 시작」 · 「19회 삭제」)

소재 = 나에 대한 물음(사장님 09-26). 회 하나 = 물음 하나. 여덟 묶음 25회. 한 회 = ① 물음(책사) → ② 내가 사는 장면(조각) → ③ 근거(「왜 그렇게 살까」 — 책사 해설 + 추론의 단서, 실제 연도).
조각 축은 2단계(갈림 정하기)에서 정한다. 여기서는 물음과 회의 줄 딱지만.

## 줄 딱지(연애궁합과 같음)
- `장면`(공통 지문) · `@물음`(책사) · `@나`(조각 — 내 장면 · 대사) · `@단서`(엔진, 있는 각도만) · `@해설`(조각 또는 엔진) · `@해`(실제 연도 문장) · `근거`(회 끝 표).
- 이름표: 나 = 왼쪽 위 · 책사 = 가운데(그 사람 없음).
