# 문장표 · 「우리는 몸이 붙는 사이예요?」 — 20 (2026-09-11 다시 씀 · 새 틀)

속궁합 4번, 무료. 각도는 「몸」 — 마음 4번(끌림이 어디서 시작되나)·궁합 5번(같이 사는 장면)과 겹치지 않게.
첫 판(2026-09-05)은 「두 사람의 짝 자리가 서로 붙는 글자이고 중심 글자끼리도 붙어요. 여기에 한쪽 짝 자리가 다른 쪽의 눈길 자리예요」로
칸마다 판정키를 늘어놓았다. 새 틀(docs/34)로 다시 썼다. 제목의 「자리」도 뺐다(표 이름은 그대로).
