# 검사 요청 — 명리 통변 시스템 「상태차」

아래는 저희가 만든 사주 통변 시스템입니다. **명리 이론과 설계 양쪽에서 검사해 주세요.**
저희가 이미 아는 약점도 아래 6번에 적어 두었으니, 그것 말고 저희가 못 본 게 있는지 봐 주시면 좋겠습니다.

---

## 1. 무엇을 만들려는가

사주 상담 앱입니다. 문제는 **판정이 아니라 통변**이었습니다.
엔진이 계산은 다 하는데, 그 값을 사람이 읽는 문장으로 옮기는 데서 막혔습니다.

LLM을 쓰면 문장은 나오지만 원가가 들고 매번 달라집니다.
그래서 **「계산값의 조합마다 문장을 미리 정해 두는」** 방식을 택했습니다.

---

## 2. 핵심 설계 — 상태차(狀態差)

사주를 **상태 벡터**로 보고, 두 시점의 차이를 말합니다.

```
x(시점)  =  그 시점에 작동하는 운에서 다섯 무리(비겁·식상·재성·관성·인성)의 개수
Δ        =  x(볼 시점) − x(기준 시점)
통변     =  Δ 를 말로 옮긴 것
```

**과거를 물으면** 기준=올해, 볼 시점=과거 → 「지금은 이런데, 그때는 이랬다」
**미래를 물으면** 기준=올해, 볼 시점=미래 → 「지금은 이런데, 그때가 되면 이렇다」

같은 표 하나로 과거·현재·미래를 다 답합니다. 코드가 갈리지 않습니다.

---

## 3. 상태를 재는 방법 (실제 코드)

```javascript
// 그 해에 작동하는 대운·세운의 네 글자를 다섯 무리로 센다.
// 가중치를 두지 않는다. 개수만 센다.
M.판 = (R, 해) => {
  const e = global.ChaeksaEngine;
  const out = { 비겁: 0, 식상: 0, 재성: 0, 관성: 0, 인성: 0 };
  const ds = R.pillars.day.stem;                       // 일간
  const du = e.currentDaeun(R, new Date(해, 6, 1));    // 그 해의 대운
  const tf = e.dateFortune(해, 7, 1);                  // 그 해의 세운
  const 넣 = (st) => {
    if (st == null) return;
    const g = 무리표[e.TEN_GODS[e.tenGod(ds, st)]];    // 십신 → 다섯 무리
    if (g) out[g]++;
  };
  [ du.stem,                          // 대운 천간
    (e.HIDDEN[du.branch] || [])[0],   // 대운 지지의 본기
    tf.year.stem,                     // 세운 천간
    (e.HIDDEN[tf.year.branch] || [])[0] // 세운 지지의 본기
  ].forEach(넣);
  return { x: out };
};

// 두 시점의 차 → 키 다섯 자리
M.판차 = (R, 기준해, 볼해) => {
  const a = M.판(R, 기준해), b = M.판(R, 볼해);
  return ['비겁','식상','재성','관성','인성'].map(g => {
    const d = b.x[g] - a.x[g];
    return d > 0 ? '+' : d < 0 ? '-' : '0';
  }).join('');
};
```

십신 → 무리 대응은 통상대로입니다.
`비견·겁재 → 비겁` / `식신·상관 → 식상` / `편재·정재 → 재성` / `편관·정관 → 관성` / `편인·정인 → 인성`

## 4. 키 체계 — 243칸

키는 **다섯 자리**, 순서는 `비겁 · 식상 · 재성 · 관성 · 인성`.
각 자리는 `+`(늘었다) `0`(그대로) `-`(줄었다).

```
0+-+0   →  비겁 그대로 · 식상 늘고 · 재성 줄고 · 관성 늘고 · 인성 그대로
```

3⁵ = **243칸**. 전수를 다 채웠습니다.
움직인 자리 수로 나누면 0개 1칸 · 1개 10칸 · 2개 40칸 · 3개 80칸 · 4개 80칸 · 5개 32칸.

각 자리의 뜻은 이렇게 잡았습니다.

| 자리 | 늘면 | 줄면 |
|---|---|---|
| 비겁 | 내 힘과 내 사람이 는다 | 혼자 서는 힘이 준다 |
| 식상 | 말과 하고 싶은 것이 는다 | 내놓을 데가 준다 |
| 재성 | 돈과 손에 잡히는 것이 는다 | 돈과 결과가 준다 |
| 관성 | 자리와 책임이 는다 | 자리와 규율이 헐거워진다 |
| 인성 | 받쳐 주는 것과 배움이 는다 | 기댈 데와 명분이 준다 |

## 5. 실제 동작 (1992-07-03 14:10 여, 서울)

```
2015년   대운 甲辰 / 세운 乙未   →  비겁0 식상0 재성2 관성0 인성2
2026년   대운 癸卯 / 세운 丙午   →  비겁0 식상1 재성1 관성2 인성0
2035년   대운 壬寅 / 세운 乙卯   →  비겁0 식상1 재성3 관성0 인성0
```

**과거를 물으면** (기준 2026 → 볼 2015, 키 `0-+-+`)
> 지금은 자리와 책임이 앞에 서 있는 때예요. **그때는** 돈도 기댈 데도 느는데 내놓을 데도 자리도 줄었어요.
> 쥐어지는 것과 받쳐 주는 것은 커졌는데 낼 통로와 세울 자리가 같이 빠졌어요. 조용히 채우는 자리라, 이럴 때 쌓아 둔 것이 다음에 나옵니다.

**미래를 물으면** (기준 2026 → 볼 2035, 키 `00+-0`)
> 지금은 자리와 책임이 앞에 서 있는 때예요. **그때가 되면** 돈은 붙는데 자리가 헐거워지는 때예요.
> 실속은 느는데 직함이나 소속은 옅어진 자리예요. 조직 밖으로 나가거나 혼자 하는 쪽으로 기우는 구간이에요.

무작위 사주 400개 × 시점 8개 = 3,200번 물어서 **칸을 못 찾은 경우 0건**, 실제로 나온 키 164가지였습니다.

## 6. 저희가 이미 아는 약점 (이것 말고 다른 걸 봐 주세요)

정직하게 먼저 적습니다.

1. **원국(사주 여덟 글자)을 안 봅니다.** 운의 네 글자만 셉니다.
   같은 「재성 +1」이라도 원국이 신강이냐 신약이냐에 따라 뜻이 정반대일 텐데, 지금은 구분이 없습니다.
2. **지지 본기만 세고 중기·여기를 버립니다.** 지장간 셋 중 하나만 씁니다.
3. **가중치가 없습니다.** 통근·왕쇠·월령을 안 봅니다. 대운 천간과 세운 천간이 같은 1점입니다.
   (앞서 가중치를 넣어 봤다가, 그 가중치를 저희가 임의로 정하게 되어 결과가 그 숫자에 좌우되는 걸 보고 뺐습니다.)
4. **「−」가 극(剋)인지 단순 부재인지 구분이 없습니다.**
   재성이 줄었다는 게 「비겁이 겁탈해서」인지 「그냥 그 글자가 안 와서」인지를 표가 모릅니다.
5. **합·충·형을 안 봅니다.**
6. **대운 경계와 세운 경계가 어긋나는 해**(입춘 전후, 대운 교체기)를 지금은 7월 1일 기준으로 단순화했습니다.

## 7. 검사해 주셨으면 하는 것

**명리 쪽**

- 「운의 네 글자를 십신 무리로 세어 상태로 삼는다」는 발상이 명리적으로 성립합니까? 성립한다면 어느 유파의 논리에 가깝고, 성립하지 않는다면 무엇이 결정적으로 빠진 겁니까?
- 위 6번의 약점 중 **무엇을 먼저 메워야 통변의 정확도가 가장 크게 오릅니까?** 순서를 매겨 주세요.
- 4번(극인지 부재인지)을 구분하려면 어떻게 해야 합니까? 이걸 넣으면 칸 수가 얼마나 늘어납니까?
- 243칸을 다 쓰는 게 맞습니까, 아니면 명리적으로 **일어날 수 없는 조합**이 있어서 걸러야 합니까?

**설계 쪽**

- 「두 시점의 상태를 빼서 그 차이만 말한다」로 과거·현재·미래를 다 덮으려는 구조에 논리적 구멍이 있습니까?
- 원국을 안 보는 것을 **나중에 층으로 얹을 수 있습니까**, 아니면 처음부터 상태에 넣어야 합니까?
- 이 방식이 결국 「대운·세운 간지를 다시 말하는 것」에 지나지 않게 될 위험이 있습니까?
  (앞서 다른 방식으로 만들었을 때 결과의 83%가 대운 두 글자의 십신과 그대로 같아서 폐기한 적이 있습니다.)

**문장 쪽**

- 5번의 실제 출력 두 개가 명리적으로 타당한 서술입니까? 틀린 대목이 있으면 짚어 주세요.
- 「지금은 이런데 그때는 이렇다」라는 형식이 상담에서 실제로 쓸모가 있습니까?

## 8. 참고 — 243칸 문장표 전문

별도 파일 `37_상태차_243.md` 에 243칸이 전부 들어 있습니다.
각 칸은 `답`(한 줄 결론) + `왜`(2~3문장 설명 + 오늘 할 것)로 되어 있습니다.

예시 세 칸:

```
**0+-+0**   (식상↑ 재성↓ 관성↑)
답: 말은 느는데 돈은 안 되고 책임만 늘었어요.
왜: 하고 싶은 말과 맡는 자리가 같이 커졌는데 그 사이를 잇는 돈만 빠졌어요.
    벌인 것이 값을 못 받고 곧장 규율과 부딪히는 자리라, 말을 그냥 내면 상하고
    결과물로 바꿔 내면 받아들여집니다.

**0+++0**   (식상↑ 재성↑ 관성↑)
답: 말도 돈도 자리도 같이 늘었어요.
왜: 만든 것이 돈이 되고 그 돈이 자리로 이어지는 자리예요. 사슬이 끝까지
    이어지는 드문 구간이라, 지금 벌인 일이 이력으로 남습니다.

**---+0**   (비겁↓ 식상↓ 재성↓ 관성↑)
답: 책임만 늘고 나머지가 다 줄었어요.
왜: 맡는 일 하나만 커지고 밀 힘과 낼 말과 거둘 것이 다 얇아졌어요.
    스물다섯 자리 중 제일 무거운 쪽이라, 새 짐을 받지 않는 것이 최선입니다.
```
