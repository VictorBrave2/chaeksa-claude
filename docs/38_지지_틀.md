# 지지 규칙 — 이런 꼴이면 바로 짤 수 있다 (2026-09-14 · 사장님 「코드로 짜기 쉽게 가져와야 하는 숙제」 → 「틀을 주고」)

사장님이 채우면 그대로 코드가 되는 틀이다. 낱말은 아래 **정해진 것만** 쓴다. 정해진 낱말 밖의 말이 오면 내가 되묻는다.
원문이 말하는 것 / 안 말하는 것은 docs/36 에 있다. 이 틀은 그 위에 사장님이 정하는 자리다.

## 둘 · 채울 표 다섯

### 표 1 · 지지 온도 (열두 칸)

「지지의 힘 근거는 온도」(사장님). 원문(궁통보감 丙 수요)이 뽑아 준 순서: 丑 > 子 > 寅 ≈ 亥 > 卯 > 申·酉 > 辰 > 戌 > 未 > 巳 > 午. 사장님 말은 「亥가 가장 차다」. 둘이 다르니 사장님 값으로 채운다.

| 지지 | 子 | 丑 | 寅 | 卯 | 辰 | 巳 | 午 | 未 | 申 | 酉 | 戌 | 亥 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 온도 (−5 가장 참 … +5 가장 더움) | | | | | | | | | | | | |

그리고 온도가 **무엇을 바꾸나** 한 줄: 「온도 −3 이하의 자리에 앉은 火 글자는 힘을 (얼마) 깎는다 / 水 글자는 (얼마) 더한다」처럼. 오행마다 한 줄, 다섯 줄.

### 표 2 · 지지가 하는 일 (IF → THEN)

한 줄이 규칙 하나다. 「IF [층] [누가] [무엇을] THEN [결과 키 또는 글자 상태]」. 예시 두 줄은 원문(docs/36)에서 온 것이고, 나머지는 사장님이 쓴다.

| IF | THEN | 근거 |
|---|---|---|
| 원국 일지가 다른 원국 지지와 충 | 일지 궁 = 궁충 | 16:62 「충은 곧 극」 (이미 코드에 있음) |
| 운 지지가 원국 지지 둘과 삼합을 완성 | 그 오행의 국이 선다(뿌리·취격) | 15:694 (이미 코드에 있음) |
| 오늘 지지가 일지와 충 | | (23조는 운의 충을 배제 — 사장님이 열면 여기) |
| 오늘 지지가 일지와 육합 | | |
| 이달 지지가 월지와 충 | | |
| 운 지지가 원국 지지와 반합 | | (6조: 반합은 국이 아님) |
| 형 · 파 · 해 | | (16:62 「반드시 파격 아님」 — 안 쓰면 「없음」) |

## 셋 · 채우는 법

- 빈 칸은 비워 둬도 된다. 빈 칸은 「아직 규칙 없음」이고 코드도 안 짠다.
- 낱말은 「하나」의 표에서만. 「좀 세다」 「약간」은 못 짠다. 수나 결과 키로.
- 사례가 있으면 표 옆에 「예: 壬申 甲辰 丁卯 庚子, 이날 이랬다」 한 줄. 그게 시험이 된다.
