## 핵심 설계 원칙 (이걸 어기면 제품이 무너진다)
> **뼈대는 코드가 정하고, 문장은 LLM이 쓴다.**
가설·순위·확률·간지·실행과제를 LLM이 만들게 두면 같은 사주라도 날마다 말이 달라진다.
판단은 전부 규칙으로 확정하고 LLM에게는 서술만 맡긴다.

> **카드 콘텐츠에는 LLM이 아예 없다.** 아홉 종 전부 기기 안 계산이라 원가 0원이고
> 같은 사주는 언제나 같은 카드가 나온다. 그래서 무료로 다 열 수 있다.

## 배포 전 점검 (반복 실수에서 뽑은 것)
1. **SVG 카드**: 먼저 /cards.html 로 **눈으로 본다**. 그다음 getBBox + getScreenCTM
   (변환 반영) 실측으로 ①경계 ②하단 ③도장 겹침 ④빈 구간 ⑤**글자 유실**.
2. **카드 배치**: 클래스 세 개만 달면 된다 — `.cardwrap > .cardflip > .cardsvg`.
3. **탭**: 새 탭은 내비에 넣거나 `← 홈`을 붙이거나 **둘 중 하나**.
4. **타이포**: 정적 HTML에 `.brief` 금지(pre-line이라 소스 줄바꿈이 그려진다) → `.doc`.
5. **새 유형·분기를 넣으면 반드시 분포를 찍는다** — 안 걸리는 가지가 세 번 나왔다.

## 알려진 함정
- `fallbacks`는 opus-5 전용, `effort`는 haiku 미지원 → ai.js paramsFor()가 분기
- lunar.js는 astro.js 뒤에 로드 (지연 참조로 방어는 해둠)
- CSS grid는 `minmax(0,1fr)` 필수 — `1fr`은 카드 밖으로 넘침
- python 문자열 치환 후 반드시 `new Function(소스)`로 파싱 확인.
  단 **스코프 오류는 파싱으로 안 잡힌다** — 배포 후 실행 스모크까지가 한 세트
- **브라우저 창이 숨겨져 있으면** clientWidth가 0이라 레이아웃 측정이 헛값이고,
  setTimeout이 조절되며, CSS 애니메이션이 0% 프레임에 멈춘다. resize_window로 폭 명시.
- GitHub Actions 큐가 멈추는 일이 있다(11분간 잡 미생성). 빈 커밋으로 재실행하면 풀린다.
- 공개값(Supabase URL·anon키)은 코드에 하드코딩. Vercel 비밀은
  ANTHROPIC_API_KEY · CRON_SECRET · VAPID_PRIVATE_KEY만. **service_role 키는 절대 금지.**
