## 핵심 설계 원칙 (이걸 어기면 제품이 무너진다)
> **뼈대는 코드가 정하고, 문장은 LLM이 쓴다.**
가설·순위·확률·간지·실행과제를 LLM이 만들게 두면 같은 사주라도 날마다 말이 달라진다.
판단은 전부 규칙으로 확정하고 LLM에게는 서술만 맡긴다.

## 파이프라인
```
① 분석엔진   astro(절기) · lunar(음력) · places(출생지) · engine(원국·대운·십신)  — AI 없음
② 적층 체용  chaeyong.js — 6층(원국→대운→세운→월운→일운→시운)을 얹으며
             層마다 體(누적,用제외) 기준으로 用을 順/逆(-3~+3) 판정 후 편입
             → 통변좌표 · 변곡점 · 강약이동
③ 통변엔진   tongbyeon + rules-* — 도메인·시기 판별, 경쟁가설 2개, 판별질문 3개,
             Belief Revision(우도비, TEMPER 0.6, 확률 15~85% 클램프), Decision Lab A/B/C
④ 통변 LLM   ai.js — 서술만. 가드: 새 가설 금지·순위 그대로·간지 재계산 금지·변곡점 짚기
             후처리 dehanja(한자→한글, 첫 괄호 하나만 유지)
```
자세한 것은 저장소 `docs/08_아키텍처.md`.

## 수익 구조 (docs/09)
- 원가 실측: 브리핑 5.4원(haiku) · 대화 10.6원(sonnet+캐싱) · 상담 32.4원 · 원국해석 29.7원
- 구독 9,900원 기준 보통 사용 440원(4.4%) · 한도 전부 소진 2,404원(24.3%)
- **무료는 '평생 체험'** (브리핑5·대화5·상담1·해석1·궁합1 = 평생 162원). 매달 주면 매출0인 사용자에게 매달 원가가 나가 구조가 무너진다.
- 한도 초과 시 규칙 기반 결과로 자동 전환되어 서비스는 안 멈춤

## 알려진 함정
- `fallbacks`는 opus-5 전용, `effort`는 haiku 미지원 → ai.js paramsFor()가 분기
- lunar.js는 astro.js 뒤에 로드 (지연 참조로 방어는 해둠)
- CSS grid는 `minmax(0,1fr)` 필수 — `1fr`은 내용 크기까지 늘어나 카드 밖으로 넘침
- 파일 수정 시 python 스크립트로 문자열 치환하는데, 정규식/이스케이프가 깨져
  JS 문자열 안에 진짜 줄바꿈이 들어간 적이 여러 번 있었다. 수정 후 반드시 `new Function(소스)`로 파싱 확인
