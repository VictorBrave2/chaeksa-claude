# 빈칸 작성본 — 2026-09-14

대상: 첨부 `39_빈칸(1).md`의 「사장님이 채울 것」 전체.

**문서의 빈칸을 채운 검토안이다. 사장님이 이미 승인한 조문과 이번에 작성한 제안을 구분한다. 이 파일을 받았다는 사실만으로 새 제안까지 승인된 것으로 기록하지 않는다. 저장소·실행 코드·배포는 변경하지 않았다.**

- **[기존 규칙]**: 연결된 법전·설계문서에서 확인한 내용.
- **[작성안] / [제안]**: 이번에 작성한 질문 또는 운영 결정. 고전의 확정 수치나 과거 승인으로 둔갑시키지 않는다.
- **[미확인] / [관측 대기]**: 입력·관찰이 없는 사실. 「없다」와 다르다.

위 표시는 문서 검토 상태다. 판정 모듈의 새 결과 키가 아니다. 명리 규칙의 문서상 일관성을 검토한 것이며, 실제 사건의 발생이나 예측 정확도를 검증한 결과가 아니다.

## 사장님이 채울 것

### 1 · 질문 격자 빈 칸 스물넷 (docs/37)

**[작성안] 질문 18개 + 「없다」 6개 = 24칸.** 원본의 「스물여섯」은 원본 자체의 정정 주석에 따라 스물넷으로 고쳤다. 관계(썸·연애·재회)와 재물의 기존 칸은 바꾸지 않는다. [S1]

질문은 기존 결과가 나온 뒤 연결하는 제목이다. 질문 문구를 근거 삼아 새로운 명리 판정을 만들지 않는다. `docs/37`의 「상태 묻기」 형식을 따른다. [S2]

| 갈래 | 결과 | 질문 (채우거나 「없다」) |
|---|---|---|
| 배우자(결혼) | 무근 | 결혼 얘기는 있지만 실제로 밀고 갈 힘은 부족한가요? |
| 배우자(결혼) | 극 통관 | 결혼을 막는 일이 있어도 중간에서 풀어 주는 도움이 있나요? |
| 배우자(결혼) | 극 제복 | 결혼을 방해하는 일이 막혀 있나요? |
| 배우자(결혼) | 극 힘차이 | 방해가 있어도 결혼을 밀고 갈 힘이 더 큰가요? |
| 배우자(결혼) | 극없음 | 없다 |
| 이별 | 무근 | 이 관계를 이어 갈 실제 힘이 부족한가요? |

| 이별 | 극없음 | 없다 |
| 이별 | 궁충 | 이번 일 말고도 관계가 흔들릴 조건이 원래 있나요? |
| 친구 | 극 통관 | 친구와 부딪힐 일을 중간에서 풀어 주는 도움이 있나요? |
| 친구 | 극 제복 | 친구 관계를 해치는 일이 막혀 있나요? |
| 친구 | 극 힘차이 | 친구 관계를 흔드는 문제보다 버티는 힘이 더 큰가요? |
| 친구 | 극없음 | 없다 |
| 직장 | 극없음 | 없다 |
| 직장 | 기신 방치 | 내 자리를 해치는 일을 막아 주는 것이 없나요? |
| 학습(시험·공부) | 극 제복 | 공부를 방해하는 일이 막혀 있나요? |
| 학습(시험·공부) | 극 힘차이 | 방해가 있어도 공부를 이어 갈 힘이 더 큰가요? |
| 학습(시험·공부) | 극없음 | 없다 |
| 가족 | 극 제복 | 그 가족을 힘들게 하는 일이 막혀 있나요? |
| 가족 | 극 힘차이 | 그 가족이 받는 압박보다 버티는 힘이 더 큰가요? |
| 가족 | 극없음 | 없다 |

**질문 적용 범위.**

「극없음」 여섯 칸의 「없다」는 결과를 삭제하라는 뜻이 아니라, 이번 작성안에서 독립 질문을 만들지 않겠다는 뜻이다. 판정과 필요시 설명은 유지하되, 이것만으로 「결혼한다·합격한다·관계가 좋아진다」를 만들지 않는다.

이별의 위 질문들은 **관계를 맡은 대상**의 결과에 붙인다. 인성을 별도로 읽는 결과에 그대로 붙이지 않는다. 예를 들어 인성이 생을 받았다는 이유로 「그 사람이 돌아온다」로 번역하지 않는다. 그 사람의 현재 마음을 묻는 질문에는 그 사람 쪽 입력과 판정이 필요하다. 대상 구분은 기존 `docs/34`를 따른다. [S5]

「통관」의 도움은 반드시 제삼자 한 사람이라는 뜻이 아니다. 「제복」은 치는 쪽을 다른 글자가 잡은 경우이고, 「힘차이」는 치는 쪽이 못 치는 경우다. 「무근」으로 거짓말·배신·진심 없음을 단정하지 않는다. 「궁충」 질문은 원국 상태를 묻는다. 오늘 처음 생긴 일처럼 반복해서 내지 않는다.

### 2 · 지지 틀 (docs/38) — 표 다섯

**표 1 · 온도.**

첨부 `docs/39`가 요구한 「일간 × 월지 120칸 조후표를 얹는 방식」으로 채운다. 이전 `docs/38`의 열두 지지 수치표를 임의의 숫자로 완성하는 방식은 채택하지 않는다. [S1, S3]

| 물음 | 답 |
|---|---|
| 이 일간이 이 달에 찾는 글자(조후용신)가 있을 때 / 없을 때, 지지 힘(자리 무게)에 무엇을 하나 | **[제안] 자리 무게는 바꾸지 않는다.** 조후표가 요구하는 글자의 있음·없음과 실제로 명령하는지를 별도로 읽는다. 조후를 이유로 지지 힘을 더하거나 깎는 수치 보정은 적용하지 않는다. 곱셈값이 꼭 필요한 구현에서는 **1, 즉 변화 없음**으로 둔다. 이는 온도 값이나 고전의 힘 계수가 아니다. |
| 시지에도 같은 조후표를 쓰나(같은 지지 = 같은 온도) | **[제안] 월지 자리에 시지를 대입하지 않는다.** 같은 亥라도 亥월과 亥시를 같은 계절 조건으로 처리하지 않는다. 월지 조후를 배경으로 시지의 기존 뿌리·국·지장간 규칙을 읽는다. 별도의 시각별 온도 수치와 보정식은 **미확인, 미적용**으로 둔다. |

**한 줄 규칙:** 「일간 × 월지 조후표는 필요한 글자의 조건을 읽는 데 쓰고, 지지 자리 무게는 그대로 둔다.」

원국 조후의 월지는 **출생 월지**로 유지한다. 이달의 계절을 읽는 정보는 원국 정보와 분리한다. 이달이 바뀌었다고 원국 월령을 덮어쓰지 않는다. 필요한 글자가 단순히 보이는 것과, 합거되지 않고 실제로 작용하는 것은 구분한다. 조후표의 세부 조건을 읽지 않은 단순 존재 검사로 조후 충족을 확정하지 않는다. [제안]

#### 덧붙임 · 「해월이 가장 차다 / 축월」과 실제 온도 값

| 확인할 것 | 이번 답 |
|---|---|
| 「亥가 가장 차다」를 확정 규칙으로 쓸까 | **쓰지 않는다 [제안].** 현재는 사용자 발언과 채록이 충돌하고 수치 근거가 없는 상태다. 사용자 발언 자체를 삭제하지 말고 미검증 가설로 보존한다. |
| 「丑이 가장 차다」는 무엇을 뜻하나 | `docs/38`에는 **궁통보감의 丙 수요에서 뽑은 순서**의 맨 앞이 丑이라고 적혀 있다. 이 채록을 설명할 때는 丑으로 적는다. 그러나 그것을 열두 지지의 보편적 실측 온도 순위라고 확대하지 않는다. [S3] |
| 지지별 −5~+5의 실제 값 | **제공된 자료에 확정 값이 없다.** 숫자를 새로 만들지 않는다. 「미확인」을 0으로 저장하지 않는다. 0은 중립 온도라는 별도 의미가 되기 때문이다. [S3, S4] |
| 그래서 엔진은 무엇을 적용하나 | **120칸 조후 조건은 유지하고, 새 온도 수치 보정은 적용하지 않는다 [제안].** 표 1의 답과 같다. 온도표 미완성 때문에 이미 근거가 있는 다른 판정까지 멈추지는 않는다. |

`docs/38`에 적힌 채록 순서는 「丑 > 子 > 寅 ≈ 亥 > 卯 > 申·酉 > 辰 > 戌 > 未 > 巳 > 午」이다. **이 순서는 채록의 내용이며, 이 문서가 새로 승인하는 숫자표가 아니다.** 원문이 지지의 힘을 수치로 주었다는 근거는 `docs/36`에도 없다고 명시돼 있다. [S3, S4]

**표 2 · IF → THEN**

새로운 단독 운 충 이론을 만들지 않고, 기존 **23조의 운 충 배제·6조의 합충 처리·50조의 국 완성 충**을 구분해서 채운다. 사례 열의 새 예시는 규칙을 확인할 **구조 예시**이며, 사장님에게 실제로 일어났던 사건이 아니다. [S3, S6]

| IF | THEN | 사례 |
|---|---|---|
| 오늘 지지가 일지와 충 | **[기존 규칙 유지] 이것만으로 새 궁충·극닿음·무근을 내지 않는다.** 일반 운 읽기는 23조대로 단독 운 충을 배제한다. 50조의 국 완성 충은 따로 검사한다. | 원국 일지 子, 오늘 午: 이 한 쌍만으로 「헤어진다」 또는 「원국 궁충」을 새로 만들지 않는다. |
| 오늘 지지가 일지와 육합 | **[기존 규칙 적용] 운 지지를 더해 6조의 결합을 다시 푼다.** 육합 자체를 천간의 합거·생받음으로 바꾸지 않는다. 실제로 바뀐 국·명령·대상 상태가 있으면 그 기존 판정만 낸다. | 원국 일지 卯, 오늘 戌: 卯戌 육합 후보. 더 우선하는 삼합·반합이 戌을 쓰는지 먼저 본다. 육합 하나만으로 결혼·재회를 확정하지 않는다. |
| 이달 지지가 월지와 충 | **[기존 규칙 유지] 원국 월지를 지우거나 격을 자동 파격시키지 않는다.** 단독 운 충으로는 새 결과를 내지 않는다. 운의 합·국과 천간 명령을 반영한 기존 변격 계산은 별도로 한다. | 원국 월지 辰, 이달 戌: 「辰 삭제 → 원국 월령 교체」로 처리하지 않는다. 50조의 두 국 완성 여부는 별도다. |
| 운 지지가 원국 지지와 반합 | **[기존 규칙 적용] 반합으로만 센다. 국이 선 것으로 보지 않는다.** 6조 결합 우선순위에는 반영하되, 반합 보너스 수치를 만들거나 삼합국 명령을 주지 않는다. | 卯와 未만 있으면 반합. 亥까지 실제로 갖추었을 때 삼합 완성 여부를 검사한다. |
| 운 지지 하나가 원국 뿌리 하나를 충(국이 아닌 뿌리) | **[기존 규칙 유지] 이것만으로 그 뿌리를 0으로 만들거나 천간을 무근 처리하지 않는다.** 단독 뿌리 충의 손실 규칙은 별도 승인 없이 추가하지 않는다. | 壬의 뿌리 후보 중 申에 寅이 왔다는 이유만으로 다른 뿌리까지 지우지 않는다. 국 완성 충은 50조로 따로 읽는다. |
| 형 · 파 · 해 | **없음 — 현재 판정에 사용하지 않는다.** | 기존 범위 유지. 「없음」은 이 엔진에서 미사용이라는 뜻이지 모든 전통 이론에 없다는 뜻이 아니다. |

**50조 적용의 한계 [기존 규칙 + 구현 점검 제안].** 두 국이 완성되면 50조가 정한 국의 뿌리 손실을 반영한다. 그 뒤 **원국과 누적 운의 다른 유효 뿌리가 남는지 다시 계산**한다. 남은 유효 뿌리까지 없을 때 무근이다. 「충 한 번이면 모든 뿌리 삭제」로 일반화하지 않는다. 원국에서 이미 성립한 궁충과 오늘의 운 충을 같은 항목으로 덮어쓰지 않는다. [S6]

**표 3 · 궁이 먼저인가 글자가 먼저인가**

| 갈래 | 궁 / 글자 / 둘 다 |
|---|---|
| 관계(썸·연애·재회) | **둘 다 [제안].** 기존 대상 범위는 유지한다. 원국 궁 상태와 현재 관계 대상 글자의 작용을 각각 읽는다. |
| 배우자(결혼) | **둘 다 [제안].** 궁 상태와 배우자성의 작용을 모두 남긴다. 한쪽만으로 결혼 여부를 확정하지 않는다. |
| 이별 | **둘 다 [제안].** 관계 대상과 궁을 보되, 관계의 유지·끊김과 본인의 인성 상태는 섞지 않는다. |
| 가족(어머니·아버지·자식) | **둘 다 [제안].** 먼저 묻는 가족을 고른 뒤 해당 궁과 연결된 대상 글자의 작용을 읽는다. 서로 다른 가족의 결과를 하나로 합치지 않는다. |

**집계 방식은 수정 제안이다.** 현재의 「둘 다 1순위이므로 무조건 나쁜 쪽이 이긴다」 대신, **같은 대상·같은 층·같은 질문에 답하는 근거끼리만 비교**한다. 서로 다른 상태는 병기한다. 예를 들어 원국 궁충이 있다는 이유만으로 이후 모든 날의 생받음·구제됨을 지워 버리지 않는다. 원국의 조건과 오늘 생긴 변화는 따로 말한다.

이것은 고전에서 확정된 궁·글자의 절대 서열이 아니라, 현재 병렬 대상 구조를 유지하면서 무조건적인 최악값 선택을 줄이려는 **운영 제안**이다. 새로운 결론 키를 만들지 말고, 기존 근거별 결과를 보존한다. 코드를 바꿀 때는 현행 집계와 비교 시험을 남긴다. `docs/36`도 원문에 절대 우선순위가 정해져 있지 않다고 명시한다. [S4]

가족 궁의 기존 프로젝트 대응은 **아버지 월간·어머니 월지·자식 시지**다. 따라서 가족 전부를 월지 한 칸으로 처리하지 않는다. 과거에 삭제된 「궁이 사람, 글자가 모양」 규칙을 이번 표의 근거로 되살리지 않는다. [S4]

**[제안] 이 값은 46조의 지장간을 ‘대상’으로 올릴 때 쓰는 자리 무게 계수에만 한정한다.** 고전이 확정한 본기·중기·여기의 실제 세력 비율로 승인하는 것은 아니다. [S3, S6]

`대상으로 올린 지장간의 힘 = 기존 자리 무게 × 위 계수`

천간 통근 힘을 재는 1조의 산식 전체에 이 계수를 새로 곱하지 않는다. 코드가 이미 적용했다면 중복 적용하지 않는다. 이 표의 1 : 0.5 : 0.5는 개별 대상의 상대 가중치이며, 지지 전체를 100%로 나눈 지분표가 아니다. 임의로 정규화하거나 60 : 30 : 10 같은 새 비율로 교체하지 않는다. [제안]

또한 36조의 「제복에 못 미친 힘을 반만큼 깎는다」에 쓰이는 0.5와 **다른 설정**이다. 숫자가 같아도 근거와 적용 대상이 다르므로 하나의 상수로 묶지 않는다. [S6]

**표 5 · 지지끼리 우선순위**

**그대로 — 삼합 > 반합 > 육합 > 충. 한 지지는 하나의 경쟁하는 결합에만 쓴다. 더 우선하는 합이 지지를 가져가면 앞서 막힌 충이 다시 살아나는 기존 6조를 유지한다.** [기존 규칙, S6]

다만 **50조의 ‘완성된 국끼리의 충’은 별도 검사**다. 삼합이 우선이라는 이유로 이 검사를 통째로 건너뛰면 50조와 모순된다. 반합을 완성된 국으로 취급하지 않는다. 국이 있어도 명령할 천간이 합거되어 있으면, 뿌리로 남는 것과 십신 명령이 나오는 것을 41조대로 구분한다. [기존 규칙, S6]

#### 3-1 · 2026-10-19: 구조와 사건을 분리

프로젝트 명식은 `壬申 甲辰 丁卯 庚子`다. 법전 50조의 사례에서는 원국 申子辰과, 올해 午·이달 戌·오늘 寅으로 완성되는 寅午戌을 대조한다. **「이 구조의 시험 기대값이 壬 무근」이라고 기록된 것과 「실제로 직장 변동이 있었다」는 별개의 주장이다.** [S6]

이번 작성본은 전자를 문서에서 확인했을 뿐이다. 전체 대운·운의 뿌리·합거 상태를 넣어 실행한 결과는 없고, 미래 사건 기록도 없다. 실제 기록에는 사건이 없었던 경우도 그대로 남겨야 한다. 한 번의 사건 일치만으로 보편 규칙의 예측력이 검증됐다고 처리하지 않는다. [제안]

#### 3-2 · 2028: 33조 일반 극과 상관패인의 충돌을 푸는 법

《자평진전》 「논용신성패구응」에는 다음 조건이 있다. [S7]

> 「傷官佩印而傷官旺，印有根」
>
> 상관이 왕하고 인성에 뿌리가 있는 상관패인을 성격의 한 경우로 든다.

**해결은 ‘甲이 戊를 극하나’의 사실을 지우는 것이 아니라, 그 극이 해당 격에서 성격 작용인지 파격 작용인지를 구분하는 것이다.** 법전 44조도 극을 받는 글자의 역할에 따라 제복의 의미가 달라진다고 이미 정한다. [S6]

| IF | THEN — 이번 수정 제안 |
|---|---|
| 이번 층에서 상관격이 성립하고, 상관패인의 성격 조건을 갖추며, 필요한 인성이 실제로 작용하고, 그 구조를 깨는 미해결 조건이 없음 | **상관패인 성격.** 인극상관 하나를 33조의 일반 극으로 다시 세어 파격 처리하지 않는다. |
| 인성이 보이지만 합거·무근 등으로 실제 작용하지 못함 | **상관패인 성격 근거로 쓰지 않는다.** 남은 성격·파격·구응 조건을 다시 읽는다. 인성이 없다는 이유 하나만으로 자동 파격시키지도 않는다. |
| 패인 구조에 필요한 인성이 재성에게 손상되고, 그 손상을 막는 구응이 없음 | 패인 구조의 손상을 검사한다. 재극인이 실제로 닿는지와 구응 유무를 남겨, 파격 여부를 낸다. |
| 상관이 약하고 일간이 왕하여 패인이 오히려 필요한 상관 작용을 막는 경우 | 상관패인이라는 이름만 보고 성격으로 처리하지 않는다. 격표의 패 조건을 검사한다. |
| 상관왕·인유근·인성의 유효 작용 등을 판정할 근거가 모자람 | **규칙 보완 필요.** 조건을 새 숫자로 만들어 2028년의 성격·파격을 강제로 고르지 않는다. |

위 성패 조건의 원문 근거는 [S7], 실제 힘·합거·통관 계산은 책사의 기존 규칙 [S6]을 따른다. 둘을 연결하는 **갈림표 자체는 이번 제안**이다.

**처리 순서 제안:** 이번 층의 격 확정 → 그 격에 맞는 성격·패격 조건 확인 → 손상과 구응 확인 → 남은 결과 확정. 일반 「격신을 극하면 파격」은 격별 성격 작용을 오판하지 않도록 적용 범위를 제한한다.

2028년이라는 이름만으로 1년 전체를 확정하지 않는다. 각 층에서 甲이 실제로 살아 있는지, 庚이 甲을 치는지, 그것을 막는 글자가 있는지, 합으로 바뀌는지를 함께 출력해야 한다. **「상관격으로 변격되었다」와 「그 상관격이 성격이다」는 서로 다른 판정 단계**다. 기존 35·39·40·42조와 충돌 여부를 함께 시험한다. [S6]

#### 3-3 · 2029: 책사 규칙의 답과 고전 검증의 답을 분리

**책사 43조의 답은 ‘조건을 만족하는 합 쌍이면 맞다’이다.** [S6]

| 조건 | 43조에 따른 처리 |
|---|---|
| 甲·己가 실제 합의 짝으로 선택됨 + 이달 지지 ∈ {丑, 辰, 未, 戌} | 그 층에서 甲이 土로 화한다. 화한 합을 동시에 합거로도 처리하지 않는다. |
| 합의 짝은 성립하지만 이달 지지의 오행이 土가 아님 | 기존 43조대로 합이불화, 합거로 처리한다. |
| 다른 운의 甲이 먼저 己와 합해 원국 甲은 짝으로 선택되지 않음 | 선택되지 않은 원국 甲까지 일괄 화하거나 합거하지 않는다. 28·37조의 짝 선택부터 따른다. |
| 원국 안의 합을 판정함 | 43조가 정한 원국 월지 기준을 쓴다. 운의 이달 기준과 섞지 않는다. |

여기서 월은 민간 달력의 1·4·7·10월이라는 뜻이 아니라, 엔진의 **절기 기준 丑·辰·未·戌월**이다. 원본 명식의 甲을 영구적으로 삭제하거나 출생 천간을 바꾸지 말고, 해당 층에서 화한 작용과 그 근거를 별도 보존한다. [제안]

고전의 합화·진화·가화 논의는 이보다 복잡하다. 《적천수천미》 「가화」는 甲己합을 논하면서 辰·未의 목근, 丑·戌의 한습, 다른 글자의 도움 등을 구별한다. 따라서 **「토월이면 무조건 완전한 합화」를 고전 일반 명제로 광고해서는 안 된다.** 이 고전 대조는 43조가 간소화 규칙임을 밝히기 위한 것이며, 종격·외격·화기격 엔진을 새로 추가하자는 뜻은 아니다. [S8]

#### 3-4 · 2023: 기억은 판정으로 만들어 내지 않음

답: **미확인 — 본인의 사실 기록 없음.** 직장·돈·연애·건강에서 무슨 일이 있었다고 추정해 채우지 않는다. 차후 사실이 들어오면 「시기 / 실제 사건 / 확인 가능한 근거 / 변화가 없었던 부분」으로 기록하고, 기존에 고정한 판정과 대조한다. 판정에 맞추어 기억을 선택하거나 다시 쓰지 않는다. [제안]

## 결과 뜻 (격자 채울 때)

아래는 첨부 원문의 정의를 그대로 보존한다. [S1]

- 무근: 그 글자가 이름만 있고 뿌리가 없다
- 극 통관: 치는 글자가 있는데 사이 글자가 받아 넘겨 안 다친다
- 극 제복: 치는 글자를 다른 글자가 잡아 준다
- 극 힘차이: 치는 글자가 두 배 넘게 약해 못 친다
- 생받음: 운 글자가 그 글자를 생한다
- 극없음: 아무도 건드리지 않는다
- 궁충: 그 자리가 원국에서 충이다
- 기신 방치: 격신을 치는 글자를 아무도 안 잡는다

**경계값 점검:** 첨부의 「두 배 넘게」와 법전 36조의 「맞는 쪽이 치는 쪽의 두 배 이상」은 정확히 2배일 때 차이가 난다. 이 작성본에서 원문을 몰래 고치지는 않았다. 구현 점검은 현재 36조의 **이상(≥)** 조건을 기준으로 하고, 실제 코드와 용어집이 일치하는지 따로 확인한다. [S1, S6]
