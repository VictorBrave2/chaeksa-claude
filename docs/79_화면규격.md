# 화면 규격 (2026-10-01 다시 씀)

지금 규격 한 장. 바뀌면 덧붙이지 말고 이 문서를 고쳐 쓴다. 화면 에이전트(`.claude/agents/chaeksa-screen.md`)는 이 문서만 가리킨다.

## 1. 홈 = 분류 칸 (`app/home-cats.js`)
- 홈은 분류 칸을 위에서 아래로 한 줄씩. 분류 이름 · 차례는 `bunya.js` 큰분야 표, 연애가 맨 앞.
- 칸 하나 = 그림 한 장 + 그림 안 글씨(만화 표지처럼: 위 분류 딱지, 아래 콘텐츠 이름).
- **칸 높이 = 그림 원본 비율**(자르지 않음). 그림은 **원본** 그대로 — 줄인 그림(`-s`) 안 씀.
- 콘텐츠가 없는 분류는 「준비중」 칸. 새 콘텐츠는 `home-cats.js` 칸 표에 한 줄.

## 3. 탭 뼈대 (코드가 보장 — `app.js` 홈길())
```
[← 홈]          맨 위 — 홈이 아닌 탭 전부, go(tab) 이 자동으로 넣는다
표지(그림 + 이름)  이름은 표지에 한 번만. 바로 밑 카드에 같은 이름 h2 를 되풀이하지 않는다
설명 카드 + (사람 고르기)
본문
[← 홈]          맨 아래
```
- 결과 전 표지 = 이름 + 작은 부제 한 줄. 결과가 나오면 표지 = 해독 결과 첫 줄(부제는 걷음).

## 4. 유료 콘텐츠 꼴 (`love.js` · `pair.js`)
1. 표지
2. 해독 결과(이런 사람이다 · 이런 짝이다) — 맨 위
3. 장 — 장마다 그림 머리, 바탕은 장에서 장으로 이어지는 띠(`ChaeksaLoveView.띠`)
4. 항목 = **문장 제목 + 풀이**(문답 꼴 아님)
5. 결과 화면에 반응 단추(맞아요 · 아니에요 등)는 두지 않는다(10-02 사장님).
- 무료 = 해독 결과 첫 줄 + 1장 전부. 잠금 상자는 **1장 끝**에 하나.
- 맨 끝 = 다음 콘텐츠로 가는 단추(예: 사랑할 때만 나오는 당신 → 그 사람 사용설명서).

## 5. 사람 고르기 = 칩 (`app.js` 사람칩 · `window.책사사람칩`)
- select 는 숨기고(`ss-sel-hidden`) 사람 칩(`.ss-who`)으로. 정통궁합 · 웹툰궁합 · 그 사람 사용설명서가 같은 함수를 쓴다.
- 칩 끝 「＋ 다른 사람」이 사람 폼을 연다. 따로 「+ 사람 추가」 단추를 두지 않는다.
- 아직 아무도 없으면 칩 대신 가로 꽉 찬 단추 하나 「그 사람 생년월일 넣기」.

## 6. 이름 · 단추 · 잠금 말
- 다른 세계 말결: **봉인 · 해독 · 연산**. 예) 잠긴 글 = 「아직 봉인된 글 N개」, 결론 = 「해독 결과」, 기다림 = 「여덟 글자를 해독하는 중」.
- 「맛보기」 쓰지 않는다 → 「먼저 풀린 봉인 · 먼저 풀린 장면」.
- 결제 단추 = **값 + 결제**: 「출시 기념가 9,900원 결제하고 봉인 풀기」. 값은 상품표(pay.js)에서 받아 적는다.
- 결제 상자 머리 목록 = 「결제하면 풀리는 것」.
- 네 축 이름(…실단)은 화면에 안 낸다.

## 6-1. 글자 · 모서리 · 머리줄 (10-02 개편 3묶음)
- 글자 크기는 `style.css` :root 의 계단 이름만 쓴다 — `--t1` 12 · `--t2` 14 · `--t3` 16(본문) · `--t4` 18 · `--t5` 22 · `--t6` 28. `--t7` 36 은 명식 한자 · 큰 숫자 그림만. **12px 아래는 없다.** 새 규칙 · JS 안 style · 바깥 쪽 HTML 에 `font-size:13px` 처럼 픽셀을 새로 적지 않는다.
- 모서리는 `--r1` 8(딱지 · 칸) · `--r2` 14(카드 · 그림) · `--r3` 알약 셋만. 동그라미는 50%.
- 홈 그림 칸(.cat)과 연애 · 사용설명서 표지(.lv-cover)는 표지 글씨 부품 하나(딱지 .k · 제목 .n · 아래 어두운 띠)를 같이 쓴다. 큰 표지는 여백 · 제목 크기 · 띠 높이만 다르다.
- index.html 밖의 쪽(택일 안내 · 글 · 값 안내 · 약관 · 404)은 `<body>` 바로 밑에 머리줄 한 줄 — `<div class="mini-head" role="banner">` 策 로고 + 「← 홈」(404 는 주소를 / 로). 정본 글은 tools_jeongbon.py 틀이 넣는다. 결제 돌아온 쪽(pay-done · pay-fail)은 결제 확인 중 나가지 않게 머리줄을 달지 않는다.
- 홈으로 가는 글은 어디서나 「← 홈」 하나(전에는 ← 책사 · ← 책사 홈 · ← 책사로 돌아가기 · ← 처음으로 · 책사 처음으로). 「← 출산택일 안내」처럼 윗장으로 가는 길은 그대로 둔다.
