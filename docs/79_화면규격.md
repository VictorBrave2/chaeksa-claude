# 화면 규격 (2026-09-25)

사장님 「뼈대를 규격화 하고 에이전트를 만들어야 할까?」 → 규격은 **문서 한 장 + 코드가 보장 + 검사기**로 지킨다. 에이전트는 새로 만들지 않고 화면 에이전트(`.claude/agents/chaeksa-screen.md`)가 이 규격을 따른다.

## 1. 뼈대 (docs/78)
- 콘텐츠 넷 · 이름 넷: **정통사주 · 정통궁합 · 웹툰궁합 · 출산택일**. 다른 이름을 화면에 내지 않는다.
- 층 셋: 첫 화면(컷씬 + 버튼 셋) → 앱(홈 + 탭 셋) → 바깥 글(출산택일 허브 · 왜 · 신살).
- 입구 하나: 첫 만남(내 프로필) → 그 사람 → 탭. 보기 전에 로그인 · 내 정보를 요구하지 않는다.

## 2. 탭 한 장의 규격 (코드가 보장 — app.js 홈길())
```
[← 홈]                      ← 맨 위, 홈이 아닌 탭 전부
제목 카드(이름 넷 중 하나 + 쉬운 한 줄, 사주 말 없음)
(그 사람 고르기 — 칩, 궁합 둘만)
[시작 단추 — 궁합 둘만]
본문
[← 홈]                      ← 맨 아래
```
- 위아래 「← 홈」은 `go(tab)` 이 자동으로 넣는다. 탭 HTML 에 손으로 안 넣어도 된다(있으면 그것을 쓴다).
- 아래 줄 단추 넷(홈 · 정통사주 · 정통궁합 · 웹툰궁합)은 늘 보인다.

## 3. 입력 폼의 규격
- 웹툰식: 컷 그림 + 책사 말풍선 + 입력. 성별을 고르면 컷이 바뀐다.
- 처음 보이는 칸: 이름 · 생년월일 · 성별. 시각 · 곳은 접는다(「＋ 펼치기」 점선 상자). 시각 기본은 「모름」.
- 출산 예정 · 성별 모름 같은 옛 칸은 안 낸다.

## 4. 고르기의 규격
- 사람 · 단계는 select 가 아니라 칩 · 카드로. select 는 숨겨 두고 값만 쓴다(`ss-sel-hidden`).
- 사람 고르기 판에는 줄마다 고치기 · 지우기(마지막 한 사람은 못 지움).

## 5. 검사 (배포 전)
- `python tools_check.py` 막힘 0.
- 폰(375px)에서: 첫 화면 → 탭 셋 끝까지, 「← 홈」 위아래로 돌아오기.
- 새 JS 는 tools_bust FILES, 새 페이지는 PAGES.

## 6. 바꾸는 법
규격이 바뀌면 이 문서를 **고쳐 쓰고**(덧붙이지 않음), 코드가 보장하는 것은 app.js 홈길() 같은 한 곳을 고친다. 화면 에이전트 파일은 이 문서를 가리키기만 한다.
