# 궁극의 책사 — 개인 명리비서 사업 기획서

작성일: 2026-08-24 · 버전 0.1

---

## 1. 한 줄 정의

**"내 사주를 완전히 아는 비서가 매일 아침 오늘을 브리핑해주고, 언제든 물어보면 내 사주 기준으로 답해준다."**

사주 풀이 사이트가 아니다. *풀이*는 한 번 보고 끝나지만, *비서*는 매일 쓴다. 매일 쓰는 것만이 구독이 되고, 구독만이 지속가능한 사업이 된다.

---

## 2. 왜 지금, 왜 이것인가

| 기존 시장 | 문제 | 책사의 답 |
|---|---|---|
| 무료 운세 앱 | 생일만 보고 띠·별자리 수준. 누구에게나 같은 말 | 생년월일**시** 기반 사주 원국 + 대운·세운·일운을 실제로 계산 |
| 사주 풀이 사이트 | 한 번 보면 끝. 재방문 이유 없음 | 매일 달라지는 일운 브리핑 → 매일 올 이유 |
| 오프라인 철학관 | 비싸고, 한 번 가면 끝, 겁주는 경우 많음 | 월 커피 두 잔 값, 24시간, 겁주지 않고 "그래서 오늘 뭘 하면 되는지" |
| ChatGPT에 사주 물어보기 | 만세력 계산을 틀리고, 원국을 기억 못 함 | 계산은 엔진이 정확히, 해석은 AI가 내 원국을 항상 기억한 채로 |

**핵심 차별점**: *정확한 계산 엔진* × *내 원국을 기억하는 AI* × *매일의 습관*.

---

## 3. 제품 구조

### 3.1 비서가 하는 일 (기능 우선순위 순)

1. **오늘 브리핑** (매일 아침) — 오늘의 일진이 내 원국과 어떻게 만나는지. 좋은 시간대, 조심할 일, 추천 행동 1가지. *3문장 이내.*
2. **물어보기** (채팅) — "이번 주 면접 괜찮아?", "이 사람이랑 잘 맞아?" → 내 사주 기준 답변.
3. **택일** — 이사·계약·개업·여행 등 날짜 후보를 주면 순위 매김. 달력에서 한 달 단위로 좋은 날 표시.
4. **이달의 흐름 / 올해의 흐름** — 월운·세운 요약.
5. **나의 원국 카드** — 일간 중심으로 "나는 어떤 사람인가" 한 장. (첫 가입 시 감동 포인트, 공유 유도)
6. **궁합** — 상대 생년월일시 입력 → 관계 브리핑.
7. **알림** — 아침 브리핑 푸시, 중요한 날 전날 알림.

### 3.2 원칙 (브랜드 톤)

- **겁주지 않는다.** "올해 삼재" 같은 말 대신 "올해는 새 일 벌이기보다 정리하는 해. 대신 ○○는 좋음."
- **행동으로 끝낸다.** 모든 답은 "그래서 뭘 하면 되는지"로 마무리.
- **솔직하다.** 안 좋은 흐름도 숨기지 않되 대처법과 함께.
- **짧다.** 비서는 보고서를 읽어주지 않는다.

## 4. 기술 구조

```
[사용자] ── 웹/앱 (PWA) ──┐
                          │
          ┌───────────────┴────────────────┐
          │  만세력 엔진 (순수 계산, JS)       │  ← 생년월일시 → 원국·대운·세운·월운·일운
          │  · 절기 기준 월주, 진태양시 보정     │    100% 결정론적, AI 안 씀
          └───────────────┬────────────────┘
                          │ 계산 결과(구조화 데이터)
          ┌───────────────┴────────────────┐
          │  해석 레이어 (Claude API)          │  ← 원국 + 오늘 일진 + 명리 규칙 프롬프트
          │  · 시스템 프롬프트에 책사 톤·원칙    │    → 브리핑/답변 생성
          └───────────────┬────────────────┘
                          │
          ┌───────────────┴────────────────┐
          │  저장소 (Supabase)                │  ← 회원, 원국, 대화 기록, 구독 상태
          └────────────────────────────────┘
```

**단계별 기술 선택**
- 0단계(지금): 단일 HTML 파일. 설치 없음. 엔진 + 화면 검증.
- 1단계: 정적 호스팅(Vercel/Cloudflare) + 서버리스 함수로 Claude API 호출. 회원/결제는 Supabase + 토스페이먼츠(국내) / Stripe(해외).
- 2단계: PWA → 홈화면 설치, 푸시 알림. 이후 Capacitor로 앱스토어/플레이스토어 출시 (코드 재사용 90%+).

## 5. 수익 모델

| 등급 | 가격 | 포함 |
|---|---|---|
| 무료 | 0원 | 원국 카드, 오늘 브리핑 1줄, 질문 하루 3개 |
| 비서 구독 | 월 9,900원 / 연 79,000원 | 전체 브리핑, 무제한 질문, 택일, 월운·세운, 알림 |
| 단건 리포트 | 19,000~39,000원 | 평생 운 리포트, 궁합 리포트, 연간 리포트 (PDF) |

**단위 경제**: 구독자 1인당 AI 비용 월 약 500~1,500원 예상 (브리핑 1일 1회 + 질문 평균 10회). 마진 80%+.
**손익분기**: 구독자 300명 ≈ 월 300만 원 (서버·API·결제수수료 차감 후 약 220만 원).
**1차 목표**: 출시 6개월 내 유료 구독 1,000명 (월 약 1,000만 원).

## 6. 고객 확보 전략

1. **원국 카드 공유** — 첫 가입 시 나오는 "나는 ○○한 사람" 카드를 인스타/카톡 공유 → 무료 유입.
2. **매일 브리핑 숏폼** — "오늘 ○○일간인 사람은…" 하루 1개 콘텐츠. 앱 유입 링크.
3. **연초·연말 시즌** — "2027년 내 운세" 리포트로 시즌 매출.
4. **커뮤니티/카페 무료 체험** — 명리 커뮤니티에 정확한 만세력 계산기로 먼저 신뢰 확보.
5. 글로벌은 2단계: 영어 UI + 출생 시간대 자동 보정. 한국계·중화권·동남아 순.

## 7. 로드맵

| 단계 | 기간 | 산출물 | 완료 기준 |
|---|---|---|---|
| **0. 프로토타입** | 1~2주 | 만세력 엔진 + 원국 카드 + 오늘 브리핑 화면 (단일 HTML) | 생년월일시 넣으면 정확한 원국·대운·오늘 일진이 나옴 |
| **1. 베타 웹** | 4~6주 | AI 브리핑·질문, 회원가입, 50명 비공개 베타 | 베타 사용자 중 절반이 7일 연속 방문 |
| **2. 유료 출시** | 8~10주 | 구독 결제, 택일, 월운·세운, PWA 알림 | 유료 전환율 5%+ |
| **3. 앱 출시** | 12~16주 | iOS/Android 스토어 | 스토어 평점 4.5+ |
| **4. 확장** | 6개월~ | 궁합, 리포트 상품, 영어판 | 월 매출 1,000만 원 |

## 8. 위험과 대응

| 위험 | 대응 |
|---|---|
| 만세력 계산 오류 → 신뢰 붕괴 | 공개 만세력과 교차 검증 자동 테스트 100건 이상. 절기 시각 데이터 정밀 사용. |
| AI가 엉뚱한 소리 | 계산은 AI가 절대 안 함. 해석 프롬프트에 명리 규칙 고정. 출력 길이 제한. |
| AI 비용 폭증 | 무료 사용자 질문 수 제한, 브리핑은 하루 1회 캐시. |
| 미신·사행성 인식 | "겁주지 않는다" 원칙, 결정은 사용자가 한다는 문구. 의료·투자 질문은 답하지 않음. |
| 개인정보(생년월일시) | 암호화 저장, 최소 수집, 탈퇴 시 즉시 삭제. |
