## 0. 한 줄로

- **원국 단계만으로는 대업을 가르지 못했다.** 44명: 넷 5 · 셋 23 · 둘 10 · 하나 6. 67,344명(1950~2010) 분포(넷 12.3% · 셋 46.9% · 둘 33.3% · 하나 7.6%)와 거의 같다. 하나에 무하마드 알리 · 마이클 조던 · 도쿠가와 이에야스 · 왕양명이 있다.
- **대업 해에 빠진 무리가 오는 것도 우연 수준이다.** 날짜 있는 33명의 대표 대업 해에 대운 · 세운 천간으로 빠진 무리가 온 사람 23명. 같은 사람들의 15~75세 모든 해로 잰 기대값 24.4명(±2.3).
- **넷 가진 사람이 빠진 무리를 받고, 판정엔진으로 봐도 가진 넷이 합에 안 묶여 다섯이 된 대업 해는 정조 1776년 즉위 하나뿐이다.** 합을 안 보는 70조 글자 그대로라면 나쓰메 소세키 1905년도 맞는다(엔진은 소세키 원국 丁壬을 이미 합화로 본다). 넷 가진 사람에게 빠진 무리 천간이 오면, 그 천간의 합 짝은 반드시 이미 가진 무리 안에 있다(8-5). 그래서 「합거로 깨지지 않음」이 넷 가진 사람에게 늘 걸리는 조건이 된다.

## 1. 70조 요지와 셈법

**70조 요지(docs/19)** — 그릇 = 천간 네 글자(일간 포함, 일간은 비겁)를 십성 다섯 무리(비겁 · 식상 · 재성 · 관성 · 인성)로 바꿔 **지지에 뿌리가 있는 것만** 센 무리 수. 원국은 하나 · 둘 · 셋 · 넷(뿌리 있는 천간이 하나도 없으면 하나). **다섯째는 원국이 아니라 때** — 넷을 가진 사람이 운에서 빠진 한 무리를 받아 다 갖춘 때가 대업을 이루는 때. 아직 안 넓힌 것: 다섯째 글자가 대운만인지 세운도인지 · 뿌리가 있어야 하는지 · 그때 가진 넷이 합거 · 극으로 깨지지 않아야 하는지 · 운이 낮은 단계도 올리는지.

**셈법(이 문서가 쓴 법)**

| 무엇 | 어떻게 |
|---|---|
| 무리 | 일간 오행 기준. 같음 = 비겁, 일간이 낳음 = 식상, 일간이 극함 = 재성, 일간을 극함 = 관성, 일간을 낳음 = 인성 |
| 뿌리 | `ChaeksaGise.기세(R).칸[오행].하늘` 에 그 천간이 있으면 뿌리 있음(지장간에 같은 오행이 있고 힘 > 0, 남의 오행 삼합국에 든 지지는 뿌리로 안 침). `기세` 는 `R.pillars` 만 읽는다 |
| 원국 단계 | 뿌리 있는 천간의 무리 수. 0이면 하나 |
| 대운 | 엔진 대운 줄(`R.daeun.list`). 시작 나이는 반올림 없이 「절입까지 날수 ÷ 3」년. 대업 날짜의 만 나이로 몇째 대운인지 잡았다. 엔진 화면 규칙(세는 나이 · 시작 나이 반올림)으로 대운이 달라지는 사람은 표에 적었다 — 판정(아래 「빠진 무리가 왔나」)이 바뀐 사람은 없다 |
| 세운 | 대업 날짜의 연주(입춘 기준, `dateFortune`). 해만 있는 대업은 7월 1일로 셈 |
| 빠진 무리가 왔나 | 대운 천간 · 세운 천간의 무리가 빠진 무리인가 → 대운만 / 세운만 / 둘 다 / 아님. 온 글자가 뿌리 있는지 · 합에 묶였는지는 따로 적었다 |
| 넷이 온전했나 | `ChaeksaPanjeong.판정(R, 그해 7월 1일, {운들:[대운, 세운]})` 의 끝 층을 원국 층과 견주어, 원국에서 뿌리 있던 천간(일간 빼고)에 **합거 · 합화(오행이 바뀜) · 뿌리 잃음**이 새로 생겼나 |
| 그때 무리 수 (가) | 70조 글자 그대로 — 원국 천간 넷 + 대운 · 세운 천간 둘 가운데 뿌리 있는 것(원국 지지 + 운 지지로, 위와 같은 뿌리 법)의 무리 수. 합 · 화는 안 본다. 원국에서 뜬 천간이 운 지지로 뿌리를 얻으면 센다 |
| 그때 무리 수 (나) | 판정엔진 층 — 위 끝 층에서 합거된 천간은 빼고, 합화한 천간은 화한 오행으로 센다. 뿌리 법은 같다 |
| 시각 경계 | 엔진 진태양시가 시진 경계에서 20분 안이면, 넘어간 쪽 네 기둥과 단계도 쟀다. 하루 앞뒤로 월주가 바뀌는 사람(절기 경계)은 없었다 |

표의 「그때 무리」는 `(가)/(나)` 로 적는다. 5가 다섯 무리를 다 갖춘 것이다.

## 8. 눈에 띄는 것 — **짐작이다, 사장님 판정 전**

**8-1. 원국 단계가 대업을 가르지 않는다.** 44명의 분포가 67,344명과 거의 같고, 하나(최하)가 오히려 조금 많다(13.6% 대 7.6%, 여섯 명). 짐작: 70조의 단계는 「두 사람이 어울리나」를 재는 셈이지 「얼마나 크게 이루나」를 재는 셈은 아닐 수 있다. 또는 뿌리를 「지장간에 같은 오행」으로만 잡는 법이 일간이 뜬 사람(조던 · 이에야스 · 何知章 · 파스퇴르 · 쑨원)을 낮게 넣는다.

**8-2. 빠진 무리가 오는 것만으로는 못 가른다.** 23명 대 기대 24.4명. 09-23 탐침(넷 가진 사람 100%가 80세 안에 대운으로 빠진 무리를 받는다)과 같은 쪽이다. 짐작: 70조 다섯째를 가를 조건은 「오느냐」가 아니라 그 밖의 것(합에 안 묶임 · 뿌리 · 대운과 세운이 겹침 · 나이)에 있다.

**8-3. 대운만 · 세운만 · 둘 다가 고르게 나뉜다.** 6 · 7 · 10. 세운만으로 받은 대업이 대운만보다 적지 않다(플레밍 1928 · 암스트롱 1969 · 정조 1776). 짐작: 다섯째를 대운으로만 한정하면 정조 · 이소룡처럼 대운이 오기 전에 이룬 사람을 놓친다.

**8-4. 넷 아닌 사람도 운 두 겹으로 다섯에 닿는다.** (나) 셈으로 다섯이 된 대업 해 셋 가운데 둘이 넷 아닌 사람이다 — 아인슈타인 1921(셋 → 재성 · 관성이 한 해에 같이 옴), 김구 1940(둘 → 식상 · 재성이 오고 뜬 甲이 뿌리를 얻음). 70조 「아직 안 넓힘」의 「운이 낮은 단계도 올리나」의 표본이다.

**8-5. 합 짝 산수(짐작 아님, 셈이다).** 넷 가진 사람에게 빠진 무리는 하나이고 그 무리 천간은 양 · 음 둘이다. 양간의 합 짝은 그 양간이 극하는 무리의 음간이고, 음간의 합 짝은 그 음간을 극하는 무리의 양간이다(戊→癸, 丁→壬). 두 무리 다 넷 가진 사람이 이미 가진 무리다. 그러니 **그 짝 글자가 원국에 있으면 빠진 무리가 와도 원국 하나가 합거된다.**

| 이름 | 빠진 무리가 이 글자로 오면 | 짝 | 원국에 짝이 있나 |
|---|---|---|---|
| 이소룡(甲) | 壬 / 癸 | 丁 / 戊 | 있음(월간 丁) / 있음(시간 戊) — **어느 글자로 와도 묶인다** |
| 정조(己) | 丙 / 丁 | 辛 / 壬 | 없음(원국은 庚) / 있음(연간 壬) — 丙으로 올 때만 온전 |
| 소세키(庚) | 戊 / 己 | 癸 / 甲 | 없음 / 있음(시간 甲) — 戊로 올 때만 온전 |
| 게이츠(壬) | 戊 / 己 | 癸 / 甲 | 없음 / 없음 — 어느 글자로 와도 온전 |
| 董丞相(乙) | 壬 / 癸 | 丁 / 戊 | 있음(시간 丁) / 없음(원국은 己) |

짐작: 70조의 「그때 가진 넷이 합거로 깨지지 않아야 하나」를 정하면, 넷 가진 사람마다 다섯째가 될 수 있는 글자가 원국만 보고 미리 정해진다.

**8-6. (가) 셈과 판정엔진 셈이 갈리는 곳.** 70조는 `gise` 뿌리로 천간을 세고 합 · 화를 안 본다. 판정엔진은 원국 연간 · 월간 합부터 본다.
- 소세키 — 원국 丁(연간) · 壬(월간)이 계절(寅, 목)을 얻어 **원국부터 합화 목**. 70조로는 넷(관성 · 식상 · 비겁 · 재성), 엔진으로는 둘(재성 · 비겁). 1905년에 (가) 다섯, (나) 셋.
- 元丞相 — 원국 壬 · 丁이 합화 못 하고(계절 未) **원국부터 합거**. 70조로는 셋, 엔진으로는 하나.
- 뿌리 법도 둘이다. `gise` 는 지장간에 같은 오행이 있어야 뿌리로 치고, `saenggeuk` 의 「산다」는 12운성 힘 0.5 이상이면 산다. 드골의 庚 · 파스퇴르 1885 세운 乙 · 알리 1974 대운 戊는 `gise` 로 뿌리 없음, `saenggeuk` 로 산다. 이 문서는 70조 대로 `gise` 쪽으로 셌다.
- 삼합국에 든 지지는 남의 오행이면 뿌리가 못 된다. 오바마의 癸(丑이 巳酉丑 금국에 듦)가 이래서 뜬다.

**8-7. 오른 운과 떨어진 운을 원문이 함께 적은 명례 — 빠진 무리의 도착이 오름 · 떨어짐을 가르지 않는다.**
- 傷官 庚辰生: 진사(壬午) · 封疆(癸未)에는 안 왔고, **落職(乙酉)에 왔다**. 그때 뜬 庚 둘이 酉로 뿌리를 얻어 무리 수(가)도 평생 가장 많다.
- 元丞相: 台輔(庚戌)와 독살(辛亥)이 같은 판정(둘 다 식상이 뿌리 있게 옴).
- 何知章 尚書: 원문은 己未 운에 인성이 **지지 국으로** 서고 식상이 천간에 떠서 尚書가 됐다고 적는다. 70조(천간만)는 지지 국을 못 센다. 오히려 亥卯未 목국이 서면서 亥에 뿌리 두던 원국 癸 둘이 뿌리를 잃어 (가) 0이 된다. 짐작: 무리를 천간으로만 셀지, 운에서 선 국(방 · 삼합)도 셀지를 정해야 이 명례와 맞출 수 있다.

**8-8. 대업 해에 가진 넷이 합으로 깨진 사람이 적지 않다.** 대표 해 33건 중 13건에서 원국의 뿌리 있던 천간이 새로 합거 · 합화됐다(아인슈타인 · 워싱턴 · 처칠 · 루스벨트 · 드골 · 다 빈치 · 피카소 · 괴테 · 마오쩌둥 · 쑨원 · 강희제 · 방봉시 · 철보). 마오쩌둥 1949는 인성 甲 둘이 모두 묶였다. 짐작: 「넷이 온전해야 다섯」을 조건으로 두면 대업 해 여럿이 빠진다 — 이 조건은 넷 가진 사람에게만 걸지, 모두에게 걸지 정해야 한다.

## 9. 여쭐 것

1. 일간이 뿌리 없으면 비겁 무리를 안 세는 것이 맞나(조던 · 이에야스 · 何知章 · 파스퇴르 · 쑨원).
2. 원국에서 이미 합화 · 합거된 천간(소세키 丁壬 · 元丞相 壬丁)을 70조 넷에 그대로 세나.
3. 빠진 무리가 운의 지지 국으로 오면(何知章 己未) 받은 것으로 치나.
4. 다섯째를 대운만으로 보나, 세운도 보나(이 표본: 대운만 6 · 세운만 7 · 둘 다 10).
5. 셋 · 둘 가진 사람이 운 두 겹으로 다섯에 닿는 때(아인슈타인 1921 · 김구 1940)를 무엇으로 부르나.
6. 대업 해를 「시작한 해」로 잡나 「이룬 해」로 잡나. 이 문서는 사람마다 두세 해를 넣고, 대표 해는 계산 전에 정했다.

## 부록 B. 계산 방법(다시 돌릴 때)

- 날짜 있는 사람: `ChaeksaEngine.calc({year, month, day, hour, minute, gender, longitude, tzOffset})`. `tzOffset` 은 시간 단위 숫자. 표준시 이전은 지방평균시(경도 ÷ 15)로 넣었다(예: 아인슈타인 +0.6667, 워싱턴 −5.1278). 1582년 이전은 그레고리 소급 날짜.
- 받은 목록의 네 기둥과 엔진 네 기둥이 33명 모두 같았다.
- 간지만 있는 명례: 1504~2099년에서 같은 네 기둥이 나오는 날을 찾아 `R` 을 빌렸다(대운 시기는 안 씀).
- 무리 셈(핵심):

```js
const 무리of = (ds, st) => ((E.STEM_ELEM[st] - E.STEM_ELEM[ds]) % 5 + 5) % 5;  // 0 비겁 1 식상 2 재성 3 관성 4 인성
const g = ChaeksaGise.기세(R), 가진 = new Set();
['year','month','day','hour'].forEach(k => {
  const st = R.pillars[k].stem, o = E.STEM_ELEM[st];
  if (g.칸[o].하늘.some(h => h.자리 === k)) 가진.add(무리of(R.pillars.day.stem, st));
});
const 단계 = Math.max(1, 가진.size);
```

- 운 층의 뿌리: 원국 지지(엔진 무게 `NATAL_WEIGHT`) + 운 지지(1.0)를 합쳐 `gise` 와 같은 법(같은 오행 지장간 + `E.stemPower > 0`, 남의 오행 삼합국에 든 지지 뺌)으로 다시 쟀다.
- 층: `ChaeksaPanjeong.판정(R, new Date(해, 6, 1), { 운들: [{stem, branch, name:'대운'}, {stem, branch, name:'세운'}] })` 의 `층들[0]`(원국)과 마지막 층의 `표.글자` 를 `key` 로 맞춰 합거 · 화 · 힘을 읽었다. 이달 층을 안 얹었으니 합화 계절은 원국 월지다.
- 우연 기대값: 날짜 있는 33명마다 15~75세 해(7월 1일)를 모두 같은 법으로 재서 「빠진 무리가 온 해」의 몫을 구해 더했다.
