# GEO 전략 — AI 답변에 우리가 인용되게 (2026-09-15 사장님 「GEO가 무엇이고 우리 사업에 적용할 전략」)

## 하나 · GEO가 무엇인가

SEO는 검색 결과 목록에서 위에 뜨는 것이다. **GEO(Generative Engine Optimization)는 AI가 답을 지어 말할 때 그 답의 재료로 우리 글이 뽑히는 것**이다.
ChatGPT·퍼플렉시티·구글 AI 개요·네이버 AI 브리핑이 「왜 2026년이 병오년인가요」에 답할 때, 답 속에 「chaeksa.kr에 따르면…」이 들어가거나 출처 카드에 우리가 뜨는 것.

둘의 차이가 전략의 전부다.
- SEO는 **클릭**을 다툰다. GEO는 **인용**을 다툰다. 클릭이 없어도 이름이 불린다.
- SEO는 키워드 밀도를 본다. GEO는 **문장 하나가 그대로 옮겨 쓸 만한가**를 본다.
- SEO는 백링크를 본다. GEO는 **같은 사실이 여러 곳에서 같은 말로 반복되는가**(엔티티 일관성)를 본다.
- SEO는 한 페이지가 한 검색어를 잡는다. GEO는 **질문 하나에 답 하나**가 잡는다.

AI 엔진이 재료를 고르는 기준(공개된 연구·각 사 문서에서 반복되는 것): 답이 앞에 있는가 · 숫자·날짜·고유명사가 있는가 · 출처를 댔는가 · 최근 갱신됐는가 · 저자·조직이 분명한가 · 여러 곳에서 같은 주장이 확인되는가 · 크롤러가 읽을 수 있는가.

## 둘 · 우리가 이미 맞는 것

- **제목이 질문, 첫 줄이 답**(feedback-why-first-titles). GEO의 기본 꼴이다.
- **「이 글의 답 세 줄」 상자.** AI가 집어 가기 좋은 단위(한 문장씩, 숫자 포함).
- **고유한 숫자.** 「창원 26분」 「360개」 「132 → 10」 「4,722년」. 남이 안 쓰는 숫자는 출처가 우리로 잡힌다.
- **판본을 댄다.** 자평진전(심효첨)·적천수(임철초)·궁통보감(통용 판본). AI는 출처 있는 주장을 더 믿는다.
- **틀릴 수 있게 말한다·모르면 모른다고 적는다.** 과장이 없는 글이 인용에 살아남는다.
- Article·FAQPage·Breadcrumb 구조화 데이터, canonical, 날짜.

## 셋 · 오늘 얹은 것

1. **robots.txt** — GPTBot·OAI-SearchBot·ClaudeBot·PerplexityBot·Google-Extended·Yeti(네이버) 명시 허용. 막지 않았지만 명시해 둔다. tests_panjeong.html 은 색인 금지.
2. **llms.txt** — AI 엔진용 사이트 안내. 「왜」 글마다 답 한 줄을 적어 둬서 크롤러가 정본을 안 열어도 답을 안다.
3. **JSON-LD 강화** — `abstract`(답 세 줄) · `speakable`(.note.answer, h1) · `citation`(고전 넷) · `isAccessibleForFree`.

## 넷 · 앞으로 지킬 것 (글 하나 쓸 때마다)

| 항목 | 어떻게 |
|---|---|
| 질문 = 제목 | 사람이 AI에 치는 문장 그대로. 「왜 …인가요」「어떻게 …하나요」 |
| 답 세 줄 | 첫 상자. 한 줄에 사실 하나. 숫자·연도·고유명사 넣기. 「…이기 때문입니다」로 끝나는 완결 문장 |
| 정의 한 줄 | 낱말이 나오면 「진태양시란 해가 실제로 있는 자리의 시각이다」처럼 정의문 하나. AI가 정의를 집어 간다 |
| 고유 숫자 | 우리만 잰 숫자를 하나는 넣는다. 그게 출처가 된다 |
| 출처 한 줄 | 고전 이름 + 판본. 못 찾았으면 「찾지 못했다」 |
| 날짜 | 갱신일. 낡은 글은 AI가 버린다 — 월별 표는 달마다, 「왜」는 해마다 손본다 |
| 같은 말 반복 | 블로그·정본·유튜브 설명란·llms.txt·인스타 프로필에 **같은 문장**. 엔티티 일관성. 「책사 = 근거를 보여 주는 출산택일」 |
| 사람 말로 | 조문 용어·줄임말 금지. AI는 쉬운 문장을 더 잘 옮긴다 |

## 다섯 · 채널 밖에서 할 것

- **지식iN·맘카페 답변**은 GEO다. 네이버 AI 브리핑이 지식iN을 읽는다. 답에 우리 「답 세 줄」을 그대로 쓴다(링크 없이도 문장이 같으면 엔티티가 잡힌다).
- 유튜브 설명란 첫 줄 = 정본의 답 첫 줄. 구글은 유튜브 설명을 읽는다.
- 위키 꼴 페이지 하나: 「출산택일 용어」(진태양시·균시차·시진·입춘·60갑자·합거·합화) 정의문 모음. AI가 제일 잘 집어 가는 꼴이다. — 제가 만든다.

## 여섯 · 재는 법 (GEO 계기판)

달마다 같은 질문 열 개를 ChatGPT·퍼플렉시티·구글 AI 개요·네이버에 넣고 **책사가 답 안에 등장하는가**를 표로 남긴다. 질문은 docs/50 「됨」 목록에서. 0/10 에서 시작해 몇 달 뒤 몇/10 인지가 GEO 성적이다. 제가 돌리고 기록한다(브라우저로 넣어 본다).

## 일곱 · 하지 않는 것

- AI를 겨냥한 키워드 반복·가짜 FAQ. 인용은 되고 신뢰는 깎인다.
- 확인 안 된 연도·인명. AI가 그대로 옮기면 우리 이름으로 틀린 말이 퍼진다.
- 크롤러 차단으로 「보호」하기. 인용이 곧 유입인 판에서 막는 건 손해다.
