# 영역전개 전략 — 무엇을 말할 수 있고, 무엇을 가져올 수 있나

**2026-08-31.** `docs/27_영역관제.md` 가 **조문**이라면 이 문서는 **실행 계획**이다.

순서를 지킨다 — **먼저 사람에 대해 말할 수 있는 것을 다 늘어놓고, 그다음 엔진이 무엇을 주는지 맞춘다.**
거꾸로 하면 있는 재료에 맞춰 말을 깎게 되고, 그러면 영역관제가 아니라 「우리가 계산할 수 있는 것들」이 된다.

---

## 하나 · 사람의 영역을 말할 때 말할 수 있는 것 — 열넷

명리를 잊고, 사람의 자리를 두고 실제로 오가는 말을 다 적는다.

| | 무엇 | 실제로 이렇게 묻는다 |
|---|---|---|
| 1 | **있는가** | 지금 맡은 게 있나, 소속이 있나 |
| 2 | **크기** | 몇 명을 데리고 있나, 얼마를 굴리나 |
| 3 | **종류** | 조직 안인가 · 내 사업인가 · 전문성인가 · 사람망인가 · 작품인가 |
| 4 | **어떻게 얻었나** | 물려받았나 · 뽑혀 들어갔나 · 직접 만들었나 · 겨뤄서 땄나 |
| 5 | **정당한가** | 직함·자격이 있나, 아니면 실질만 있나 |
| 6 | **안정한가** | 지켜지나 · 흔들리나 · 뺏길 수 있나 |
| 7 | **경계가 어디인가** | 어디까지가 내 몫인가 |
| 8 | **무엇을 내는가** | 그 자리를 유지하려고 시간·자유·건강·관계 중 무엇을 내는가 |
| 9 | **커지나** | 넓어지나 · 그대로나 · 줄어드나 |
| 10 | **옮길 수 있나** | 이 자리는 나에게 붙었나, 회사에 붙었나 |
| 11 | **내가 없으면** | 대체되나, 무너지나 |
| 12 | **물려줄 수 있나** | 남길 수 있는 자리인가 |
| 13 | **누가 노리나** | 경쟁자·동업자·안에서 |
| 14 | **언제 열리나** | 언제 자리가 오고 언제 닫히나 |

## 둘 · 엔진이 실제로 주는 것 (2026-08-31 확인)

**추측하지 않고 코드에서 확인한 것만 적는다.**

### 지금 화면에 나가는 값

```
자평진전   격 · 판정 · 상신 · 갖춤/걸림/받침/무너짐
           힘{일간 비겁 식상 재성 관성 인성}          ← 영역()이 지금 쓰는 것
억부       강약 · 깎는것 · 채우는것 · 빈오행
궁통보감   필요한글자 · 보조 · 기신
천직       축 · 유형 · 풀이 · 일들 (25유형)
운로       곡선 · 최고구간 · 지금칸 · 대운 9칸
재물       재물진단 · 재물결론 · 샌해 · 지킬해 · 열리는달_재물
궁위       과거연대기(해 · 축 · 근거)
겉속       겉글자/겉십신 · 속글자/속십신
```

### 엔진에 있는데 영역으로 안 쓰는 것

```
통근        stemPower — 천간이 지지에 뿌리내렸나
합거        natalHap — 묶여서 명령을 못 내는 천간
십이운성    E.power — 장생·건록·제왕·묘 12단계
삼합국      samhapOf — 지지가 국을 이뤄 성질이 바뀜
지장간      HIDDEN — 겉에 안 난 것
충          branchRels
정관/편관   지금은 「관성」으로 뭉뚱그려 쓴다
```

### 없는 것

**관성으로 해·달을 잡는 계산이 하나도 없다**(실측 0건).
財는 「열리는 해·달」을 잡는데 官은 안 잡는다.

다만 **인연의 열리는 달이 이미 官을 잡고 있다** —
「관성이 달의 하늘에 옵니다 — 인연의 글자입니다」.
같은 계산을 **배우자성 한 얼굴로만** 읽고 있는 것이다.
영역관제에서 官은 두 얼굴이므로(`docs/27` 여섯), **그 해가 곧 자리가 열리는 해다. 새 계산이 필요 없다.**

## 넷 · 무엇을 먼저 하나

### 1순위 — 「언제 자리가 열리나」 (새 계산 0)

인연의 열리는 해·달 계산이 **이미 관성을 잡고 있다.** 그 값을 영역의 얼굴로 한 번 더 읽는다.

> 「2027년 3월 — 사람이 들어오는 달입니다」
> **그리고 같은 달이 자리가 열리는 달이기도 합니다.**

- 재료가 100% 있다. 새 산식도 새 상수도 없다.
- **여성향에서 이게 제일 크다.** 「좋은 남편」과 「자기 판」을 같은 달로 말하는 것이
  `docs/27` 여섯(官의 두 얼굴)의 실물이다.
- 다만 **두 얼굴을 한 문장에 섞지 않는다.** 축이 다르므로 발언을 나눈다.

### 2순위 — 「이 자리가 무엇을 가져가나」 (이미 계산돼 있음)

억부의 `깎는것` 에 관성이 들어 있으면, 그것이 곧 **영역의 비용**이다.

> 「책임이 몰릴 때 남보다 빨리 바닥납니다」 ← 지금은 억부가 이 말만 한다
> **그 책임이 곧 공주님 자리입니다. 자리가 주는 것과 가져가는 것이 같습니다.**

- 형준(억부)과 장현(영역)이 **같은 값을 두고 갈리는 자리**다 — 갈림 재료로도 좋다.
- 새 계산 0. 이어 붙이기만 하면 된다.

### 3순위 — 「어떻게 얻은 자리인가」 (새 판정, 재료는 있음)

네 갈래. 전부 지금 있는 값으로 갈린다.

```
물려받은 자리   印이 官을 받친다        어른·문서·자격이 자리를 준다
뽑혀 든 자리    官이 통근 + 財가 생한다  제도가 인정하고 밑천이 받친다
만든 자리       官 없고 食傷生財         내놓은 것이 돈이 되고 그 돈이 자리가 된다
겨뤄 딴 자리    比劫 무거운데 官 있다    같은 것을 놓고 겨뤄서 얻는다
```

**말맛이 제일 좋은 자리다.** 「당신은 만든 자리에서 사는 사람입니다」는
누구도 안 해 주는 말이고, 계산으로 나온다.

### 4순위 — 정관/편관을 갈라 본다

지금은 「관성」으로 뭉뚱그린다. 그런데 둘은 다른 자리다.

```
정관   제도가 인정하는 자리 — 직함 · 자격 · 공식
편관   실질로 쥐는 자리 — 권한 · 압박 · 뺏고 지키는 판
관살혼잡  지켜야 할 자리가 둘이라 어지럽다
```

### 5순위 — 안정성 (통근 · 합거 · 상관)

```
관성이 통근  자리에 뿌리가 있다 — 흔들려도 안 뽑힌다
관성이 합거  자리가 묶여 명령을 못 낸다 — 이름만 있고 실권이 없다
상관이 있다  내가 만든 것이 내 자리를 친다(傷官見官)
```

**「이름만 있고 실권이 없다」는 합거로 그대로 나온다.** 지금 안 쓴다.

## 다섯 · 하지 않을 것

- **영역 점수를 만들지 않는다.** 0~100 을 붙이는 순간 貴賤이 뒷문으로 돌아온다(`docs/27` 여덟).
  크기를 말해야 하면 **백분위**로 말한다 — 재물그릇이 이미 그렇게 한다.
- **없는 넷(경계·이동성·대체가능성·승계)을 말하지 않는다.** 말맛이 좋아도 근거가 없다.
- **두 얼굴을 한 문장에 섞지 않는다.** 「좋은 사람도 오고 자리도 열립니다」는
  한 문장 두 주장이라 법전 제24조에 걸린다. 발언을 나눈다.
- **새 상수를 만들지 않는다.** 비교만 한다(`docs/13` 「輕重은 비교로만」).
