# 협기변방서 이관 대장

판본: **《欽定協紀辨方書》 四庫全書本** (위키문고 zh-hant, 2026-08-30 채록).
자평진전·궁통보감과 같은 절차 — 기억으로 쓰지 않고 원문을 채록해 대조한다.

## 1. 건제십이신 (권4 義例二)

> 建除滿平定執破危成收開閉 凡十二日周而復始
> 其法從月建上起建 … 正月建寅則寅日起建順行十二辰
> 每月交節則疊兩值日

산식: **신 = (일지 − 월건) mod 12** → 建0 除1 滿2 平3 定4 執5 破6 危7 成8 收9 開10 閉11.
절입에서 값이 하루 겹치는 것(疊兩值日)은 월건 교체로 자동 재현된다.

> 月建者陽建之神也 / 月破者月建所衝之日也 — **월파 = 건제의 破日과 동일** (자기검증 불변식)

성격 원문: 建為歲君為元神為吉凶衆神之主帥 · 除舊布新 · 物無成而不毁故繼之以破 …

## 2. 천덕·월덕 계열 (권5 義例三)

> 天德者 正月丁 二月坤 三月壬 四月辛 五月乾 六月甲 七月癸 八月艮 九月丙 十月乙 十一月巽 十二月庚
> 天德合者 正月壬 三月丁 四月丙 六月己 七月戊 九月辛 十月庚 十二月乙
> 月德者 正五九月在丙 二六十月在甲 三七十一月在壬 四八十二月在庚
> 月德合者 正五九月在辛 二六十月在己 三七十一月在丁 四八十二月在乙
> 月空: 寅午戌月壬 亥卯未月庚 申子辰月丙 巳酉丑月甲

- 2·5·8·11월 천덕은 방위(坤乾艮巽) — 날로는 못 쓰므로 null 처리, 원문대로 기록.
- 위키 변환 오류 두 곳(己→巳)을 **합 짝 검증으로 교정**: 천덕합 = 合(천덕),
  월덕합 = 合(월덕), 월공 = 월덕의 충 천간 — 세 불변식 전 칸 통과.

## 3. 宜忌 (권10)

천덕·월덕·천덕합·월덕합: 宜 제사·기복·구사·봉작·안장 등 광범위 / 忌 畋獵取魚.
월공: 宜 上表章.

건제 12신 (원문 → 현대어):
建 임관·부임·공식 자리 / 除 청소·목욕·이발·치료 시작 / 滿 개시·계약·납재·사람 들이기
平 정비·길 닦기 / 定 예식(冠帶) / 執 붙잡는 일(捕捉) / 破 치료·철거만 (그 외 흉)
危 안상·조심 / 成 입학·이사·개업·성사(천희·천의) / 收 수금·입고 / 開 여는 일 전반
(忌 안장·벌목) / 閉 막고 메우는 일(제방·봉인)

## 4. 우리 체계와의 자리

협기 = **만인 공통의 날 신살** (보조 축). 우리 본축 = 원국 맞춤(조후·통근).
쓰임: ① 택일 화면 「협기(민력) 기준」 열 ② 「민력 길일이 당신 사주엔 아닌 이유」
대조 콘텐츠 ③ 혼인·이사·개업 택일 상품의 근거층 (권11 用事 — 후속 채록).
