# 배포 가이드 (1단계 베타)

## A. 웹 공개 (무료, 10분)
1. GitHub 저장소 만들기 → 이 폴더 push
2. Cloudflare Pages 또는 Vercel에서 저장소 연결, 루트 디렉터리 `app` 지정
3. 나온 주소(예: chaeksa.pages.dev)로 접속 → 휴대폰 홈화면에 추가하면 앱처럼 동작 (PWA)

## B. AI 비서 켜기 (서버 프록시)
1. Anthropic Console(console.anthropic.com)에서 API 키 발급 — **사용자가 직접**
2. Cloudflare Workers에서 `server/worker.js` 배포, 환경변수 `ANTHROPIC_API_KEY` 등록, `ALLOWED_ORIGIN`에 A의 주소
3. 앱 → 설정 → "프록시 서버 주소"에 `https://<워커>.workers.dev` 입력
   (베타 기간엔 앱 코드에 기본값으로 박아 배포)

## C. 비용 예상
- 브리핑 1회 ≈ 입력 1,200토큰 + 출력 250토큰. Opus 5 기준 약 $0.02. Sonnet 5 기준 약 $0.006.
- 사용자 1인 월: 브리핑 30회 + 질문 30회 ≈ Opus $1.5 / Sonnet $0.4
- 베타 50명 1달 ≈ Opus 약 10만 원 / Sonnet 약 3만 원

## D. 베타 전 체크
- [ ] 프록시에 일일 호출 제한 (사용자당 브리핑 1 + 질문 20)
- [ ] 회원 로그인 (Supabase Auth) → 원국을 서버에 저장해 기기 바꿔도 유지
- [ ] 개인정보처리방침 페이지
- [ ] 절기·만세력 교차검증 100건 자동 테스트 (현재 2024년 12절기 + 8케이스)
