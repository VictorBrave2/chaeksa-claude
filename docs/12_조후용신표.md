# 조후용신표 — 검수용 (궁통보감 통용 판본)

`app/classic.js`의 표를 그대로 펼친 것이다. **원본은 코드**이고 이 문서는 자동 생성본이니,
칸을 고칠 때는 classic.js를 고치고 이 문서를 다시 뽑는다 (`python tools_johu.py`).

표기: **주용신** (보좌). 점수 규칙: 주용신이 연·월·시 천간에 있으면 50, 보좌만 있으면 30, 없으면 0.

## 채점 구조 (사용자 설계안)

```
궁통보감 50점: (일간×월지) 120칸 → 필요한 천간 → 원국 천간에 있다/없다
자평진전 50점: (일간×월지) → 격 → 상신 투출 → 성격/파격
합계 100점 — 표가 점수를 정한다. 조절 노브 없음.
```

자평진전 축의 격 판정 규칙(양인=甲卯·丙午·庚酉·壬子만 등)은 `app/typecard.js`의 `gyeok()`이 원본이다.
