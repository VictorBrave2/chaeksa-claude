# 책사 법전

사장님이 사례로 정한 것만 적는다. 판정은 코드가 하고, 이 문서는 기억이다.
2026-09-04 「애매한 건 다 삭제해봐」 — 사례와 규칙이 둘 다 또렷한 것만 남겼다.
원본은 `docs/19_법전_원본_2026-09-04.md`(기록 전용, 근거로 쓰지 않는다).

- 사례 없는 조문은 없다.
- 범위는 사례의 모양까지다. 둘째 사례가 오기 전에는 넓히지 않는다.
- 못 쓰는 것은 못 쓴다고 적는다.
- 사례를 받으면 구현하지 않고 조문으로 되받아 쓴다. 「이 사례에서만」과 「어디까지 넓혔는지」를 따로 보인다.

조문 번호는 코드 주석이 가리키므로 그대로 둔다. 빠진 번호는 버렸거나 법이 되지 못한 것이다.
