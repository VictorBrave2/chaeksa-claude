# 책사 법전 — 정한 것 · 버린 것 · 미룬 것

사장님이 사례로 정한 것의 기록이다. 판정은 코드가 하고, 이 문서는 기억이다.
2026-09-04 「난잡하다」 — 28조·개정·결재 기록·설명 절을 한 장으로 줄였다.
원본은 `docs/19_법전_원본_2026-09-04.md`(기록 전용, 근거로 쓰지 않는다).

**쓰는 법 셋**
- 사례 없는 조문은 없다. 사례가 없으면 그것은 잣대가 아니라 추측이다.
- 조문의 범위는 사례의 모양까지다. 둘째 사례가 오기 전에는 넓히지 않는다.
- 못 쓰는 것은 못 쓴다고 적는다. 빈칸이 채워 넣은 것보다 정확하다.

**되받아쓰기** 사례를 받으면 구현하지 않고 조문 초안으로 되받아 쓴다. 그때 「이 사례에서만」과
「어디까지 넓혔는지」를 따로 적어 보인다. 승인된 것만 구현한다.

조문 번호는 코드 주석이 가리키므로 그대로 둔다. 빠진 번호는 버린 것이다.

### 판정키 (화면에 안 나간다)

- **세 층** — 판정마다 원전(자평·궁통·삼명) / 잣대(사장님 판) / 통설(유파 갈림) 꼬리표를 단다. 통설은 실측이 반증하면 걷고, 못 하면 통설이라 적고 둔다. 화면에는 칩을 내지 않는다(09-04 「기준 공개」 삭제).
- **육안** — 한 대상(오늘·이달·올해·대운·상대·궁 글자)을 여섯 축으로: 자평(상신/파격) · 적천(중화·일지충) · 궁통(필요/기신) · 잣대(열림만, 좋고 나쁨 없음) · 통설 십신(사길/사흉) · 통설 신살(귀인·공망·도화·역마). 평균 내지 않는다. 화면은 좋다·나쁘다 근거 문장만.
- **하루 한마디** — 천간 십신과 **지지 본기 십신** 둘 다 사건으로 센다(09-04 「왜 지지는 제외한 것이야」). 일지 충도 사건.
- **십신·격 이름은 화면에 안 나간다** — 마지막 문(`chaeksadan.공주님말`)에서 자리말로 바꾼다.
