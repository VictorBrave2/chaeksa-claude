# 문장표 · 「계속 가면 뭐가 좋아요?」 — 16 (2026-09-12 다시 씀 · 새 틀)

이별 6번. 첫 판(2026-09-05)은 「그 사람의 기운이 나를 채우고」「두 사람의 짝 자리도 붙어요」「원국에서 좋은 자리 셋이 다 있어요」로 칸마다 판정키를 냈다.
새 틀(docs/34)로 다시 썼다. A(적천 채움)는 「누가 누구 곁에서 힘이 나나」, B(궁통 필요)는 「나한테 늘 모자란 걸 이 사람이 가짐 — 곁에 있으면 숨이 트임」,
C(짝 자리 합·삼합)는 「같이 있으면 말하지 않아도 편함」으로 옮긴다.

**새 틀** — 답은 한 문장으로 단정 · 왜는 둘이 같이 있을 때의 모습 · 축 설명 낱말 없음 · 끝은 오늘 할 수 있는 일 하나.

| 축 | 등급 |
|---|---|
| A 채움 | 둘 · 그가 · 내가 · 없 |
| B 내 계절에 필요한 사람인가 | 필요 · 무 |
| C 짝 자리 붙음(합·삼합) | 붙 · 무 |

표기 `A둘-B필요-C붙`.
