# 58 영역별 통설 수집 — 재물 · 연애결혼 · 직업 · 건강

수집일 2026-09-21. 정통사주 「재물운 · 연애결혼운 · 직업운 · 건강운」 장에 쓸 재료.

## 이 문서가 무엇인가

- 한국 웹의 명리 글(블로그 · 위키 · 명리 사이트 · 카페 · 신문 칼럼)이 **공통으로 말하는 것**을, 엔진이 계산할 수 있는 조건 단위로 모았다.
- **고전이 아니다.** 통설이다. 화면에 낼 때는 docs/57(일주 통설)과 같이 「통설」이라고 밝힌다. 법전(19)과 부딪히면 법전이 이긴다.
- 어떤 출처의 문장도 옮겨 적지 않았다. 키워드 · 짧은 구로 줄여 다시 썼다.
- 「n곳」은 **직접 연 페이지** 가운데 그 말을 한 곳의 수다. 검색 결과 요약만 본 것은 세지 않았다. 같은 사이트의 글 여러 편은 한 곳으로 셌다.
- 「일치」는 3곳 이상, 「갈림」은 1~2곳이거나 출처끼리 반대인 것.
- 한계: 페이지는 WebFetch(요약 모델을 거침)로 읽었다. 원문과 글자 단위 대조는 못 했다. 「확인 필요」라고 적은 항목은 쓰기 전에 원문을 다시 본다.

### B1-2 일지 겁재

### B1-3 일지 식신

### B1-9 일지 편인

### B1-10 일지 정인

## D4 오행과 장부 짝

장 · 부 짝은 열 곳(A B C D E F G H N K)이 모두 같다.

갈리는 곳.
- 눈 — 목 (A D N) ↔ 화 (C F H K M). 한의학 표를 따르면 목, 명리 실전 글은 화 쪽이 많다.
- 뼈 — 수 (A D N) ↔ 금 (C F H K) ↔ 목 (H, D 일부)
- 피부 — 금 (A D N) ↔ 토 (C F)
- 코 — 금 (A D) ↔ 토 (C, K 의 무)
- 췌장 — 목 (D) ↔ 토 (E)
