# 재생성 전략 — 줄기를 안 탄 콘텐츠를 폐기하고, 줄기에서 다시 낸다 (2026-09-14 · 사장님 「지금 나온 콘텐츠들을 다 폐기시키고 위 순서를 타는 콘텐츠들을 다시 생성하는 것에 대한 전략」)

줄기 = **법전 → 길흉 판정 → 공통 통변 규칙 → 질문 생성기(격자) → 질문 콘텐츠 → 답변.**
이 줄기에서 나온 것만 남기고, 줄기 밖에서 손으로 지은 것은 버린다. 판정이 아니라 **말**을 버리는 일이다 — 판정 모듈·법전·격자는 그대로다.

## 하나 · 지금 있는 것을 줄기에 대 본다

| 콘텐츠 | 줄기 | 처리 |
|---|---|---|
| 원국 밴드(홈 맨 위) | 탐 — 판정 모듈이 낸 층·범주 그대로 | **남긴다** |
| 「오늘 나에게 필요한 질문」 띠 | 탐 — 격자 99문 중 오늘 걸리는 것 | **남긴다** |
| 갈래 카드 8장 + 날 고르기 이레 | 탐 — 판정·격자·답변 24문장 | **남긴다** |

| 도화·홍염·괴강·백호 원문 페이지 | 별개 — 채록 공개 | **남긴다** |

폐기 셈: 유료 장 8(궁합 비밀 포함) + 무료 타일 5 + 상황 칩 74. **남는 콘텐츠 = 격자 99문**(날 고르기 9 · 상태 묻기 90) + 밴드 + 달력 + 택일.

## 둘 · 다시 내는 법 — 콘텐츠 하나 = 격자 질문 하나

| 조각 | 어디서 나오나 | 손이 가나 |
|---|---|---|
| 제목 | 격자의 질문 문장 | 없음(격자표) |
| 답 | 판정 이유 문장 | 없음(자동) |
| 결론·할 것 | 갈래 × 칸 24문장 + 둘 사이 3문장 | 없음(이미 씀) |
| 언제(날 고르기) | 이레·한 달 판정 | 없음(자동) |
| 지속 | 45조 「이달 내내」 | 없음(자동) |
| 삽화 | 88벌을 갈래 × 결과 칸에 다시 붙임 | **한 번** — 매핑 표 하나 |
| 소개 한 줄 | 격자 결과 뜻(docs/39 「결과 뜻」) | 없음 — 결과 뜻 그대로 |

그러니 「재생성」은 글을 다시 쓰는 일이 아니다. **격자를 콘텐츠 목록으로 삼고, 삽화를 그 위에 다시 붙이는 일**이다. 새 콘텐츠는 조문이 늘 때 격자에서 저절로 는다(사장님 「새 콘텐츠 더하기는 하지 않는다 — 해상도가 먼저」와 맞는다).

## 셋 · 순서

1. **상황 칩 → 격자 질문 칩.** 갈래 카드를 열면 그 갈래의 상태 묻기 질문(관계 9 · 재물 10 …)이 칩으로 서고, 고르면 「오늘 이 질문의 답」 + 이레가 선다. 74편 제목·소개·마무리는 이때 지운다(stories.js 목록 → 격자로 대체). 삽화는 매핑 표로.
2. **홈 「지금 마음에 걸리는 이야기」 셋** = 오늘 나에게 필요한 질문 중 조심 칸 셋. 돌려 보여 주는 게 아니라 오늘 걸리는 것.
3. **유료 장 일곱 + 궁합 비밀 폐기.** 홈 진열대에서 내리고 코드는 한 커밋에 지운다(git에 남는다). 상품(products 표)은 **토스 심사가 끝난 뒤** 내린다 — 심사 중에 상품을 지우면 다시 심사다.
4. **무료 타일 다섯 폐기.** 전체 목록에서 내린다. 원국 탭 밴드가 「나는 어떤 사람」의 자리다.
5. **새 유료.** 격자 위에서 값을 받을 자리는 둘이다 — 「둘 사이」(그 사람 하나마다) 와 「한 달 30일」(갈래 하나마다). 심사 통과 뒤 products 를 이 둘로 바꾼다. 값은 사장님이 정한다(값 조정 금지).

## 넷 · 하지 않을 것

- 격자 밖에서 질문을 새로 짓지 않는다. 질문이 필요하면 조문이 먼저다.
- 폐기하는 장의 문장을 「아까워서」 격자에 옮겨 붙이지 않는다. 판정에서 안 나온 말이다.
- 삽화를 새로 만들지 않는다. 88벌로 99문을 덮되, 모자라는 칸은 글자 표지.

## 다섯 · 결재

1. 폐기 목록(하나)에 남길 것이 있나. 특히 「내 짝은 언제 와요」(jjak)와 「이 남자, 나한테 돈을 쓸까요」(geunamja)는 물음 자체는 좋다 — 격자에 같은 물음이 서면(둘 사이·재물) 그때 되살아난다.
2. 순서 3의 시점 — 심사 결과가 나온 뒤인가, 지금인가.
