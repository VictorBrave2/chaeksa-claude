# 정통사주 웹툰 — 조각표 (2026-09-26, 3단계 「갈림만큼 원고 생성」의 발주서)

조립기 `app/jt-webtoon.js`(메인) · 조각 `app/jt-webtoon-2.js`(작가). 시제품 `jt-webtoon-proto.js`(丁卯)는 **틀과 말투의 본보기**다 — 사장님 「틀 확정」(09-26).

## 1. 작가가 채우는 것 — `window.ChaeksaJtJogak`
```js
window.ChaeksaJtJogak = {
  격:   { 3: { 정관: { 장면, 나, 답, 해설 }, 편관: {…}, 정재, 편재, 정인, 편인, 식신, 상관, 비견, 겁재 }, 4: {…}, 11: {…}, 15: {…}, 20: {…} },   // 5회 × 10 = 50칸
  성패: { 6: { 성격: { 장면, 나, 답, 해설 }, 기신: {…}, 구응: {…}, 파격: {…} }, 20: { 성격: { 답, 해설 }, 기신, 구응, 파격 } },        // 20회는 답 · 해설만(장면 · 나는 격 조각)
  공통: { 1: { 장면, 나, 답, 해설 }, 2: {…}, 5, 7, 8, 9, 10, 12, 13, 14, 16, 17, 18, 19 },   // 13회 — 장면 · 나는 모두에게 같고, 답 · 해설은 {변수} 틀
  단서틀: { 1: '…{변수}…', 2: …, …20 }   // 접힘의 추론의 단서 — 사주 말 · 한자 허용, {변수}로 그 사람 값
};
```
- 20회는 격 조각(장면 · 나)에 성패 조각(답 · 해설)을 얹는다 — 곱하지 않고 겹친다.
- 13 · 14회 공통의 답은 `{바람}`(연애궁합 바라는사람 문장)을 써도 되고, 새로 써도 된다.

## 2. 답 틀에 쓸 수 있는 {변수} (조립기 값())
| 변수 | 값 예(丁卯) | 쓰는 회 |
|---|---|---|

| {찾는글자있음} | 있어요 / 없어요 | 1 |

값이 비면(예: 격이 안 바뀌는 사람의 {바뀐해}) 빈 글자가 된다 — **답 틀은 값이 비어도 말이 되게** 쓰거나, 갈래를 나눠 둘 다 쓴다(`답: { 바뀜: '…{바뀐해}…', 안바뀜: '…' }` 꼴은 조립기가 아직 모른다 — 필요하면 메인에 말한다).

## 3. 말 규칙(뼈대 v2)
답 · 장면 · 나에 사주 말 · 한자 · 회사 다섯 칸 말(지시 · 자료 · 성과 · 실행 · 동료 · 판) 금지. 답 20자 안팎. 코칭 · 훈계 금지. 「깨졌다」를 겁주는 말로 쓰지 않고 돌아오는 해로. 성패는 성격 · 기신 · 구응 · 파격 넷 말만(해설 · 단서에서). 신강 · 신약 · 통설 금지. 금지 낱말 목록은 작가 파일.

## 4. 시험(5단계)
뼈대 동결 지문 · 빈칸 0(격 10 × 성패 4 가 다 나오는 명식 40개 이상) · 원고 검사기(정통사주용) · 사장님 명식 = 시제품과 같은 말.

## 5. 아는 한계(09-26 검수 2바퀴)
- 건록 · 양인 원국(판정엔진이 격 층을 안 냄, 512명식 중 58)은 대운마다 격 · 성패를 못 재서 「평생 안 바뀜」으로 나온다. 잰 게 아니라 못 잰 것 — 다음 일: 판정엔진 격 층을 건록 · 양인에도 내거나, 조립기가 「못 잼」 갈래를 갖는다.
