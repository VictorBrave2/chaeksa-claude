# AI 비서를 모든 방문자에게 열기 — Cloudflare Worker 설정

지금은 각자 자기 API 키를 넣어야 AI 비서가 동작합니다.
아래를 한 번 해두면 **방문자 누구나 키 없이** AI 비서를 쓸 수 있습니다. 약 10분.

## 1. Cloudflare 무료 가입
1. https://dash.cloudflare.com/sign-up 접속
2. 이메일 + 비밀번호로 가입 (카드 등록 불필요)
3. 메일 인증

## 2. Worker 만들기
1. 왼쪽 메뉴 **Compute (Workers)** → **Create** → **Create Worker**
2. 이름: `chaeksa-api` → **Deploy**
3. **Edit code** 클릭 → 기존 코드를 전부 지우고 `server/worker.js` 내용을 붙여넣기 → **Deploy**
4. 나온 주소를 복사 (예: `https://chaeksa-api.OOO.workers.dev`)

## 3. 환경변수 넣기
Worker 화면 → **Settings** → **Variables and Secrets** → **Add**

| 이름 | 종류 | 값 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Secret | Anthropic 콘솔에서 발급한 키 (`sk-ant-…`) |
| `ALLOWED_ORIGIN` | Text | `https://chaeksa.kr` |
| `DAILY_LIMIT` | Text | `40` |

저장 후 **Deploy**.

## 4. 호출 제한용 저장소 (권장, 5분)
1. 왼쪽 메뉴 **Storage & Databases → KV** → **Create a namespace**, 이름 `chaeksa-rate`
2. Worker → **Settings** → **Bindings** → **Add → KV namespace**
   - Variable name: `RATE`
   - KV namespace: `chaeksa-rate`
3. **Deploy**

이걸 하면 한 사람이 하루 40회까지만 쓰게 되어 비용이 폭주하지 않습니다.
(안 해도 동작은 하지만 제한이 걸리지 않습니다.)

## 5. 앱에 연결
2번에서 복사한 주소를 알려주시면 제가 앱 기본값으로 넣고 배포합니다.
(임시로 직접 하시려면: 앱 → 설정 → "프록시 서버 주소"에 `https://chaeksa-api.OOO.workers.dev` 입력)

## 비용
- Cloudflare Workers 무료 한도: 하루 10만 요청 (베타 규모엔 충분)
- Anthropic API: 사용량만큼. Sonnet 5로 두면 사용자 1인 월 약 400원, Opus 5는 약 1,500원.
