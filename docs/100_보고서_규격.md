# 출산택일 보고서 규격 — PDF와 소책자를 한 규격으로 (전략)

10-05 사장님 「PDF 보고서도 작성하고 소책자도 작성하려면 일정한 규격이 있어야 한다. 전략 수립부터 진행하자」.

## 1. 지금 무엇이 문제인가

- 지금 PDF는 **화면(웹) 보고서를 크롬으로 그대로 인쇄한 것**이다. 쪽 크기 · 여백 · 쪽 나눔 · 쪽 번호 · 차례가 없다. 그래서 칸이 쪽 가운데서 잘리고, 쪽수가 신청마다 13쪽에서 41쪽까지 들쭉날쭉하다.
- 같은 내용이 세 곳(웹 「내 보고서」 · PDF · 앞으로 소책자)에 나가는데 판짜기 기준이 하나도 없다.
- 글꼴: 웹 글꼴을 그대로 인쇄해 PDF가 무거웠다(10-04 고침 — 인쇄 때는 바탕). 웹과 인쇄본의 글꼴이 다르다.

## 2. 원칙

1. **내용은 하나, 판짜기는 둘.** 보고서 데이터(report JSON)는 지금 하나뿐이다. 그 위에 「화면 판짜기」와 「인쇄 판짜기」 두 벌만 둔다. **PDF = 소책자의 디지털본**(같은 판, 같은 쪽 번호). 소책자는 그 PDF를 인쇄소에 넘기기만 한다.
2. **쪽이 단위다.** 칸이 아니라 쪽으로 설계한다. 곳 하나, 명반 하나가 쪽 경계에서 시작한다.
3. **쪽수 상한을 둔다.** 「넣을 수 있는 것 다」는 지키되, 넘치는 것은 본문이 아니라 부록으로 보낸다(10-04 사장님 「넣고 빼지 말고」 — 빼지 않고 자리만 옮긴다).
4. **인쇄 원가가 싼 쪽으로.** 2도(먹 + 주홍) · 흰 종이 · 표준 판형(10-04 명반 카드에서 정한 색과 같다).

## 3. 규격 초안

### 판형 · 제본 · 색
| 항목 | 권하는 값 | 까닭 |
|---|---|---|
| 판형 | **A5(148 × 210mm)** | 우리나라 인쇄소 표준 판형이라 싸고 빠르다. 폰에서 PDF로 볼 때도 세로 한 쪽이 화면에 맞는다. |
| 제본 | 48쪽 이하 **중철**(스테이플) / 넘으면 **무선**(책등 풀) | 중철은 4의 배수 쪽 · 얇을 때만 된다. |
| 색 | **2도** — 먹 + 주홍(#b5412c) | 명반 카드 디자인과 같다. 4도보다 싸다. |
| 재단 여유 | 사방 3mm(소책자 파일만) | 인쇄소 공통 요구. PDF 손님본엔 없다. |
| 여백 | 위 18 · 아래 20 · 안쪽 20 · 바깥 15mm | 제본 쪽을 넓게. |
| 글꼴 | 본문 명조 10pt / 줄간 1.7, 제목 명조 굵게, 원문 인용 한자 명조 | 웹과 인쇄본을 같은 글꼴로 맞춘다(정적 글꼴 파일을 써서 PDF가 무거워지지 않게). |

### 차례(쪽 예산 — A5 기준)
| 부 | 내용 | 쪽 |
|---|---|---|
| 표지 | 「출산택일 보고서」 · 부모님 성함(신청서) · 예정 기간 · 책사 낙관 · 만든 날 | 1 |
| 차례 | 부 · 곳 · 쪽 번호 | 1 |
| 1부 한눈에 | 결론 한 쪽: 권하는 곳 셋(날짜 · 시각) · 고른 까닭 한 줄씩 · 알아 둘 흠 | 1~2 |
| 2부 권하는 곳 | 곳마다 **펼침 두 쪽**: 왼쪽 명식 카드 · 오른쪽 세 고전 · 가족 · 대운 · 병원 시간 | 곳 × 2 |
| 3부 자미두수 | 곳마다: 명반 카드 1쪽 → 질문 다섯 결론 1~2쪽 → 열두 궁 4쪽 안팎 | 곳 × 6~7 |
| 4부 물어보신 것 · 정리 | AI 두 칸(궁금하다고 하신 것 · 정리) | 2~3 |
| 부록 | 어떻게 골랐나 · 빼 둔 곳 · 그 밖의 곳 · 날짜별로 전부 · 원문 전체 표 · 읽는 법(용어) | 나머지 |
| 맺음 · 판권 | 책사 이름 · 발행일 · 신청 번호 · 연락처 · 「그저 그렇게 볼 뿐」 맺음말 | 1 |

- 곳 셋 기준 본문 약 32~36쪽 + 부록. 부록을 빼면 중철(48쪽 이하)에 들어간다.
- 성별 모름: 3부에서 「아들이면 / 딸이면」은 질문 다섯만 둘로 나누고, 열두 궁은 부록으로.

### 쪽에 들어가는 부품(모든 쪽이 이것만 쓴다)
| 부품 | 규격 |
|---|---|
| 명식 카드(사주) | 한 쪽 위 절반 고정 크기 |
| 명반 카드(자미) | 한 쪽 전체 — 네모 판 · 2도 · 전통 궁 이름 한글(10-04 정함) |
| 결론 상자 | 주홍 왼줄 · 행동 문장 · 끝에 「무엇으로 보았나」 한 줄 |
| 원문 인용 | 한자 원문 + 출처(권 · 편) + 한국어 뜻, 쪽 사이에서 안 잘림 |
| 쪽 머리 · 쪽 발 | 짝수 쪽 「출산택일 보고서」 · 홀수 쪽 부 이름 / 쪽 번호 바깥쪽 |

## 4. 만드는 길(단계마다 잣대)

1. **규격 확정** — 아래 「사장님이 정할 것」 결정. 잣대: 이 문서에 결정 줄이 다 찬다.
2. **인쇄 판짜기 견본** — 같은 report JSON으로 A5 인쇄 판짜기(@page · 쪽 나눔 · 쪽 머리 · 차례 · 표지)를 만들고 가상 신청으로 PDF 한 부. 잣대: 칸이 쪽 가운데서 안 잘림 · 쪽수가 예산 안 · PDF 2MB 이하 · 사장님 검수.
3. **실물 시험 인쇄 1부** — 온라인 인쇄소에 견본 PDF로 1부(사장님 주문 — 결제는 사장님). 잣대: 글자 크기 · 2도 색 · 제본이 손에 맞는다.
4. **자동 보고서에 적용** — 손님 PDF가 이 판으로 나간다. 잣대: 기존 시험 초록 + 새 시험(쪽 예산 · 잘림 0).
5. **소책자 상품화** — 값 · 배송 · 주문 길(사장님 결정, 결제 · 약관은 사장님 몫).

## 5. 사장님이 정한 것 (10-05)

> 「태어난 후에 발송이니까 — 1 A5 · 2 (부모 이름) 넣고 아이도 넣고 · 3 번체 · 4 소책자에 열두 궁 전부 넣어야지 · 5 PDF 99,000원, 소책자까지는 20만 넘게 받아야 하지 않겠어? 그만큼 고급스럽게 만들어 줘야」

| 결정 | 정한 것 |
|---|---|
| 판형 | **A5** — PDF · 소책자 같은 판 |
| 표지 이름 | **부모님 성함 + 아이 이름** |
| 원문 한자 | **번체로 통일**(위키문헌 전사본의 간체를 번체로 바꿔 싣는다. 원문 대조 시험은 번체로 바꾼 뒤 대조) |
| 자미두수 | **소책자엔 열두 궁 전부** |
| 값 | **PDF 99,000원 · 소책자는 20만 원 넘게**(정확한 값은 사장님) — 그만큼 고급스럽게 |

## 6. 그래서 두 상품은 다르다 — 「태어나기 전 PDF」와 「태어난 뒤 소책자」

**태어난 뒤에 보내므로 소책자는 「고른 시각」이 아니라 「실제로 태어난 아이」의 책이다.** 손님이 실제 출생 시각 · 아이 이름을 알려 주면 그 시각으로 다시 계산한다. 수술이 늦어져 권한 시각과 달라져도 책은 실제 아이 그대로다.

| | 출산택일 PDF | 소책자 |
|---|---|---|
| 언제 | 신청 직후(태어나기 전) | 태어난 뒤(손님이 출생 시각 · 이름을 알려 줌) |
| 무엇 | 권하는 곳 고르기 + 곳마다 자미두수 | 실제 태어난 아이 한 명의 책 |
| 표지 | 부모님 성함 · 예정 기간 | **아이 이름 · 태어난 날과 시 · 부모님 성함** · 책사 낙관 |
| 본문 | 지금 보고서(A5 판짜기) | ① 이 시각을 고른 까닭(택일 보고서 요약 — 권한 시각과 실제 시각) ② 아이 명식 카드 · 사주 풀이(세 고전) · 대운 연표 ③ 명반 카드 · 질문 다섯 · **열두 궁 전부** · 대한 연표 ④ 원문(번체) ⑤ 부모님께 드리는 맺음 |
| 쪽 | 32~48 | 64~96(무선 또는 양장) |
| 값 | 99,000원 | 20만 원 넘게(사장님) |

### 소책자를 「20만 원 넘는 물건」으로 — 고급 사양 (권함, 인쇄소 견적 뒤 확정)
- **양장(하드커버)** 또는 반양장, 실로 꿰매는 제본(사철) — 오래 펴 봐도 안 풀린다.
- **표지에 박(箔)** — 아이 이름과 책사 낙관을 금박 또는 먹박으로. 표지 천 또는 무늬 있는 고급지.
- **본문 미색 고급지**, 2도(먹 + 주홍) — 명반 카드 · 원문 인용을 주홍으로.
- **케이스(책집) 또는 상자** — 선물로 건넬 수 있게.
- 한 부씩 만드는 소량 양장은 포토북 · 소량 출판 인쇄소가 받는다. 값 · 기간은 견적을 받아 본 뒤 적는다(지어내지 않는다).

### 소책자 주문 길(만들 것)
1. 택일 PDF를 받은 손님에게 「아기가 태어나면 소책자로 만들어 드려요」 안내(보고서 맺음 · 메일).
2. 출생 뒤 손님이 실제 출생 시각 · 아이 이름 · 받을 주소를 보낸다(주소는 배송에만 쓰고, 보내면 지운다).
3. 엔진이 다시 계산 → 소책자 판 PDF(재단 여유 3mm) → 사장님 검수 → 인쇄소 → 배송.

## 7. 다음
- 2단계(인쇄 판짜기 견본): A5 · 쪽 나눔 · 쪽 머리 · 차례 · 표지를 지금 PDF에 먼저 입힌다(두 상품 공통 판).
- 소책자 견본: 가상 아이 하나로 목차 ①~⑤를 다 채운 PDF 한 부.
- 사장님 몫: 고급 사양 인쇄소 견적(양장 · 박 · 케이스 1부 제작) — 업체 고르기 · 결제는 사장님. 후보 업체 찾기는 메인이 돕는다.
