# 93. 고전 조항 · 법전 대조 (2026-09-27)

사장님 09-27 「진행해」 — **판정 권위는 법전(docs/19) 하나.** 고전 조항은 법전 조문이 된 것만 판정에 쓰고, 나머지는 제일의실단 인용으로만(docs/92 0절).
이 문서는 그 첫 단계인 **목록**이다. 코드는 한 줄도 안 고쳤다.

- 대상: 판정 길 `panjeong.판정` → `saenggeuk.표 · 층격 · 취격` → `gyeokguk.judge` → `classic.gungtong` → `gise.기세 · 원류` (+ `samyeong`, `engine` 힘 · 합 재료)에서 **판정 결과를 바꾸는 규칙**.
- 판정 칸: **겹침** = 법전 조문 글자와 같은 말 · **부딪힘** = 법전 조문과 다른 말(어느 조와 어떻게) · **없음** = 법전에 없음.
- 칠살 · 인성 관법(사장님 09-27, 74조 초안 — 법전 미등재)은 지시대로 「사장님」 출처 · 겹침으로 친다. 그 관법과 어긋나는 조항은 부딪힘에 따로 적었다.
- 출처 칸: 원문 = 『자평진전』 論用神成敗救應 심효첨 원문(docs/16 부록) · 평주 = 서락오 · 궁통 = 궁통보감 · 적천 = 적천수 · 삼명 = 삼명통회 · 사장님 · 나(내가 만든 것).
- 「걸림」「바뀜」 수: 브라우저(개발 서버 8791)에서 무작위 1,000명(1950~2010년, 시 무작위, 씨앗 20260927)을 원국 층으로 돌려 셌다. **걸림** = 그 조항이 선 사람 수(근거 목록에 찍힌 수), **바뀜** = 그 조항 하나를 격표에서 빼고 다시 돌렸을 때 판정(섰다 · 띠었다 · 구제됐다 · 깨졌다) / 성패(성격 · 패격)가 바뀐 사람 수. 메모리에서만 뺐다 넣었다 — 파일은 안 건드렸다.

- 원문표(gyeokguk.js:238-307)에 한문이 없는 조항 셋: 「투간한 재 옆에 인이 붙어 서로 극한다」 · 「재를 생하는데 관살이 낀다」 · 「금수상관이라 관을 반긴다」 — 원문 구절이 아니다(평주 · 내가 만든 것).
