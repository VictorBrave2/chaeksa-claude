# 정통사주 웹툰 — 뼈대 v1 (2026-09-26, 사장님 검수 대기)

소재 = 나에 대한 물음(사장님 09-26). 회 하나 = 물음 하나. 여덟 묶음 26회. 한 회 = ① 물음(책사) → ② 내가 사는 장면(조각) → ③ 근거(「왜 그렇게 살까」 — 책사 해설 + 추론의 단서, 실제 연도).
조각 축은 2단계(갈림 정하기)에서 정한다. 여기서는 물음과 회의 줄 딱지만.

| 묶음 | 회 | 물음(책사가 묻는다) | 답이 나오는 곳 |
|---|---|---|---|
| **태어남** | 1 | 나는 어떤 계절에, 어떤 글자로 태어났나요? | 일간 · 월지(궁통보감) — 엔진 |
| | 2 | 그 계절의 나는 무엇을 먼저 찾나요? | 조후(궁통보감) — 엔진 |
| | 3 | 내 여덟 글자는 서로 무엇을 하고 있나요? | 원국 생극 — 엔진 |
| **자리** | 4 | 회사로 치면 나는 어느 자리에 앉는 사람인가요? | 격(자평진전) — 조각 |
| | 5 | 그 자리에서 내가 잘하는 건 뭔가요? | 격 — 조각 |
| | 6 | 그 자리에서 내가 자꾸 걸리는 건 뭔가요? | 격 — 조각 |
| | 7 | 나를 그 자리에 앉혀 준 글자는 누구인가요? | 상신 — 엔진 |
| **되나** | 8 | 그 자리는 지금 서 있나요, 흔들리나요? | 성패(성격 · 기신 · 구응 · 파격) — 조각 |
| | 9 | 흔들린다면 무엇이 흔드나요? | 기신 · 파격 글자 — 엔진 |
| | 10 | 살려 주는 글자가 있나요? | 구응 — 엔진 |
| **하루** | 11 | 나는 하루를 어떤 힘으로 사나요? | 십이운성(삼명통회) — 엔진 |
| | 12 | 내 곁에 어떤 신살이 있나요? | 신살(삼명통회, 연지 기준) — 엔진 |
| | 13 | 나를 도와주는 귀인은 어디서 오나요? | 천을귀인(일간 기준) — 엔진 |
| **돈** | 14 | 돈은 나에게 어디로 들어오나요? | 재성 자리 — 엔진 |
| | 15 | 들어온 돈은 남나요, 나가나요? | 재성 × 격 — 조각 |
| | 16 | 돈이 흔들리는 해는 언제인가요? | 대운 · 세운 충합(실제 연도) — 엔진 |
| **사람** | 17 | 나는 어떤 사람에게 끌리나요? | 일지 바람 10 — 연애궁합 조각 재사용 |
| | 18 | 좋아하면 나는 어떻게 하나요? | 식상 언행 — 연애궁합 조각 재사용 |
| | 19 | 그 사람과 나는 — (웹툰궁합으로 잇는 문) | 문 |
| **일** | 20 | 나는 어떤 일에서 힘이 나나요? | 격 — 조각 |
| | 21 | 나는 혼자 하는 쪽인가요, 같이 하는 쪽인가요? | 비겁 · 관성 자리 — 엔진 |
| | 22 | 일이 바뀌는 해는 언제인가요? | 대운에서 격이 바뀌는 해(실제 연도) — 엔진 |
| **열 해** | 23 | 지금 나는 어느 열 해를 지나고 있나요? | 현재 대운(실제 연도) — 엔진 |
| | 24 | 이 열 해에 내 자리는 무엇으로 바뀌었나요? | 대운 층의 격 — 엔진 |
| | 25 | 언제 돌아오나요? | 다음 대운(실제 연도) — 엔진 |
| | 26 | 그래서 지금 나는 어떻게 살면 되나요? | 총론 — 조각(격 × 성패) |

## 줄 딱지(연애궁합과 같음)
- `장면`(공통 지문) · `@물음`(책사) · `@나`(조각 — 내 장면 · 대사) · `@단서`(엔진, 있는 각도만) · `@해설`(조각 또는 엔진) · `@해`(실제 연도 문장) · `근거`(회 끝 표).
- 이름표: 나 = 왼쪽 위 · 책사 = 가운데(그 사람 없음). 19회만 「그 사람」이 등장(웹툰궁합 문).
