# 글은 두 벌로 낸다 — 보고서형 · 블로그업로드형

계산은 한 번, 산출은 두 벌이다.

블로그 글을 보고 찾아온 사람이 상담을 청하고, 상담 보고서에서 나온 발견이
다시 블로그 글이 된다. 이 순환이 끊기면 계산을 두 번 하게 되고,
두 번 하면 숫자가 어긋나서 신뢰를 잃는다.

**한쪽만 만들고 넘어가지 마라.** 같은 자리에서 둘 다 낸다.

---

## 둘은 무엇이 다른가

| | 보고서형 | 블로그업로드형 |
|---|---|---|
| 파일 | `marketing/보고서*.html` | `marketing/붙여넣기-*.html` |
| 읽는 사람 | 돈을 낸 의뢰인 한 명 | 검색해서 들어온 낯선 사람 |
| 목적 | **답을 준다** | **믿게 만든다** |
| 표 | 쓴다. `.tw`로 감싼다 | **절대 안 쓴다** |
| 개인 사례 | 그대로 쓴다 | **못 쓴다** (아래 참조) |
| 결론 | 맨 위 | 맨 아래 (읽혀야 내려온다) |
| 길이 | 길어도 된다. 인쇄한다 | 한 문단 한 호흡 |
| 끝맺음 | 한계와 면책 | 무료 검증 + chaeksa.kr |

### 왜 블로그에는 표를 못 쓰나

네이버 스마트에디터에 표를 붙여넣으면 PC에서는 멀쩡한데
**모바일에서 본문이 통째로 옆으로 밀린다.** 유입의 대부분이 모바일이다.

표로 낼 내용은 `blockquote` 안에 `▸` 줄로 바꾼다.

```html
<blockquote><p><b>ⓐ 12월 21일</b></p><p>▸ 재성 1개, 관성 1개</p><p>▸ 재관 대운 : 15~54세</p></blockquote>
```

네이버는 **class와 inline style을 버린다.** 살아남는 것은
`h2 h3 p b i hr blockquote` 정도뿐이다. 그 안에서 짜야 한다.

### 문단은 한 줄에 한 호흡

폰 화면에서 45자가 넘으면 서너 줄로 접혀서 읽는 속도가 무너진다.
문장을 짧게 끊고 `<p>`를 나눈다. 마침표마다 나눈다고 생각하면 대체로 맞다.

## 개인 상담은 그대로 블로그에 못 올린다

익명이어도 안 된다. **본인은 자기 사연을 알아본다.**
댓글은 공개된 채로 남아 있고, 날짜·기간·가족 구성만으로 특정된다.

블로그판으로 옮길 때는 이렇게 바꾼다.

- **뺀다** — 가족 일주, 분만예정 기간, "받으신 택일", 의뢰인이 한 말
- **남긴다** — 계산 방법, 집계 숫자(132개 중 66개), 간지, 판정 사유
- **바꾼다** — "이 아이는" → "이런 자리는", 사례 → ⓐ/ⓑ 익명 부호

의뢰인이 공개해도 좋다고 **먼저 말했을 때만** 사례로 쓴다.
물어보는 것도 조심스럽다. 대부분은 방법만으로 충분히 좋은 글이 된다.

실제로 12월 상담에서 나온 '그릇이냐 타이밍이냐'는
가족 정보를 전부 빼고도 글 한 편이 됐다 — `붙여넣기-그릇과타이밍.html`

## 검사

형식이 섞이면 조용히 망가진다. 낼 때마다 돌린다.

```
python tools_form.py
```

- `X` 막힘 — 고치기 전에는 올리지 마라
- `!` 확인 — 판단해서 넘어가도 된다

무엇을 잡는가: 블로그판의 표·class·inline style·안 닫힌 태그·긴 문단·
chaeksa.kr 링크 누락, 보고서판의 `.tw` 안 감싼 표·인쇄 대응·다크모드.

**정상 파일만 통과시켜 보고 만족하지 마라.** 일부러 깨뜨려서
잡히는지 확인해야 검사기를 믿을 수 있다.

## 만들 때 순서

```
1  계산한다                     한 번만
2  보고서형을 먼저 쓴다           숫자를 다 담는다. 여기가 원본이다
3  블로그판으로 옮긴다            개인 정보를 빼고, 표를 ▸로 풀고, 문단을 쪼갠다
4  python tools_form.py         둘 다 통과할 때까지
5  보고서는 아티팩트로, 블로그는 붙여넣기 페이지로
```

**2번을 먼저 하는 이유** — 보고서는 숨길 곳이 없어서 숫자가 다 드러난다.
블로그를 먼저 쓰면 좋은 대목만 추려 쓰게 되고, 나중에 보고서를 쓸 때
빠진 숫자가 나온다.

블로그판 껍데기(복사 버튼·스타일)는 기존 `붙여넣기-*.html`을 복사해 쓴다.
`#doc` 안의 내용만 갈아끼우면 된다. 복사 버튼은 `h2`와 `.alt`를 빼고
서식이 살아 있는 채로 클립보드에 넣는다 — 네이버 본문에 Ctrl+V 하면 그대로 붙는다.
