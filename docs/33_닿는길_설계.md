# 닿는 길 — 체용·용신을 법전 29~32조로 다시 짜는 설계안 (2026-09-13, 결재 대기)

법전 29조(신강·신약·중화는 판단 뒤의 요약) · 30조(일간에 닿는 길) · 31조(격 글자에 닿는 길, 십성 사이의 길로 근거를 쓴다) ·
32조(방패는 두번법칙으로 센다)를 엔진에 옮기는 안이다. **새 판정은 하나, 「닿는 길」이다.** 나머지는 그것을 소비하는 자리를 바꾸는 일이다.

## 2. 새 판정 — 닿는 길 (`chaeyong.reach`)

들어오는 천간 X(운의 어느 층이든)에 대해:

1. **과녁**을 잡는다. 일간(30조), 그리고 격의 주인 글자(31조, `gyeokguk.judge` 의 상신/격신 천간). X 가 과녁을 극하면 「위협」, 생하면 「도움」, 그 외는 「무관」.
2. **방패**를 센다. 원국 천간 가운데 뿌리가 있고(`stemPower > 0`) 합거되지 않은 것 중
   - X 를 극하는 글자(제복 — 자평진전 갑목이 무토를 잡음), 또는
   - X 가 생하고 그 글자가 과녁을 생하는 글자(통관 — 사장님 갑목이 임수를 받아 정화로 넘김).
3. **묶는 글자**를 센다. 이미 층마다 도는 `합거재판정`이 답이다 — 방패 자리가 `합거자리` 에 들어 있으면 묶인 것. 32조: 방패 수 − 묶인 수 > 0 이면 아직 막힌다.
4. **판정** (한 층에 하나):

| 결과 | 뜻 | 값 |
|---|---|---|
| 받음 | 위협인데 방패가 남아 있다 — 받아먹는다(관→인→나, 상관패인) | +2 |
| 도움 | X 가 과녁을 생한다 | +1 |
| 무관 | 극도 생도 아니다 | 0 |
| 닿음 | 위협이고 방패가 없거나 다 묶였다 | −2 |
| 뚫림 | 이 층에서 마지막 방패가 묶여 닿음으로 바뀌었다 (닿음의 특수형, 화면에 따로 말한다) | −2 |

값 넷은 **우리가 정한 값**이다(7조·docs/15 C절에 적는다). 순서와 부호만 조문에서 나오고 크기는 눈금(−3~3)에 맞춘 것이다.
운실허(뿌리 없는 운은 힘이 없다)는 지금처럼 곱한다. 지지의 합·복음 가감(judge 의 extras)은 그대로 둔다.

**強弱 이름은 어디에도 안 쓴다.** 층마다 `strength`/`bodyStrength`/`moved` 필드는 계산에서 빼고 화면에서도 안 낸다.

## 3. 용신 후보 → 이어 주는 기운 (`engine.calc → bridges`)

원국 안에서 이미 서 있는 위협(뿌리 있는 관성이 방패 없이 일간을 극하는 등)마다, 방패가 될 오행을 「이어 주는 기운」으로 잡는다.
관성 위협이면 인성 오행(통관)·식상 오행(제복). 격 글자가 위협받으면 그것을 지키는 오행. 없으면 빈 목록 — 「없다」도 답이다(7조).
`yongCandidates` 이름은 남기되 값은 이것으로 바꾼다(소비자 수정 최소). 화면 말 「나를 채우는 기운」은 「길을 이어 주는 기운」으로.

## 5. 순서

1. `reach` 를 짓고 `stack` 안에서 judge 와 **나란히** 돌려 값을 비교한다(라이브 안 바꿈). 사장님 사주·자평진전 사례·표본 300 으로 부호가 어디서 갈리는지 본다.
2. 갈리는 자리를 사장님께 보여 드리고 결재.
3. judge → reach 교체, hourCurve·오늘 탭·달력·이야기 줄 갱신(한 커밋).
4. 문장표 갈래 결정 뒤 tongbyeon·gyeokguk·재물.

## 5-1. 09-13 조율에서 바뀐 것

- **단위는 일운까지.** 시운은 판정에서 뺀다 — 「시까지 넣으면 문제 발생 빈도가 매우 커진다」. 하루에 판정이 12개가 되고, 방패를 묶는 합이 두 시간마다 켜졌다 꺼지며, 출생 시각·진태양시 오차까지 얹힌다. 오늘 탭(시간대 그래프·방아쇠)은 통째로 걷었다(v808).
- **원국 역할표가 먼저다.** 운마다 길을 새로 추적하지 않는다. 원국을 읽을 때 거기 있는 십성마다 역할(주인·치는 자·받는 자·잡는 자·통로·새는 곳·이름뿐)을 정해 두고, 운은 그 역할표를 건드리는지만 본다. 식상이 힘을 빼는지는 식상의 역할(통로로 가는가, 새는가)로 갈린다 — 사람마다 다른 이유. 역할 이름은 사장님 말로 확정해야 한다(초안은 대화 09-13).
- **변격은 규칙으로 안 잡는다.** 종격·화격처럼 역할표 자체가 뒤집히는 경우는 텍스트 규칙으로 못 적는다(사장님). 엔진은 정격 역할표만 짜고, 뒤집힐 조건(일간 무근 + 한 오행이 판을 덮음 · 일간합 + 化 오행 당령)은 「갈림」으로만 표시한다(7조). 그 손님은 사람이 보는 상품으로 넘긴다.

## 5-2. 09-14 — 빠진 레이어를 찾았고 세웠다 (33조, app/saenggeuk.js)

「레이어를 쌓아왔는데 어디가 빠졌는지 모르겠다」(사장님 09-13) → 펼쳐 보니 **천간 사이의 생극을 글자별로 따라가는 계산이 없었고, 그 자리를 강약 합산이 대신하고 있었다.**
사장님: 「정화한테 갑이 있으면 임수가 도움이 되고, 갑한테 임수가 있으면 경금이 도와준다 — IF 로 들어가야 한다」. 두 IF 는 하나다: **극하는 두 글자 사이에 잇는 셋째 글자가 살아 있으면 극이 생으로 바뀐다.**
`ChaeksaSaenggeuk.표(pillars, 운천간들)` — 모든 쌍의 생/극, 통관(셋째 글자), 제복(잡는 글자), 끊김(생하는 쪽이 막힘 없이 극당함), 일간에 닿음(도움/받음/잡힘/닿음).
합은 서로 묶는다 — 운으로 온 己는 甲과의 합에 쓰여 제 명령을 못 한다. 32조는 「방패마다 묶는 글자 하나」로 자동.
**2절의 `reach` 는 이 표로 대체한다** — 층마다 닿는 길을 새로 추적하는 대신 원국 표 + 운 글자 한 장으로 다시 그린다. 이 표가 곧 「원국 역할표」다(사장님 「십성에 하나씩 역할을 부여」): 셋째 글자·잡는 글자·끊김이 역할이다.
아직 어느 화면도 안 쓴다. 다음: ① 표를 원국 화면에 사람 말로 세우기(원국을 메인으로) ② 달력·이야기 하루 줄이 「오늘 온 글자가 표를 어떻게 건드리나」를 읽기 ③ chaeyong judge·yongCandidates 폐기.
길흉 평가(정관격에서 戊가 壬을 잡으면 상관견관이라 흉)는 표 위의 다음 층 — 31조의 「격의 주인」이 누구인지가 필요하다(gyeokguk).

## 5-3. 09-14 — 표가 화면에 흐른다

- **원국 밴드(wongook.js, v812~815)**: 홈 「걸리는 이야기 → 원국 밴드 → 어떤 사이」. 명식 표(시일월년 · 천간 십신/천간/지지/지지 십신, 한자) + 「갑목(甲) 하나에 걸려 있어요」 한 줄 + 접기(돌아감·격·오늘/이달/올해/대운·조심할 글자). 34조 「임수(壬)」.
- **달력·이야기(v816)**: scoreDay 의 용신 +1.5 를 「오늘 글자가 표를 건드리나」로 교체(+1.5/−1.5/−1.5). 이야기 「나는 …날」이 표의 말. 80편이 사람마다 갈린다.
- **남은 것**: ③ chaeyong judge(順逆)·engine yongCandidates 폐기 — 소비자는 이제 hourCurve(오늘 탭 걷음)·tongbyeon(문장표 strong/mid/weak)·gyeokguk·재물뿐. 문장표 갈래 결정 뒤에.

## 6. 결정해 주실 것

- 값 넷(+2/+1/0/−2)을 이 크기로 두는가.
- 방패의 뿌리 기준: 천간이 지장간에 통근하면 뿌리로 본다(1조 그대로). 지장간에만 있고 천간에 안 뜬 글자는 방패가 아니다 — 맞는가.
- 문장표 세 갈래를 어떻게 할 것인가(합치기 / 이어 주는 기운 유무로 갈래 바꾸기).
