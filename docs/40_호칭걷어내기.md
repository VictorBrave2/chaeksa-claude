# 호칭을 걷어낸다 — 공주님·도련님 (2026-09-10 사장님)

> 「현재 우리 웹사이트에서 공주,도련님이라고 부르는데 이걸 삭제하자.
>  통변 과정에서 자꾸 꼬이네」

## 왜 꼬였나

글은 **한 벌만** 쓰고 「공주님」을 박아 뒀다. 남자 명식이면 화면에서 「도련님」으로
바꿔치기했다(`app.js` 호칭·fix). 그 바꿔치기가 **DOM 글 노드를 훑는 감시자** 안에 있고,
같은 함수에서 십신 낱말 정리기(`ChaeksaDan.공주님말`)도 돌린다.

한 문장이 화면에 서기까지 **두 번 문자열 치환**을 거친다. 그래서 꼬인다.
치환기를 없애려면 애초에 박지 않으면 된다.

## 무엇을 걷고 무엇을 남기나

**걷는다 — 화면에서 사람을 부르는 말**
「공주님」 「도련님」 이 손님을 가리키는 모든 자리.

**남긴다 — 내부 용어**
- `ChaeksaDan.공주님말()` 함수 이름
- 「공주님 원칙」(`docs/21`) 이라는 설계 개념과 문서 제목
- 소스 주석 안에서 설계를 논하는 대목

부르는 말이 아니라 **우리끼리 쓰는 이름**이라 그대로 둔다.

## 바꾸는 법 — 기계적 삭제 금지

한국어는 주어를 잘 생략한다. 그 성질을 쓴다.
다만 지우고 나서 **말이 되는지 반드시 읽어 본다.**

### 1. 주어·화제 → 지운다

- `공주님은 기운이 여린 쪽이에요` → `기운이 여린 쪽이에요`
- `공주님이 먼저 다가가는 쪽이라` → `먼저 다가가는 쪽이라`
- `공주님한테 어울리는 자리는` → `어울리는 자리는`

### 2. 목적어·소유격 → 「나 · 내」

**표가 이미 이렇게 쓰고 있다.** `docs/33_문장표_좋은사람.md` 안에
「이 사람의 좋은 점은 곁에 있을 때 **내 상태로** 확인하세요」가 그대로 있다.
사주 상담에서 화자가 손님 시점을 빌려 「내 기운」이라 말하는 건 원래 자연스럽다.

- `이 사람의 기운이 공주님을 채우고` → `이 사람의 기운이 나를 채우고`
- `공주님 기운을 채우나 빼나` → `내 기운을 채우나 빼나`
- `공주님 태어난 계절에도 맞아요` → `내가 태어난 계절에도 맞아요`
- `그게 이 사람이 공주님에게 주는 거예요` → `그게 이 사람이 나에게 주는 거예요`

### 3. 「나」가 어색한 자리 → 「이쪽」

방향을 말하는 자리다. 그 사람은 이미 「그 사람 · 그쪽」이라 부르니 짝이 맞는다.

- `그 말이 이제 공주님한테 와` → `그 말이 이제 이쪽으로 와`
- `마음이 아직 공주님 쪽으로 안 돈 거예요` → `마음이 아직 이쪽으로 안 돈 거예요`
- `그중에 공주님이 있었던 거예요` → `그중에 이쪽이 있었던 거예요`

**셋 중 무엇을 쓸지는 문장마다 읽어 보고 정한다.** 한 규칙으로 밀면 말이 깨진다.

### 4. 소유격 제목 → 「나의」

- `공주님의 재물 이야기` → `나의 재물 이야기`
- `공주님의 유형 카드` → `나의 유형 카드`

### 5. 랜딩 카피 → 이름을 모르는 자리라 다시 짓는다

로그인 전이라 이름이 없다. 호칭을 넣을 수 없다.

- `공주님의 이야기를 두고 책사들이 다툽니다` → `사주 하나를 두고 열 사람이 다툽니다`
- `정하는 것은 공주님이십니다` → `정하는 것은 언제나 본인입니다`

### 6. 이름을 부르고 싶으면 조립기가 넣는다

`app.js` 의 `nim()` 이 이미 `이름 + 님` 을 낸다. **표에는 박지 않는다.**
표에 박으면 다시 치환기가 필요해지고, 그게 이번에 걷어내는 바로 그것이다.

## 다 고친 뒤

1. `python tools_mun.py` — 96장을 `app/mun/*.js` 로 다시 만든다
2. `app.js` 의 호칭 치환기를 걷는다 — `호칭()`, `fix()` 안의 공주님↔도련님 교체
   (`nim()` 은 남긴다. 이름을 쓰는 자리는 그대로 필요하다)
3. `python tools_check.py` · `python tools_bust.py --bump`
4. 화면에서 눈으로 확인
