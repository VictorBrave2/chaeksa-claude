4. **Claude Code** — 뜻이 바뀐 줄이 없는지 원문 · 계산과 대 보고, 시험을 돌린 뒤 합칩니다. 비공개 원고 안은 책사 쪽이 옮겨 넣습니다. 상태를 `적용됨`으로 바꿉니다.

## 글의 기준(사장님 말 그대로)

1. **일반인이 · 알아먹게 · 있는 그대로 · 가감없이 · 단호하게.** 사주를 모르는 20~30대가 되묻지 않고 한 번에 알아듣는 말. 계산 · 옛 책이 말한 것은 빼지도 더하지도 않는다.
2. **「우리 문장 ~ (원문 작게)」** — 우리 말 문장이 먼저, 한자 · 사주 낱말 · 책 이름은 그 뒤 괄호 안. 사주 낱말을 쓰면 바로 뒤에 뜻을 붙인다(「쌓이는 돈(정재)」).
3. **흐리는 말을 쓰지 않는다** — 「~일 수 있어요 · ~편이에요 · ~쪽이에요 · ~기 쉬워요 · 짐작 · 아마 · ~듯해요」. 계산 · 책이 단정한 것은 단정한다. 다만 법 · 사실의 가능성(「청약철회가 제한될 수 있어요」 「설정에서 다시 볼 수 있어요」)은 그대로 둔다.
4. **한 칸은 「상태 → 겪을 일 → 할 일」** — 「그래서 어떻게 하라」까지. 할 일은 화면에 이미 있는 근거에서만.
5. 사장님 말투 본보기는 `.claude/agents/chaeksa-writer.md` 맨 위 표(「옛 문장 → 사장님 문장」)입니다. 금지어보다 이것을 먼저 봅니다.

## 건드리면 안 되는 것

- **뜻 · 사실** — 계산 결과 · 판정 낱말(으뜸 · 차선책 · 흠 · 깨진 격 등) · 옛 책 원문 · 숫자 · 값(원) · 날짜 · 시간. 말만 고친다.
- **코드** — id · class · data- 속성 · 변수 · JSON 열쇠 · `{자리표}` · `{?이름:안}` 갈래. JS 파일은 따옴표 안 손님 글만.
- **상품 약속 장부(`app/yaksok.js`)의 못 박은 칸** — 코드 · 탭 · 자리 · 그림 · 견본 · 딱지(`{값}` 자리) · 시간(「보통 2~3일 안」 「보통 1~2분」 「1분 남짓」 「3분쯤」) · 보관(「2년 동안」 「1년 동안」) · 「걷은 약속」 목록. 글 칸(한줄 · 홈한줄 · 미리 · 신청 · 만듦 · 받는것 · 필요 · 환불)만 고친다.
- **다시 넣지 않을 말(걷은 약속)** — 맞아요 / 아니에요 · 이건 나 같아요 · 아홉 장면 · 최대 30장 · 두 분이 어떤 짝인지 · 앞 답 5개 · 1장 무료 · 첫 부분 무료 · 무료 맛보기 · 채널 추가 · 네이버폼 · 사람이 직접 · 작업 전 전액 환불 · 계산 전 전액 환불.
- **약관(`terms.html`) · 개인정보처리방침(`privacy.html`) · 사업자 정보 바닥글** — 법 문서라 고치지 않는다. 어색한 곳은 PR 설명에 적기만.
- **우리끼리 말** — 「○○실단」 · 법전 · 조문 · 조 번호 · 파일 이름은 손님 글에 쓰지 않는다. 책사 개인 이름 · 실제 상담 사연 · 웹에 떠도는 통설은 쓰지 않는다. 호칭은 「당신」 · 「그 사람」(출산택일은 「아이」 · 「부모님」).
- 줄 끝은 CRLF 그대로.
