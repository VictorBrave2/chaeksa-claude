## 보고서의 새 차례(값은 조립기가 다 낸다 — Codex 는 글만 · 기존 칸의 문장은 손대지 않는다)

1. 인사(기존) + **설명 한 줄** — 지금은 사장님 말 그대로: 「사주팔자 세 고전 크로스체크, 자미두수 귀한 구조 체크, 가족이 되었을 때 가화만사성을 이루는지 체크. 위 순서대로 대응되는 날짜를 추천드립니다.」 → **가족은 뺀다**(11-11 결정). 이 뜻으로 손님이 읽을 두세 문장: 「사주팔자를 세 고전으로 크로스체크하고, 자미두수로 귀한 구조인지 보고, 고객이 적어 주신 조건에 맞춘다. 이 순서대로 거른 날짜를 추천한다.」
2. **답부터**(기존 결론 칸 그대로)
3. **어떻게 골랐나 — 필터 셋**(이름은 사장님 말 그대로: 사주팔자 필터 · 자미두수 필터 · 고객요구사항 필터). 필터마다 「조건 한 줄」이 비어 있다 — 아래 표.
4. **첫 추천이 필터를 지난 길** — 필터마다 「이 자리에서는」 한 줄. 지금은 기존 까닭 문장 · 자미 셈 숫자 줄 · 관점 줄을 그대로 놓았다. 머리(지금 「첫 추천이 필터를 지난 길」)와 자미 줄의 틀을 써 달라.
5. **알아 둘 것 · 맞바꿈** — 첫 추천의 흠(기존 문장) + 「으뜸 자리인데 뒤 필터에서 빠진 곳」 목록. 머리와, 빠진 자리 한 줄의 틀.
6. **다음 후보** — 한 줄씩(날짜 · 시각 · 으뜸/차선책 · 흠 수). 머리.
7. 궁금하다고 하신 것 · 드묾 · 병원에 전달 · 말씀하실 때(기존)
8. **사용된 근거**(머리 「사용된 근거」 — 사장님 말, 그 아래는 접힘)

## 필터 조건 한 줄의 뜻(이 뜻에서 벗어나지 않는다 · 각 25자 안팎 · 「~수 있어요」 없음)

| 필터 | 조건의 뜻(엔진 사실) | 되돌림이 있나 |
|---|---|---|
| 사주팔자 필터 | 궁통보감(태어난 계절에 필요한 글자) · 자평진전(격이 깨졌나) 두 고전에 걸리는 것이 없는 자리만 남긴다. 적천수(아이를 치는 글자가 막힘 없이 닿음)와 이른 대운의 충은 빼지 않고 「흠」으로 적는다 | 없음 |
| 자미두수 필터 | 명반(별 배치표)에 《자미두수전서》의 「무서움」 구절이 그대로 걸린 것이 없는 자리만 남긴다 | 있음 — 그런 자리가 하나도 없으면 빼지 않고 무서운 구절이 적은 차례로만 쓴다 |
| 고객요구사항 필터 | 신청서의 수술 가능 시간(조금이라도 겹치면 남김) · 주말 가능 여부 · 원하시는 방향(재물 · 자리 · 학업 · 건강 · 무난)에 맞는 자리만 남긴다 | 시간 · 주말은 늘 뺌 · 방향은 맞는 자리가 하나도 없으면 되돌림 |

되돌림이 일어난 필터는 화면에서 점선 테두리로 표시된다. 그때 손님이 읽을 **한 줄**(「이 조건을 완전히 만족하는 자리는 없어 차례에만 썼다」는 뜻)도 하나(공통).

## 어디에 쓰나

공개 `app/taekil-report-copy.js`(새 파일 · 장부 꼴 — `window.ChaeksaTaekilReportCopy = { 설명: '…', 조건: { 사주: '…', 자미: '…', 요구: '…' }, 되돌림: '…', 머리: { 지난길: '…', 맞바꿈: '…', 다음후보: '…' }, 틀: { 자미줄: '…{무서움}…', 빠진자리: '…{날짜}…{시각}…{필터}…', 같은조건: '…{번호들}…' } }`). 비공개 조립기가 이 장부를 읽어 넣는다(메인 몫). 다른 칸의 문장은 건드리지 않는다.
