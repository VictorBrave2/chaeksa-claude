## 사장님 기준 — 이 주문서에서 가장 먼저(10-28 추가)

1. **제목은 「오늘의 운세」.** 손님이 찾는 이름 그대로 쓰고, 내용을 다르게 하는 것이 우리 강점이다.
2. **제목은 파멸적으로 세게.** 사장님 예: 「오늘의 운세 — 책사의 미래 예지」. 한 번 보면 눌러 보지 않고는 못 배기는 제목. 쪽 제목 · 홈 칸 이름 · 공유 카드 제목 후보를 각각 다섯 이상 내고 보고서에 나란히 둔다(사장님이 고른다). 낚시는 안 된다 — 본문이 제목만큼 구체적이어야 한다.
3. **일어날 일을 뭉개지 않는다.** 사람들이 오늘의 운세에서 아쉬워하는 것은 「당신에게 일어날 일을 뭉개서 말하는 것」이다. 그래서 우리는
   - **누구와 · 무슨 일로 · 무엇이 일어나는지** 단정해서 말한다. 「좋은 일이 있겠습니다 · 대인관계에 주의」 같은 누구에게나 맞는 말은 쓰지 않는다.
   - 누구 · 무슨 일은 그날 새로 온 십성의 뜻(`app/sipseong.js` 중심)에서 꺼낸다 — 예: 관성 = 상사 · 약속 · 공식적인 자리, 재성 = 돈 · 거래 · 손에 쥘 것, 식상 = 말 · 결과물 · 내가 만든 것, 인성 = 문서 · 배움 · 나를 돕는 윗사람, 비겁 = 동료 · 경쟁자 · 내 몫. 무엇이 일어나나는 `두드러짐` · `부딪힘`에서.
   - 「~할 수 있습니다 · ~일 수도 · ~편입니다」로 흐리지 않는다. 아래 사장님 견본 말투의 「받아들일 수 있습니다」도 「받아들입니다」로.
   - 같은 날 다른 사람은 다른 사건을 읽어야 한다(원국대비로 갈림 — 아래 엔진 확인).

**조각 열쇠 읽는 법**
- `새로|지지|정관|없음` = 오늘 **몸 · 행동(지지)** 으로 **새로 들어온** **정관**, 타고난 사주에 **없던** 것. 필드: `한줄` · `누구` · `일` · `행동` · `주한줄`(이번 주 띠에 들어갈 짧은 꼴).
- `이어|지지|정관|겉` = 이번 달 바탕에서 이어지는 정관(조용한 날 첫 줄). 필드는 같다.
- `바탕|천간|관성` = 이번 달까지 이어 온 흐름 한 줄 · `빠짐|지지|재성` = 이어지던 흐름이 오늘 쉰다 한 줄 · `조용` = 조용한 날 한 줄 · `저녁` = 물음 · 답 단추 셋(비슷 · 다름 · 없음).
- 사장님 기준 3(누구 · 무슨 일 · 무엇이 일어나나)은 `누구` · `일` 필드가 맡는다. 재료는 ref 의 중심 · 두드러짐 · 부딪힘에서만.
- 원국대비: 겉 = 이미 드러나 쓰던 힘이 오늘 한 번 더 · 속 = 숨어 있던 힘이 오늘 밖으로 · 없음 = 타고나지 않은 것이 오늘 잠깐 들어온다. **같은 날 다른 사람이 다르게 읽히는 건 이 칸 덕이다** — 같은 십신이라도 셋을 다르게 쓴다.

**잰 값(뼈대 기준):** 같은 날 1,000명의 첫 줄 = 30갈래 안팎(일간 10 × 원국대비 3), 열흘 동안 1위 4.9~12.4%. 조용한 날(변동폭 0~1) 14.5%.

## 하려는 것(사장님 말 줄임)

- 매일 찾는 이유 = **「오늘 내 이야기는 어떻게 이어지는가」.** 한 사람의 이야기가 오늘 → 이번 주 · 이번 달 → 인생의 전환점으로 이어진다.
- 매일 방문하는 힘은 「나쁜 일이 생길까 봐 확인하는 불안」이 아니라 「오늘의 나를 읽고 내일의 변화를 궁금해하는 마음」에서.
- 첫 제작은 작게: **① 오늘의 나 ② 가까운 변화 ③ 저녁 기록** 셋. 홈 개편(오늘의 나 · 지금 삶의 흐름 · 가까운 변화 · 오늘의 기록 네 칸)은 이 쪽이 선 뒤 다음 주문.

## 엔진에서 꺼내는 값(이 밖의 판정을 짓지 않는다)

브라우저 전역 그대로 — `ChaeksaEngine` · `ChaeksaSipseong` · `ChaeksaByeonhwa` · `ChaeksaPeople`(index.html 처럼 engine.js → sipseong.js → sipseong-byeonhwa.js → people.js 차례로 싣는다).

```js
const p = ChaeksaPeople.active();                 // 넣어 둔 사람(생년월일 입력은 프로필에서 — 새 입력 칸을 만들지 않는다)
const R = ChaeksaEngine.calc(ChaeksaPeople.toProfile(p));
const 오늘 = ChaeksaByeonhwa.말(ChaeksaByeonhwa.변화(ChaeksaByeonhwa.층표(R, new Date())));
const 이번주 = ChaeksaByeonhwa.주(R, new Date());   // 오늘부터 일곱 날
```

- `오늘.용.천간` = 오늘 **생각**으로 오는 것, `오늘.용.지지` = 오늘 **몸 · 행동**으로 오는 것(사장님 26조: 천간은 깨달음, 지지는 행동).
  - `십신` · `상태`(새로 옴 / 이어짐) · `처음`(이번 층들에 처음) · `다시옴` · `원국대비`(겉 · 속 · 없음 — 타고난 사주에 이 십성이 드러나 있나 · 숨어 있나 · 없나)
  - 새로 옴이면 `뜻.중심` · `뜻.두드러짐` · `뜻.부딪힘` 셋 다, 이어짐이면 `말`(중심)만. 문장의 뜻은 이 대응표(`app/sipseong.js`)에서만 꺼낸다.
  - `이어지던` — 오늘 빠진(끊긴) 흐름. 「이번 달 내내 이어지던 ○○가 오늘은 쉰다」의 재료.
- `오늘.체` = 이번 달까지의 바탕(대운 · 세운 · 월운이 이어 온 무리). 「지금 내 삶의 흐름」 한 줄.
- `오늘.용.변동폭`(0~4) · `새로온수` — 오늘이 얼마나 달라지나.
- `이번주.띠`(일곱 날) · `이번주.뾰족한날` · `이번주.동점날들`(변동폭이 같은 날은 고르지 않고 다 낸다 — 사장님 09-27) · `이번주.체바뀜`(이번 주 안에 달이 바뀌면 그 날).

## 할 일

### 1. 새 쪽 `app/today.html` — 오늘의 운세

- 단독 쪽 공통 디자인(머리 줄 ← 홈, `style.css` 변수만). 사람은 프로필에서 고른다(`people.js`). 시간 모름도 된다(일주까지로 계산됨).
- 꼴: **오늘의 핵심 한 줄 → 내가 느낄 변화 → 행동 하나.** 사장님 견본 말투:
  > 오늘은 인정받고 싶은 마음이 앞섭니다. 가볍게 들은 말도 평가처럼 받아들일 수 있습니다. 보여 주고 싶은 일이 있다면, 말보다 결과를 먼저 내놓으세요.
- 첫 줄에 올릴 것: **새로 온 줄**(처음 > 다시 옴 > 이어짐 차례). 둘 다 새로 왔으면 천간(생각) · 지지(몸) 둘 다 짧게.
- 희로애락: 매일 넷을 억지로 채우지 않는다. 새로 온 십성의 `두드러짐`(기대 · 즐거움 쪽)과 `부딪힘`(신경 건드리는 것 · 힘든 이유 쪽)이 그날의 재료다. 둘 다 엔진이 내는 값이니 둘 다 써도 된다.
- 같은 날 사람마다 다르게: `원국대비`로 갈라 쓴다 — 겉(이미 드러나 있던 힘이 오늘 커진다) · 속(숨어 있던 것이 오늘 밖으로) · 없음(타고나지 않은 것이 오늘 잠깐 들어온다).
- **조용한 날**(변동폭 0~1, 열흘에 한두 번꼴): 극적인 말로 채우지 않는다. 「어제와 이어지는 하루」로 그대로 말하고 이어지는 것(`말`)을 쓴다.
- 「이번 달 바탕」 한 줄로 오늘을 큰 흐름에 놓는다(`체`). 대운 · 「내 운은 언제 풀릴까」(`when.html`) 링크로 먼 미래를 잇는다.
- 맞혔다고 유도하지 않는다. 불안을 부르는 말(「조심하세요 · 사고 · 손해」로 겁주기)을 첫 줄에 두지 않는다.

### 2. 가까운 변화

- **이번 주:** `이번주.띠` 일곱 날을 한 줄씩(오늘과 무엇이 다른가). `뾰족한날` · `동점날들` = 「힘을 쓸 날」. 날짜를 바꾸는 것만큼 실제로 바뀌는 날을 구별해 보인다(변동폭으로).
- **이번 달:** `체바뀜`이 있으면 달이 바뀌는 날과 바뀌는 바탕. 돈 · 일 · 관계는 십성 무리(재성 · 관성 · 비겁 등)를 사람 말로 옮겨서 — 대응표 뜻 안에서.
- 먼 미래는 이 쪽에서 새로 계산하지 않는다. `when.html` · 정통사주 · 자미두수로 링크만.

### 3. 저녁 기록

- 아침 예고 → 저녁 「오늘 실제로는 어땠나요?」 — 고르기 셋: **비슷했어요 · 달랐어요 · 특별한 일 없었어요.** 한 줄 메모는 선택.
- 저장은 **이 브라우저 안(localStorage)만** — 서버에 보내지 않는다(개인정보 · 원가 0). 열쇠와 꼴은 아래 그대로(메인이 정함, 나중에 로그인 계정으로 옮길 때 같은 꼴):
  ```
  chaeksa.diary.v1 = { [사람 id]: { "YYYY-MM-DD": {
      예고: { 간지, 천간: { 십신, 상태, 원국대비 }, 지지: { 십신, 상태, 원국대비 }, 변동폭 },
      답: "비슷" | "다름" | "없음",  메모: "…"(200자까지, 선택),  at: ISO 시각 } } }
  ```
  - 예고는 그 날 화면을 열 때 저장(나중에 엔진이 바뀌어도 그날 보여 준 것이 남게). 읽기 · 쓰기는 try/catch, 못 쓰면 조용히 넘어간다.
- 쌓이면 **「이번 달의 나」:** 이번 달 날마다 예고 한 줄과 답을 나란히. 맞힌 비율 · 점수를 내지 않는다(예측과 실제를 나란히 두는 것뿐).
- 사건 세기: 저장할 때 `ChaeksaTrack.event('today_note')`, 쪽 열면 `ChaeksaTrack.event('today')`, 끝 줄 `ChaeksaTrack.watchEnd(결과칸, 'today_end')`.

### 4. 들어오는 길(작게)

- 손님 글에 「십성 변화 엔진 · 체 · 용 · 변동폭 · 층」 같은 우리끼리 말, 법전 · 조문 · 파일 이름 · 「○○실단」.
- 기록을 서버로 보내지 않는다. 생년월일을 주소창에 넣지 않는다.
- 그 밖은 `copy-requests/README.md` 「건드리면 안 되는 것」.
