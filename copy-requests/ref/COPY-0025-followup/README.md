## 먼저 고친 여섯 항목

| 항목 | 바뀐 내용 |
|---|---|
| 사주 근거 세 줄 | 「운이 닿는 달」을 「이 물음의 사주 조건에 맞는 달」로 바꿨다. 물음마다 다른 조건을 포괄하며, 돈만의 입금·손실 예시는 만남·이별과 얻음·잃음으로 고쳤다. |

| 돈 타로 섞임 | 카드가 돈을 직접 말한다고 하지 않고 「카드를 돈 문제에 …로 읽습니다」로 썼다. 길·흉의 조사도 맞췄다. |
| 돈 자미 없음의 할 일 | 「이번 달」을 「그달」로 고쳤다. 결과 줄의 「이 달」도 「그달」로 맞췄다. |

돈 사주 「없음」은 「일이 움직이는 달」 대신 「살펴볼 달」로 고쳤다. 조건에 맞는 달을 찾았다는 사실과 실제 사건의 변화를 구별했다.

## 아홉 물음 원고의 범위

각 물음은 일어남 13칸 + 할 일 13칸이다. 일, 연애·결혼, 자녀, 부모·집안 어른, 곁의 사람, 떠남·바깥, 집·땅·재산, 몸, 마음을 채웠다.

- 타로는 모두 카드를 그 물음의 흐름으로 읽는 표현이다. 원문이 그 물음을 직접 언급했다고 새로 주장하지 않는다.
- 사주는 법전 21조와 주문서의 판정 범주에 맞춰 풀림·막힘·유지·관심과 시간의 변화까지만 썼다. 집 사주도 재산 관련 일의 범위이며 집값·이사·매매 성사를 만들지 않았다.
- 자미두수는 주문서가 대조한 원문의 시점을 유지했다. 일은 그해와 그달, 집·몸·마음은 그해다. 배우자·자녀·부모·아랫사람·이동 원문의 사건 줄에는 새로운 때 말을 넣지 않았다.
- 배우자와 자녀는 존재를 전제하지 않도록 「있다면」을 붙였다. 곁의 사람의 자미 풀이에서 원문이 가리키는 대상은 아랫사람으로 한정했다.
- 자미 「없음」은 해당 점에서 길흉을 가를 별이 없다는 뜻이다. 그해 전체의 길흉을 판정하지 못한다는 말로 확대하지 않았다.
- 몸·마음은 사주 점·타로·옛책의 해석임을 밝혔다. 별도 병명·완치·사고를 지어내지 않았다. 몸·마음의 사주 조건은 주문서에 메인 추론으로 적혀 있으므로 고전의 직접 조건이라고 소개하지 않았다.
- 할 일은 확인·대화·준비·생활 기록 등 사용자가 할 행동이다. 도움 줄 사람이 나타난다는 사건을 새로 만들지 않았다.
