## 합치기 전에 판단할 것

1. `그대로`는 점이 없는 결과에도 근거 접힘 아래에 나옵니다. 이번 문장은 양쪽에 맞췄지만 점 없음에서는 `다음카드`와 날짜가 두 번 나옵니다. 메인이 표시 조건을 조정할지 판단할 대상입니다.
2. 24달 표에서 타로가 여러 분야를 가리키면 ●●●여도 자미두수와 사주가 서로 다른 분야와 겹칠 수 있습니다. 현재 문구는 ●●●를 삼자 교집합이라고 설명하지 않습니다. 실제 공통 분야나 선택된 점의 표시를 메인이 보강할 대상입니다.
3. 기록은 기간 시작일부터 열리고 제출 후 수정 버튼이 없습니다. ‘지금까지’·‘아직 없어요’로 썼습니다. 기록 시점과 답 수정 동작은 메인 판단입니다.
4. `끝말`은 오늘의 운세를 안내하지만 현재 코드에는 이동 링크가 없습니다. 메인이 연결할 대상입니다.
5. 제목은 주문대로 두 해·세 관점·한 점을 모두 넣었습니다. 홈 카드 적용 시 제목의 줄바꿈과 작은 표지 구도를 메인이 확인합니다.
6. 새 WebP 큰 판·360px 작은 판과 PNG를 함께 전달합니다. 홈 카드·프로필 성별 연결, 캐시 버전, live 배포는 이 PR에 포함하지 않았습니다.
