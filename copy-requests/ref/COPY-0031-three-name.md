# COPY-0031 — 세 관점 메뉴 이름 제안

기존 이름은 그대로 두고 후보만 제안합니다.

## 1. 내 물음, 세 가지 답

- 홈 한 줄: 궁금한 일 하나를 타로·사주·자미두수로 나란히 봅니다.
- 이유: 하나의 질문에 세 가지 풀이가 나온다는 경험이 짧고 분명하게 전달됩니다.

## 2. 세 가지 점으로 보는 내 물음

- 홈 한 줄: 같은 물음을 세 가지 점술로 각각 살펴봅니다.
- 이유: 세 풀이가 서로 다른 점술에서 나온다는 점을 이름에서 바로 알 수 있습니다.

## 3. 세 관점으로 읽는 내 질문

- 홈 한 줄: 타로·사주·자미두수의 답을 한 화면에서 봅니다.
- 이유: 각각의 풀이를 비교해 읽는 화면의 성격이 차분하게 드러납니다.

추천은 **1번**입니다. 이름이 짧고 방문자가 무엇을 얻는지 바로 알 수 있습니다. 세 방식이 서로의 결과를 입증한다는 뜻은 담지 않았습니다.
