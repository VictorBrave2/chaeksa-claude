## 판단 필요 — 뼈대는 수정하지 않음

1. why.js는 2배 이상인 사건이 없으면 배수 큰 3개를 표시한다. 공통 머리말에 모든 항목이 2배 이상이라고 쓰지 않았다.
2. 실제 조건은 2배 이상·3번 이상·절반 이상이다. 주문서의 넘게와 경계가 다르다.
3. 오늘 태어난 아기도 내일부터의 운세를 계산한다. 빈말은 앞으로 태어날 아이처럼 계산할 날짜가 없는 상태에 맞췄다.
4. 횟수와 배수는 실제 생활의 관측 빈도가 아니라 오늘의 운세 문장이 계산상 나온 빈도다. 머리말·근거말·비교 평균 표기에 반영했다.
5. 표지 요청 IMG-0063/0064는 PR #6의 다른 삽화 ID와 겹친다. 이 PR의 파일명은 IMG-0063-why-cover-f.md / IMG-0064-why-cover-m.md이고 원본은 image-requests/out/IMG-0063.png / IMG-0064.png이다. 통합 시 목록을 파일명으로 구분하고 ID 정리가 필요하다.
6. 이번 주문 범위 밖의 사건 문장은 수정하지 않았다. 1년에 여러 번으로 환산해도 문장의 의미는 그대로다.
