「시간 모름」을 선택한 사람의 저장 자체는 막지 않는다. 신청 시점의 기존 차단을 정확하게 설명했다. 분을 비웠을 때 0분으로 처리하는 기존 방식에 맞춰 “시·분을 모두 입력해야 한다”는 말은 쓰지 않았다.

### 개인정보와 동의

- 신청 정보는 주문에 저장된다고 밝히고, **결과의 재열람 기간은 결제일부터 2년**으로 안내한다. “생년월일을 저장하지 않는다”, “신청서가 2년 뒤 자동 삭제된다”, “요청하면 즉시 지운다”는 확인되지 않은 설명은 쓰지 않는다.
- 동의 대상에 실제 사용하는 이름·생년월일시·성별·태어난 곳, 주문 신청서 저장·분석·결과 제공을 적었다. 다른 사람의 동의를 받고 입력하라는 안내는 유지했다.
- 첫 열람 전 전액 환불·생성 실패 전액 환불·열람 후 청약철회 제한 가능성은 기존 약관 그대로다. **환불 문장의 “제한될 수”는 기존 조건을 보존하기 위한 예외**이며 무조건 환불 불가로 고치지 않았다.
- 값은 `data-price="sss"`에 서버 상품표가 넣는다. 화면에 값을 새로 적지 않았다.

## 3. 결제 직후·결과 상태

### 결제 직후 조립되는 문장

> 넘어가면 바로 만들기 시작해요. 보통 몇 초 걸려요. 그 화면에서 기다리시면 다 되는 대로 바로 보여요. 창을 닫았다면 홈 「설정」의 「내 결제」에서 다시 열어 주세요.

`pay-done.html`의 일과 돈·SSS 공통 줄에서 **재진입 안내 한 문장만** 고쳤다. SSS에 없는 “소개 페이지의 내 결과” 대신 두 상품에 실제로 있는 경로를 안내한다. 일과 돈의 제공시간은 장부의 기존 “보통 1~2분” 그대로다. 3초 이동·주문 확인·시험 결제 처리는 변경하지 않았다.

### SSS 전용 상태말

| 상태 | 원고 |
|---|---|
| todo | 결제가 확인됐어요. 두 사람의 궁합 분석을 시작해요. |
| no_intake | 결제는 확인됐지만 두 사람의 신청 정보를 찾지 못했어요. |
| making | 두 사람의 정보를 계산해 24가지 질문의 답을 준비하고 있어요. 보통 몇 초 걸려요. |
| checking | 결과를 열기 전에 확인할 내용이 있어요. 책사가 확인을 마치면 궁합 분석 결과가 열려요. |
| ready | 두 사람의 궁합 분석 결과가 열렸어요. |
| canceled | 이 주문은 환불되어 궁합 분석 결과가 닫혔어요. |

기존 `sss.상태말: ilgyeol.상태말` 공유를 동일 키의 SSS 문장 객체로 교체했다. 일과 돈의 원본 상태말은 바꾸지 않았다. SSS에 근거 없는 “풀이를 쓰는 중”, “보통 하루 안”은 나오지 않는다.

결과 쪽의 자체 문장도 “궁합 분석 결과”로 맞췄다. 로그인·주문번호 없음·미결제·기간 만료·불러오기 실패·만들기 실패·신청서 없음·환불·확인 중 상태의 기존 분기와 단추 동작은 그대로다.

## 6. 메인에게 넘길 실제 누락

주문서 지시대로 약관과 개인정보처리방침은 수정하지 않았다.

1. **주문 신청서에는 출생 정보도 남는다.** `sss-apply.js`의 `사람꼴` → `api/pay.js` → `server/migrate-42-sss-product.sql`의 `order_intake`는 이름·생년월일시·성별·출생지·음력 입력 정보를 보관한다. “여덟 글자와 이름만”은 결과 객체 설명이지 주문 전체의 보관 범위가 아니다.
2. **결과 열람 2년과 신청서 보관 기간은 다르다.** `sss_view`는 결제일부터 2년을 확인한다. `sss_take`의 삭제 대상은 오래된 결과 행이며, 신청서의 2년 자동 삭제는 이 코드에서 확인되지 않았다. 탈퇴 시 신청 내용·메모와 SSS 결과를 지우는 정의는 있다. 운영 DB 적용 상태는 이번에 확인하지 않았다.
3. `privacy.html`에 SSS 수집·처리·보관 안내가 없다. 실제 저장 범위에 맞춰 메인이 보완해야 한다.
4. `terms.html`의 서비스 제공기간과 상품별 최초 열람 정의에 SSS가 빠져 있다. 상품 수를 가리키는 “네 가지”와 “다섯 가지”도 어긋난다. SSS 상품·환불 줄은 이미 있으므로 그 내용과 맞춰 보완해야 한다.
5. 이번 PR은 문장 제안이다. Supabase 이전 파일 실행·실제 시험 결제·홈 연결·main 배포는 하지 않았다.
