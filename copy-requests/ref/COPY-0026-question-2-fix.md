## 정한 것

- 근거는 주문서 마지막 뜻 대조 절, [수정표](COPY-0026-question-fix3.md)의 맞는 뜻과 낱말 옮김 60줄, [자료표](COPY-0026-question-cards.md) §2·§3이다.
- 병·정신의 병·죽음·임신·출산·불임·매장·장례도 원문의 뜻으로 쓴다. 실제 누구에게 언제 얼마나 일어나는지는 지어내지 않는다.
- 자리 설명 대신 직접 뜻을 말하고, 같은 낱말은 같은 우리말로 옮긴다. 다른 풀이·조건·남녀 및 나이·혼인 조건을 유지한다.
- 연애 남녀 7면의 M·F 구조와 기존 나머지 문구는 유지한다. 일반 카드뜻·카드말은 별도 담당 범위다.
