# COPY-0051 — 새 구조 원고와 연결 인계

2026-11-11 · 상태: 제안됨 · 가지 `codex/COPY-0051` · 기존 PR #61 갱신

최신 주문서(main edfcd689, 결정함 161)를 반영한 원고다. 이전 가족명식 조건 키와 설명·되돌림의 부모 관계 문장은 삭제했다. 필터는 사주팔자 → 자미두수 → 고객요구사항 셋이다. 손님 원고에 가족·부모·챕터 말은 없다.

## 납품 11칸

`app/taekil-report-copy.js`의 `window.ChaeksaTaekilReportCopy`에 주문서가 지정한 키만 사용한다. 필터 이름 셋과 「사용된 근거」, 기존 결론 본문은 그대로다. 결론 되풀이를 묶는 틀만 새로 제공한다.

## 자리표와 연결 인계

- `틀.자미줄`: `{무서움}`, `{좋게}`, `{반김}`, `{조심}`, `{걱정}` 다섯 개. 주문서의 「같은 값 넷」은 열거된 자리표 수와 다르므로 다섯 값을 모두 남겼다. 숫자에 단위를 붙이지 않은 값으로 넘긴다.
- `틀.빠진자리`: `{날짜}`, `{시각}`, `{필터}`. 주문서의 필터 이름을 그대로 채운다. 되돌릴 수 있는 자미 조건·원하는 방향에 적용한다. 병원 시간·주말 때문에 제외된 후보를 곧바로 추천으로 되살리는 문장이 아니다.
- `틀.같은조건`: `{번호들}`은 「2번과 3번」 또는 「2번·3번·4번」처럼 마지막이 「번」으로 끝나는 묶음이다. 실제 같은 비교 조건에 묶인 후보가 둘 이상일 때 한 번만 사용한다. 날짜·시각 정렬은 조립기가 정한 값을 그대로 쓴다.
- `되돌림`은 조건을 모두 만족하는 후보가 없어 순서에만 반영한 경우에만 붙인다. 자료가 없어서 필터를 적용하지 않은 경우에는 이 문장을 붙이지 않는다.
- 비공개 조립기가 장부를 읽어 설명·조건·새 머리와 틀을 보고서 노드에 넣는다. 현재 공개 filters 분기는 `f.조건`과 점선 표시만 그리므로 되돌림 문장도 실제 보고서 노드에 들어가도록 연결해야 한다.
- 기존 인사·답부터·흠 본문·고객요구사항의 기존 관점 줄·질문·드묾·병원 안내·근거 본문은 바꾸지 않았다. 원고 파일 자체에는 렌더러·계산·필터 로직이 없다.

## 확인 범위

최신 주문서와 기존 조립기·공개 그리기 코드를 읽어 뜻과 지정 키를 대조했다. 자동 시험·구문 실행·배포는 하지 않았다. 메인에서 장부 연결·의미 대조·견본 재생성과 배포를 진행한다.
