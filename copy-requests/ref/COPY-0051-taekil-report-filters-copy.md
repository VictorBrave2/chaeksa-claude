# COPY-0051 — 원고와 연결 인계

2026-11-11 · 상태: 제안됨 · 가지 `codex/COPY-0051`

## 납품

`app/taekil-report-copy.js`의 `window.ChaeksaTaekilReportCopy`에 설명 1칸, 조건 4칸, 되돌림 1칸을 작성했다. 주문서가 지정한 키만 사용한다. 필터 이름과 「사용된 근거」, 기존 결론 문장은 바꾸지 않았다.

| 칸 | 손님 문장 | 옮긴 뜻 |
|---|---|---|
| 설명 | 먼저 세 고전(궁통보감·자평진전·적천수)으로 사주팔자를 살피고, 후보를 제외할 조건과 따로 알려드릴 흠을 구분해요. 이어 자미두수에서 귀하게 보는 별의 배치와 경계할 대목을 확인하고, 아이와 부모의 사주를 맞대어 한 가족으로서의 조화를 살펴요. 이 차례로 후보를 좁힌 뒤, 병원에서 가능한 시간과 신청하신 조건에 맞춰 날짜와 시간을 추천해요. | 사주 세 고전 → 자미두수의 귀한 구조·경계 → 가족의 조화 → 신청 조건 순서. 세 고전을 모두 탈락 기준으로 쓰거나 실제 화목을 보장한다는 말은 넣지 않음. |
| 조건.사주 | 계절에 맞고 사주의 큰 틀이 온전한 때를 남겨요. | 계절의 필요는 궁통보감, 큰 틀이 깨지지 않음은 자평진전. 적천수·이른 대운 충까지 통과해야 한다고 넓히지 않음. |
| 조건.자미 | 옛 책이 크게 경계한 별 배치는 걸러요. | 자미두수전서의 무서움 구절이 걸린 명반. 단순히 드문 별 배치를 남긴다는 뜻으로 바꾸지 않음. |
| 조건.가족 | 부모와 부딪히거나 힘을 깎는 사주 관계를 걸러요. | 부모 일지와 아이 일지의 충, 부모 어느 쪽과도 깎는 관계가 아닌 조건. 실제 감정싸움으로 단정하지 않도록 사주 관계라고 밝힘. |
| 조건.요구 | 수술 시간·주말 여부·원하시는 방향을 맞춰요. | 수술 가능 시간과 일부라도 겹침, 주말 가능 여부, 신청한 방향. 시간 구간 전체가 병원 시간 안이어야 한다는 말은 쓰지 않음. |
| 되돌림 | 이 조건을 모두 맞춘 후보가 없어 추천 차례에만 반영했어요. 부모와의 충과 병원의 시간·주말 제한은 그대로 적용해요. | 조건을 다 맞추는 후보가 없을 때 일부 조건을 순서에만 반영. 부모 충·수술 시간·주말 제한까지 해제된다는 오해를 막기 위해 공통 안내 한 칸에 두 문장으로 씀. |

## 메인 연결 시 확인할 곳

- 공개 파일은 원고 장부만 제공한다. 비공개 조립기가 설명, 조건 네 칸, 되돌림을 읽어 넣는 작업은 메인 몫이다.
- 현재 공개 `app/taekil-report.js`의 filters 분기는 `f.조건`만 글로 그리고 `f.적용 === false`는 점선 표시로 쓴다. 새 장부의 되돌림 문장이 실제 보고서 노드에도 들어가도록 연결해야 한다. 키를 추가하거나 화면 코드를 고치지는 않았다.
- 부모 충, 수술 시간, 주말은 항상 제한으로 남는다. 자미두수의 경계, 가족의 깎음, 원하는 방향 가운데 되돌림이 발생한 조건에만 공통 문장을 붙인다.
- 기존 결론과 「사용된 근거」는 그대로 둔다. 연결·합침·견본 재생성과 배포는 메인 단계다.

## 확인 범위

주문서와 공개 그리기 코드를 읽어 키와 문장 범위를 대조했다. 자동 시험·구문 실행·배포는 하지 않았다. 이번 PR은 손님 문장 제안이다.
