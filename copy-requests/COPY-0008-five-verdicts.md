## 지킬 것

1. **뜻 · 판정 · 숫자 · 연도 · 치환 토막(`{…}`) · 괄호 안 책 · 엔진 낱말은 그대로.** 세게 하거나 흐리지 않는다(「~일 수 있어요」 「~편이에요」 금지). 책이 갈린 자리는 갈린다고.
2. **첫 문장이 판정.** 「~를 확인하세요 · 아래에서 보세요 · ~에서 보여요」 안내 꼬리는 결론 문장에서 뺀다.
3. 사장님 문장은 건드리지 않는다 — gwi `끝.줄` 「당신의 언행은 누구를 향합니까」, 「나를 뜻하는 글자」 「나와 나란한 힘」 「뿌리 힘」 같은 낱말.
4. 글 표 파일은 **값(한국어)만** 고친다. 키 · 구조 · 따옴표 꼴 · 줄 끝(CRLF) 그대로. `gyeokgi-copy.js` · `saram-copy.js` 는 한 줄짜리 JSON 이라 꼴을 깨지 않게 조심(고친 뒤 `node -e "require('vm').createScript(require('fs').readFileSync('app/파일','utf8'))"` 로 문법 확인).
5. 다른 함수 · 다른 파일은 건드리지 않는다. 그림 · API · 커밋 · 푸시 없음.
6. 끝나면 `CODEX_REPORT.md`(저장소 뿌리)에 파일 · 키마다 전 → 후를 적고, 뜻이 바뀔까 걱정된 곳은 「판단 필요」에.
