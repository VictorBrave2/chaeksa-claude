# 정통사주 · 정통자미두수의 해석자 장면

2026-10-28 사용자 요청: 두 콘텐츠에서 남녀 해석자가 개인의 결과를 이야기하는 컨셉에 맞춰 삽화와 배치를 전체적으로 결정하고 적용한다.

## 현재 방향

- 캐릭터는 개인별 결과를 전하는 도구다. 제작용 남신·여신 이름이나 캐릭터 설정을 고객에게 설명하지 않는다.
- 정통사주와 정통자미두수에 같은 화풍과 장면 문법을 사용한다. 남성은 은 장식과 책, 여성은 작은 진주 장식과 별 지도가 있는 책으로 구분한다.
- 눈을 맞추는 첫 해설, 책을 읽는 근거 구간, 책을 덮은 마지막 정리의 세 자세를 각각 생성했다. 한 삽화를 확대·반전하여 돌려 쓰지 않는다.
- 첫 장면은 큰 상반신과 바로 이어지는 결과 카드다. 모바일에서 인물과 결론을 세로로 연결하고, 넓은 화면에서는 나란히 배치한다.
- 중간은 두 번째 조건 묶음의 제목 옆에 작은 독서 장면으로 둔다. 조건과 수치의 읽을 폭을 확보한다. 조건 묶음이 하나면 중간 장면을 생략한다.
- 마지막은 책을 덮은 인물과 기존 개인별 요약을 묶는다. 첫 장면보다 작은 크기로 마무리한다.
- 양쪽 어깨를 화면 안에 배치한다. 좌우 확대, 음수 여백, 좌우 반전, 인물을 가르는 세로 크롭을 사용하지 않는다.
- 눈동자가 보이고 가슴이 과장되지 않는 자연스러운 성인 체형, 손으로 책을 받치는 자세를 사용한다. 작은 옷 무늬와 장식을 줄였다.
- 자미두수 명반이 먼저 오는 순서, 모든 기존 해설·필터·수치·근거·공유·궁과 별의 풀이를 유지한다. 결과 DOM의 해당 문장만 장면 안으로 옮긴다.
- 고정 견본 자료를 서비스에 연결하지 않는다. 서비스는 매번 기존 엔진이 만든 이용자의 실제 결과에 장면을 붙인다.
- 삽화 숨기기, 지연 로딩, 모션 줄이기, 장식 이미지의 빈 대체문자, 이미지 실패 시 본문 복원을 유지한다.

## 자산 · 생성 기록

도구: built-in image_gen. 투명 배경의 1254×1254 PNG, 기존 얼굴을 기준으로 편집. 첫 자세를 다음 두 자세의 신원·의상 기준으로 사용했다.

- 정통사주: `app/art/jeongtong-companion/welcome-v4.png`, `reading-v4.png`, `closing-v4.png`
- 정통자미두수: `app/art/ziwei-companion/welcome-v4.png`, `reading-v4.png`, `closing-v4.png`
- 프롬프트 전문: 각 폴더의 `image-prompts-v4.txt`

## 적용

- 정통사주: `jeongtong-pyo.js/css`의 장면 연결과 스타일을 정리한다. 첫 제목과 한 줄 풀이, 두 번째 필터 제목, 마지막 요약을 묶는다.
- 정통자미두수: `myeongban-companion.js/css`. 명반 아래 첫 개인별 제목, 두 번째 조건 묶음, 마지막 요약에 적용한다.
- `index.html`에서는 위 정통사주 파일 두 개의 내용 지문만 갱신한다. 다른 진행 중인 수정은 포함하지 않는다.
- `myeongban.html`에서는 companion JS/CSS의 내용 지문을 갱신한다.
- 별도 자동 시험은 추가하거나 실행하지 않는다. 로컬 모바일 견본을 눈으로 살핀 뒤 서비스에 적용한다.
