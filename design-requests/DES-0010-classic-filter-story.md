# DES-0010 — 옛 책이 귀하게 본 조건을 쌓는 이야기

- 사용자 교정: 별 모양을 만들지 않는다. 계절·격·성패·강약·기운을 버리라는 뜻도 아니다. 다섯 자리를 채우는 대신 옛 책이 좋다고 말한 대목을 찾고, 해당 조건이 겹쳐질수록 드물어지는 과정을 보여 준다. 마지막은 「당신은 귀한 사람」이라는 인정으로 이어진다.
- 적용 대상: DES-0009 공용 견본과 로컬 8794 개인 견본. 10-25 사용자 승인으로 모든 이용자의 출생 정보에 연결하고 운영에 반영한다.

## 화면

1. **옛 책이 당신을 좋게 본 이유** — 짧은 대표 이름과 한 문장.
2. **좋은 조건의 누적** — 책·좋게 본 내용·내 명식의 해당 조건·여기까지 모두 만족한 누적 비율을 세로로 쌓는다. 조건 수는 가변이다.
3. **당신은 귀한 사람입니다** — 확인한 좋은 대목이 겹친다는 이야기로 마무리한다. 귀함은 고전의 가치 언어이며 실제 성취·인간의 우열을 측정한 점수로 표시하지 않는다.
4. **운에서 이어질 가능성** — 원국에서 아직 성립하지 않은 정화견진은 누적 필터 밖에 두고, 운의 조건과 생각·행동의 변화로 잇는다.

## 계산

- 비교 자료는 1950~2009년의 매일 홀수 시각 정시·남녀 동일 비중·서울 기준 525,960개 달력 격자 명식이다. 처음 60,000개 표본에서 일부 조합이 관측되지 않아 날짜·시각 격자로 확대해 다시 계산했다. 실제 인구 빈도나 모든 가능한 절입 경계 명식의 전수조사는 아니다.
- 각 조건을 독립적으로 곱하지 않는다. 동일한 명식 집합에서 앞 조건을 모두 만족하고 새 조건도 만족하는 개수를 다시 센다.
- 조건이 중복되면 비율이 유지될 수 있다. 감소를 연출하려고 수치를 바꾸지 않는다.
- 기본 판정은 기존 판정엔진, 고전 대목은 기존 전체 고전 목록의 해당 여부로 계산한다. 출처와 실제 확인한 조건을 함께 제공한다.
- 단순 신약을 좋은 것으로 세지 않는다. 「身弱喜印」은 신약과 천간의 인성 존재를 함께 확인한다.
- 정화견진 등 합화 성립을 생략한 기존 필터는 좋은 조건 누적에서 제외한다.
- 계절의 필요 글자 존재는 좋은 요소 하나로 센다. 원문의 다른 걸림을 해소했다거나 해당 장의 전체 길흉이 좋다는 뜻으로 표시하지 않는다. 기존 조후 걸림 자료는 근거에서 보존한다.
- 마지막 조합이 표본에서 관측되지 않으면 0%·100%·임의의 희귀도로 바꾸지 않고 「비율 미산정」으로 표시한다.
- 표본 수와 집계 개수는 산출 기준에서 제공한다. 화면 본문에는 누적 비율을 중심으로 표시한다.

## 자료와 개인정보

- 로컬 계산 중간 자료와 개인 견본은 공개 저장소 밖 jt-name-season 폴더에 저장한다.
- 공개 데이터에는 기존의 가상 네 명의 집계 결과만 넣는다. 개인의 출생 정보·개인별 결과는 공개 저장소로 옮기지 않는다.
- 화면은 필터 배열을 순회한다. 카드 다섯 개·특정 인물의 조건·특정 마지막 비율에 고정하지 않는다.

## 전체 이용자 연결

- 비공개 API `jt-pyo` v2가 출생 정보별로 해당 조건, 내 글자의 근거, 원문, 누적 비율, 앞으로의 날짜를 계산한다. 공개 화면에는 계산 규칙·전체 비교 자료를 싣지 않는다.
- 전체 고전 목록 882개 중 합화 전제 등을 확인하지 못하는 기존 10개 항목은 누적에서 제외한다. 나머지 872개와 기본 조건을 같은 525,960개 비교 명식에서 다시 집계했다. 견본 인물들의 일부 조건만 저장한 이전 중간 자료는 운영에 쓰지 않는다.
- 전체 조건별 비트 집합의 교집합을 순서대로 세므로 이용자의 조건 순서나 조합이 달라도 누적 집계가 가능하다. 비교 자료는 고객 기록이 없는 달력 격자이며, 실제 인구 비율이 아니다.
- 기존 드문 이름용 판정기와 전체 목록 판정기를 별도 인스턴스로 둔다. 기존 판정 결과와 원문의 다른 걸림은 유지한다.
- 사용자가 개인 견본에서 말한 인지 경험은 다른 이용자에게 복제하지 않는다.
- 태어난 시간을 모르면 시간 추가 안내와 기존 여섯 글자 풀이를 제공한다. API 장애 시 다시 불러오기와 기존 상세 풀이로 연결한다.

## 개인 견본 결과

- 좋은 조건 12개: 계절 필요 글자 → 정관격 → 성격 → 신약에 인성 → 이인동심 → 지관향 → 합관위귀 → 록고봉재 → 마극신 → 사절위복 → 살장관로 → 화약봉수.
- 누적 비율은 27.03% → 2.98% → 1.57% → 0.60% → 0.0091% → 0.0027% → 0.0011% → 0.0004%이며, 이후에는 같은 명식 집합이라 유지된다. 낮아 보이게 수치를 꾸미지 않았다.
- 마지막은 「당신은 귀한 사람입니다. 옛 책이 좋게 본 이유가 당신의 명식 안에 겹쳐 있습니다」로 마무리한다.
