# DES-0017 · 별과 궁을 누르면 쉬운 풀이부터

2026-10-26 · 사용자 요청: 명반의 별이나 궁을 눌렀을 때 나오는 풀이를 일반인이 쉽게 이해할 수 있게 살펴보고 정리.

## 확인한 문제

- 별의 일반 설명에 다른 궁·다른 조합의 조건부 풀이까지 길게 섞여 있었다.
- 본문 문장마다 한자 구절과 책 이름이 반복됐다. 칸·재관격·반배·대한·사화 등 이름 설명이 앞섰다.
- 해당 문장이 없는 갈래에서 조건 미확인·다른 조건의 문장을 기본 본문에 보여 주었다.
- 궁은 분야 설명과 별 버튼 위주라 자기 풀이까지 한 번 더 눌러야 했다.
- 운의 배치 연도를 위 사건이 실현되는 해처럼 안내했다.
- 가상 견본의 파군/재백궁에서 기본 배치의 재물 구절과 지겁을 더한 빈곤 구절이 함께 해당했다. 원문 조건을 각 문장 위에 드러낼 필요가 있었다.

## 적용

- 별 32종 소개와 궁 12곳의 분야 설명을 짧게 작성했다. 기존 원문·뜻과 작가 원고에서만 옮겼다.
- 실제 걸림 id와 기존 밝기 조건을 통과한 문장부터 표시한다. 기존 책사 추론은 해당 갈래에 원문 풀이가 없을 때만 ‘책사의 해석’으로 구별한다.
- 한자 출처 꼬리는 본문에서 생략하고 원문 접힘에 원래 구절·뜻·출처를 보존한다. 뜻을 이미 풀어 쓴 전문 이름과 금은보화 같은 말을 정리한다.
- 여러 구절이 함께 해당할 때 엔진의 실제 ‘왜’를 쉬운 이름으로 표기한다. 상반된 구절을 임의로 합치거나 우선순위를 새로 정하지 않는다.
- 궁은 자기 별의 핵심 풀이와 실제 조건을 먼저 보여 주고 각 별의 상세 풀이로 연결한다.
- 운의 연도·조건 미확인·다른 조건·별의 옛 설명과 밝기를 각각 펼쳐 읽게 한다. 운 배치와 사건 실현을 구분한다.
- 별과 궁 사이의 이전 이동, 닫기, 열두 궁 전체 풀이에도 같은 렌더러를 쓴다.

엔진·조건·고전 원문·비율 변경 없음. 별도 테스트 스위트 실행 없음. 가상 프로필로 실제 버튼과 화면을 수동 확인한다.
