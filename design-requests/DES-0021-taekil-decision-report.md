# DES-0021 출산택일 추천을 결정하는 보고서

사용자 2026-10-26: 직접 생성·분석한 개선 전략대로 진행하고 알려 달라. 운영 반영까지 승인.

## 확정 구조

첫 추천의 실제 병원 가능 구간 → 그 아이에게 좋은 이유 → 함께 확인된 경계와 우선 추천 이유 → 후보별 차이 → 병원에 전달할 문장과 불가능할 때의 경로 → 상세 사주·자미·원문.

- 후보 선정과 순서·원문 조건·흠 수·빈도는 기존 판정 결과를 따른다.
- 명식의 전체 시진과 병원 가능 구간을 구분한다. 대표 날짜·시간과 전달 문구·검사가 동일한 구간 자료를 읽는다.
- 빈 가족 입력은 파싱 결과 수와 입력 여부로 판단한다.
- 좋은 평가와 강한 경계를 함께 보존한다. 책의 조건부 말을 실제 사건 보장으로 바꾸지 않는다.
- 자미두수는 현재 순위를 바꾸지 않는 대조 자료임을 분명히 하고 장점·경계를 추천 설명과 연결한다. 새 선정 규칙을 만들지 않는다.
- 원고 작성 → 교차 검수. 본문·원문 자료는 삭제하지 않고 상세와 부록으로 연결한다. 인쇄 시 펼침과 페이지 경계를 적용한다.
- 새 가상 보고서 A/B를 같은 조립기로 만든다. 외부 AI 크레딧 호출 없이 직접 작성한 원고를 정식 조립 경로에 넣어 견본을 완성한다. 실제 주문·기발급 본문은 다시 만들지 않는다.
- 운영 AI 자동 작성의 복구는 별도 사실로 보고한다. 검사기를 우회하거나 누락 보고서를 발급하지 않는다.

## 파일 역할

- 루트: 비공개 구간 공통 함수·검사·빈 가족 표시·조립 연결·견본 생성·배포.
- 글 작성: 표시용 모듈의 첫 추천·후보 비교·고전 강한 평가·경계·자미 대조 요약. 원문 판정·계산 변경 없음.
- 검수: 고전 출처·상충·강도·개인화·오류·AI 출력 제약 대조.
- 화면: 공개 렌더러와 보고서 CSS. 기존 노드와 부분(part) 보존, 상세·부록 접힘과 인쇄 대응.
