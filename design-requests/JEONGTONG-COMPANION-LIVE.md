# 정통사주 캐릭터 실제 적용

2026-10-28 사용자 요청: 정통자미두수와 같은 감성으로 정통사주도 적용한다.

- 기존 남신의 얼굴·단발·아이보리 외투와 먹색 안옷·은 장식·수첩을 유지한 세 장의 1024×1536 투명 삽화를 생성한다. 읽기·설명·책을 닫은 자세이며 눈동자가 보이게 한다.
- 개인별 첫 제목, 두 번째 필터의 제목, 모인 조건의 결론에 크게 등장한다. 필터가 하나라면 중간 삽화는 생략한다.
- 기존 엔진 결과·제목·설명·필터·비율·공유·근거·운 흐름은 유지한다. 실제 결과 DOM의 제목만 장면 안으로 옮긴다.
- 설명과 비율은 장면 아래에서 본문 폭으로 읽게 한다. 캐릭터의 제작용 신 이름은 표시하지 않는다.
- 삽화 숨기기, 이미지 지연 로딩, 모션 줄이기, 이미지 실패 시 원래 본문 폭을 제공한다.
- 통합 지점은 jeongtong-pyo.js의 resultView이며, 스타일은 기존 jeongtong-pyo.css 안에 범위를 제한한다. index.html에서는 이 두 파일의 내용 지문만 바꾼다.
- 이미지: app/art/jeongtong-companion/reading-v1.png, explaining-v1.png, closing-v1.png. 도구: built-in image_gen. 프롬프트 전문은 같은 폴더 image-prompts.txt에 저장한다.
