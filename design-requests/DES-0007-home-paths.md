## 정한 것

1. 첫 방문: 생년월일·성별·양력/음력 → 내 사주 무료로 보기. 시간·이름·장소는 펼쳐서 추가.
2. 재방문: 내 사주 이어 보기 → 목적 네 칸 → 전체 보기 → 내 사주 더 살펴보기(접힘).
3. 목적 네 칸: 아기 태어날 날과 시간(출산택일 소개), 우리 둘 잘 맞을까(정통궁합), 내 일과 돈(정통사주 7장), 언제 나아질까(when).
4. 전체 보기 #all: 기존 15개 콘텐츠를 다섯 묶음으로. 그림·이름·한 줄 설명·가격을 함께 표시.
5. 하단: 홈 / 전체 보기 / 내 보고서. 내 보고서는 Claude가 만든 ./#mine 재사용.
6. 중복 홈 물음 칩 제거. 계산·가격·구매 목록 구현은 변경하지 않음.

## 확인 범위

별도 테스트는 추가·실행하지 않는다. 배포 도구의 내장 검사와 실제 공개 화면 확인 결과는 CODEX_REPORT.md에 기록한다. 로그인한 구매자 목록 확인은 이번 범위에 포함하지 않는다.
