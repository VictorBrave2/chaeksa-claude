# 정통사주 캐릭터 전달 견본

2026-10-27 사용자 승인: 캐릭터는 의사전달 도구. 고객 화면에는 「본질의 남신」 등 제작용 역할명을 노출하지 않는다. 이용자의 해석을 먼저 보여주고 캐릭터는 강조·연결·경계·물러나기를 담당한다.

추가 교정: 집게손 금지. 엄지와 검지를 가까이 맞대거나 C자 모양으로 작은 것을 잡는 손, 손가락 하트, OK 제스처를 사용하지 않는다. 현재 정통사주 전달 견본은 얇은 수첩을 들고 설명하는 자세로 제작한다. 기존 다섯 신 견본의 삽화·시트·동작 문구도 교체한다.

현재 견본: app/previews/jeongtong-companion/. 사용자 교정에 따라 현재 정통사주의 뼈대를 유지하고 캐릭터만 추가한다. 이전 app/previews/reading-guide/는 별도 서사 실험 기록이며 본 서비스에 옮기지 않는다. 한 명식 고정 견본이며 실제 결과 서비스 페이지는 이번에 바꾸지 않는다.

자료: 비공개 api/jt-pyo의 기존 응답 함수로 양력 1992-04-21 00:20 대구 남성의 story를 생성했다. 현재 공개 jeongtong-model-reading / jeongtong-story / jeongtong-pyo.css를 직접 재사용한다. 제목·개인별 문장·필터 순서·12개 조건의 5개 묶음·누적 비율·근거·운 흐름·공유 카드가 기존 화면 그대로다. 법전63조(관점은 새로 계산하지 않음),64조(고전 관점 그대로 전달). 비율이나 새 판정값을 만들지 않는다.

표현: 자연 스크롤. 넓은 화면에서는 기존 본문 폭을 유지하고 오른쪽 여백에 인물을 둔다. 읽고 있는 필터에 따라 시선·자세가 바뀌고 해당 카드의 테두리만 강조한다. 모바일에서는 첫 소개·필터 입구·조건을 모은 결론의 세 곳에 배치한다. 본문 위에 고정해서 덮지 않는다. 원래 화면과 비교할 수 있는 캐릭터 숨기기 단추는 견본 전용이다. 공유·근거 펼치기·운 흐름 탭은 기존 코드를 사용하며, 돈·연애·일 상세 풀이도 기존 모듈을 펼칠 때 불러온다.

현재 자세: 얇은 수첩을 펼쳐 읽기 → 수첩에서 도형으로 시선 옮기기 → 덮어 들기. 손은 표지 뒤와 아래에서 책을 자연스럽게 받친다. 손목을 과하게 꺾거나 손가락 제스처를 만들지 않는다. 경계는 진지한 표정, 종합은 옆으로 물러나는 동작으로 전달한다. 첫 화면에도 같은 원칙을 적용한다.

이미지: built-in image_gen, 기존 인물 정체성 보존. 생성 프롬프트와 최종 자산 경로는 별도 생성 기록에 보존. 원본 이미지 보존, 새 파일명으로 참조 변경.
