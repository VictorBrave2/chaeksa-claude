# 정통사주 캐릭터 전달 견본

2026-10-27 사용자 승인: 캐릭터는 의사전달 도구. 고객 화면에는 「본질의 남신」 등 제작용 역할명을 노출하지 않는다. 이용자의 해석을 먼저 보여주고 캐릭터는 강조·연결·경계·물러나기를 담당한다.

추가 교정: 집게손 금지. 엄지와 검지를 가까이 맞대거나 C자 모양으로 작은 것을 잡는 손, 손가락 하트, OK 제스처를 사용하지 않는다. 현재 정통사주 전달 견본은 손이 보이지 않는 자세로 제작한다. 기존 다섯 신 견본의 삽화·시트·동작 문구도 교체한다.

견본: app/previews/reading-guide/. 한 명식 고정 견본이며 전체 이용자 엔진 연결은 다음 범위. 실제 결과 서비스 페이지는 이번에 바꾸지 않는다.

자료: 기존 cumulative-portrait/source-evidence.json의 확정 판정과 app/previews/guide-motion/의 풀이. 법전63조(관점은 새로 계산하지 않음),64조(고전 관점 그대로 전달). 신약+인성 → 정관격의 관인 연결 → 성격의 세 근거 → 강한 수의 부담 → 종합. 비율이나 새 판정값을 만들지 않는다.

표현: 자연 스크롤. 도형에 앞선 조건이 남고 새 연결이 더해진다. 캐릭터 자세는 공통 소재, 문장과 강조 대상은 데이터. 마지막에 인물이 뒤로 물러나 결과가 중심이 된다. 줄과 노드 크기는 정량 지표가 아니다.

현재 자세: 양손을 등 뒤에 두어 자연스럽게 가린다. 손을 화면 밖으로 잘라 숨기지 않는다. 발견은 시선과 고개, 연결은 몸의 방향과 도형, 경계는 진지한 표정, 종합은 옆으로 물러나는 동작으로 전달한다. 첫 화면에도 같은 원칙을 적용한다.

이미지: built-in image_gen, 기존 인물 정체성 보존. 생성 프롬프트와 최종 자산 경로는 별도 생성 기록에 보존. 원본 이미지 보존, 새 파일명으로 참조 변경.
