# DES-0009 — 나의 이름과 운의 흐름

- 요청: 2026-10-25 사용자 「원국에서 합화가 완성되지 않아도 운에서 조건이 오면 성질이 발휘된다」 → 「다시 만들어볼 전략을 짜고 진행」.
- 이번 결과물: 사장님 명식 한 벌을 처음부터 끝까지 읽는 개인 견본. 같은 표시 모듈로 가상 인물 네 명도 제공한다. 운영 적용에 앞서 새 구조를 검수할 수 있게 한다.
- 공개 견본: `ref/DES-0009-preview.html`. 실제 출생 정보와 개인 견본은 공개 저장소 밖 Codex 시각화 폴더에만 저장한다.

## 전략

1. **이름** — 누구에게나 대표 이름 하나. 고전 격명과 그 구조에서 풀어 붙인 문장형 이름을 함께 보여 준다. 문장형 이름을 고전의 정식 명칭이라고 소개하지 않는다.
2. **바탕과 조건** — 지금 가진 것 / 운에서 보태지는 것을 도식으로 연결한다. 고전의 조건부 이름을 비해당이라는 이유만으로 지우지 않는다. 출생 명식에서 성립한 것과 기다리는 조건을 명시한다.
3. **해·달·날·시간** — 큰 흐름, 해, 달, 날, 시를 각각 보여 준다. 처음에는 가까운 달. 서로 다른 시간 규모를 같은 강도로 읽지 않고 하나가 왔다고 전부 성립했다고 표시하지 않는다.
4. **근거** — 원문, 출생 조건, 날짜 산출 기준, 비율은 접어서 마지막에 둔다. 본문은 이름 하나·설명 한두 줄·도형으로 읽는다.

## 개인 견본의 쟁점

- 기존 결과의 정관격과 「관이 인으로 돌아 나에게 온다」라는 근거에서 문장형 이름을 만든다. 기존 판정을 새 판정으로 바꾸지 않는다.
- 丁·壬과 甲辰이 있는 경우 正化 見辰을 조건부 대목으로 남긴다. 이 표제는 기존 목록의 표제이며 『삼명통회』가 독립된 격명으로 명명했다는 뜻은 아니다.
- 辰월 출생을 亥·卯·未·寅월 출생으로 바꿔 읽지 않는다. 운의 亥·卯·未·寅은 목을 돕는 조건의 도래만 표시한다. 합화 완성·고지능·공명 확정으로 승격하지 않는다.
- 사용자가 말한 「머리가 잘 돌아간다」는 개인 견본의 관찰로만 연결한다. 다른 사람에게 일괄 복제하지 않는다.
- 이 해석은 사용자의 이번 지시로 만든 고전 조건 렌즈이다. 법전 43조의 기존 합거 계산을 몰래 고치지 않는다.

## 날짜와 데이터

- 생년월일 → 기존 비공개 `brain-saju` / `api/jt-pyo` 함수를 로컬에서 호출한 값. 새 사주 엔진을 만들지 않는다.
- 미래 간지·절입 시각은 기존 `ChaeksaEngine.calc`, `dateFortune`, `fmt.termsOfYear` 값. 연도는 입춘, 달은 절기, 날은 표시일 정오의 일주로 찾는다.
- 시의 구간은 출생지와 같은 경도·시각 보정 설정으로 계산한다. 시계로 표시하는 지역을 함께 적는다. 날짜 경계는 종전 엔진 기준이며 날짜별 목록이 하루 전체 동일 조건이라는 뜻은 아니다.
- 다른 명식은 기존 조후의 필요 글자와 운 천간의 일치만 연결한다. 한 글자가 온다는 사실을 종합적인 길흉·기능 향상으로 읽지 않는다.
- 대운은 기존 반환값을 표시하며, 시작 나이 80 미만만 사용한다. 성패는 사람의 등급으로 제시하지 않는다.
- 비율은 종전의 표본 기준과 해당수를 보존한다. 조건부 이름의 비율을 완성된 귀격의 비율로 제시하지 않는다.

## 설계 질문에 대한 답

- 다른 명식에도 이름이 생기는가: 기본 격 10갈래를 모두 대응하고, 판정이 없으면 계산한 일간의 고전 이름으로 표시한다.
- 모든 사람을 희귀격이라고 칭하는가: 아니다. 기본 이름은 누구나, 고전의 추가 대목은 조건과 함께 제시한다.
- 계산할 수 있는 날짜를 손으로 썼는가: 아니다. 가까운 날짜는 기존 역법에서 산출한다.
- 조건이 온 것과 성립을 혼동하는가: 미래 카드에는 일치한 글자·규모만 표시한다. 합화 완성 판정을 생성하지 않는다.
- 이번에는 무엇을 검수하는가: 이름을 받은 느낌, 조건과 시기의 연결, 말의 밀도와 도형의 분위기.

## 표현 기준 — 사용자 검수 반영

- 「때」를 모든 조건·날짜·변화에 반복해서 붙이지 않는다.
- 조건은 「운에서 더해지는 글자」, 작용은 「목의 기운을 받쳐 주는 네 글자」처럼 실제 대상을 쓴다.
- 寅·卯·未·亥 카드에는 「인목·묘목·미토·해수」를 붙인다. 「인의 때·묘의 때」를 쓰지 않는다.
- 날짜 표시는 가장 가까운 해 / 달 / 날 / 다가오는 시간으로 구체화한다.
- 「그 가능성에 때가 보태는 것을 봅니다」는 「타고난 바탕은 같아도, 운에서 더해지는 글자는 달라집니다」로 고친다.

## 생각과 행동으로 쓰기 — 사용자 검수 반영

- 「목의 기운을 받쳐 준다」에서 멈추지 않고, 읽는 사람이 경험할 생각·행동을 각각 한 문장으로 쓴다.
- 사장님 개인 견본: 생각 = 복잡하던 생각이 정리되고 문제의 핵심이 잡힘 / 행동 = 이해한 내용을 말·글로 꺼내기 수월함.
- 근거는 사용자 관찰과 기존 이름 풀이를 확장한 해석 초안이다. 고전이 이 행동을 그대로 적었다거나 검증된 예측이라고 표시하지 않는다.
- 한자·조건 도식은 「이 변화를 읽은 글자와 조건」에 접어 두고, 날짜 카드에도 사람 말로 연결한다.
- 다른 명식에 같은 행동을 일괄 복제하지 않는다. 공용 표시 모듈에 experience 자료를 받을 수 있게 했다.

- 사용자 용어 수정: 견본의 「섰다」는 「성격」으로 표시한다. 도형·근거·대운·표본 조건에 같은 표시 함수를 적용하고 원래 계산 값은 보존한다.

## 희소성 도형 — 사용자 검수 반영

- 비율을 근거 접힘에만 두지 않는다. 가운데에는 네 조건 조합 비율과 해당수/표본수, 꼭짓점에는 개별 특징의 비율을 직접 표시한다.
- 도형 아래에는 네 조건을 차례로 겹친 누적 해당 수를 연결한다. 개별 특징 비율과 누적 비율을 섞지 않는다. 강약은 꼭짓점에는 포함하고 가운데 네 조건 조합에는 포함하지 않는다.
- 개인 견본: 가운데 0.02% · 11/60,000, 누적 6,700 → 3,911 → 909 → 11. 표본 값은 바꾸지 않는다.

## 표본 표기의 위치 — 사용자 검수 반영

- 도형 중앙의 11/60,000 표기를 제거한다. 중앙 조합 비율·꼭짓점 개별 비율은 유지한다.
- 도형 아래 누적 개수는 「비율 산출 기준과 표본」으로 옮긴다. 도형 바로 아래 「비교 명식 기준 · 산출 기준 보기」를 제공해 직접 열 수 있다.
- 수치의 출처와 한계는 계속 공개한다. 실제 인구 비율로 바꾸어 소개하거나 표본수를 늘린 것처럼 표현하지 않는다.
