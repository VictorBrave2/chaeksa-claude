# 디자인 요청 — 책사(chaeksa.kr) × 디자인 담당(GPT · Codex)

2026-10-22 사장님 「디자인 부분은 진짜 gpt한테 다 맡기고 싶노」로 정한 길입니다. 그림 한 장은 `../image-requests/`, 손님 글은 `../copy-requests/`, 화면 모양(배치 · 색 · 글자 크기 · 칸 꼴)은 이 폴더입니다. 이 폴더는 공개 저장소에만 있고 웹사이트에는 나가지 않습니다(사이트는 `app/`만 내보냅니다).

## 흐름

1. **Claude Code(책사 쪽)** — 고칠 화면을 명세 한 장(`DES-0001-이름.md`)으로 씁니다. 지금 화면 사진(`ref/`), 고칠 수 있는 파일, 지킬 것, 끝났다고 볼 기준을 적고 `INDEX.md`에 한 줄 더해 커밋합니다.
2. **사장님** — 디자인 담당에게 「DES-0001 확인해」라고 전합니다.
3. **디자인 담당** — 가지 `design/DES-0001`에서 명세에 적힌 파일만 고쳐 올리고 PR을 엽니다. 저장소 쓰기 권한이 없으면 고친 파일을 사장님께 드리고, 사장님이 Claude Code에게 넘깁니다. 상태를 `제안됨`으로 바꿉니다.
4. **Claude Code** — 시험(검사기 · 시험 쪽)과 폰 화면을 확인하고, 명리 뜻이 든 말은 원문과 맞는지 본 뒤 합칩니다. 상태를 `적용됨`으로 바꿉니다. 고칠 곳이 있으면 PR에 적어 돌려보냅니다.

## 지킬 것(모든 요청 공통)

- **명세에 적힌 파일만** 고칩니다. 계산 · 판정 · 결제 · 로그인 코드는 건드리지 않습니다.
- **색은 `app/style.css`의 변수(`--ink` · `--accent` · `--card` …)만** 씁니다. 쪽 안에 새 색값(#hex)을 박지 않습니다.
- **두 테마 모두** — 낮(아침 한지)과 밤(새벽 인디고, `:root[data-theme="night"]`)에서 다 읽혀야 합니다.
- **폰이 먼저** — 폭 360~430px에서 글자가 칸 밖으로 넘거나 말이 중간에서 끊기지 않아야 합니다. 그다음 PC.
- **손님 글은 고치지 않습니다.** 명세가 「말 제안」을 부탁한 낱말만 바꿀 안을 냅니다. 명리 뜻이 든 말(별 · 궁 · 밝기 이름 등)은 안을 내면 책사 쪽이 원문 뜻과 대 보고 넣습니다.
- 새 외부 글꼴 · 라이브러리 · 빌드 도구를 붙이지 않습니다. 줄 끝은 CRLF 그대로 둡니다.
- 사장님 · 손님의 생년월일이나 사연은 명세 · 그림 · 코드 어디에도 넣지 않습니다. 화면 사진은 지어낸 가족으로 만든 견본입니다.

## 상태

`요청` → `제안됨` → `적용됨`, 그만두면 `취소`. 작업 ID는 `DES-` + 네 자리(`DES-0001`부터), 한 번 쓴 번호는 다시 쓰지 않습니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `INDEX.md` | 요청 목록(같은 화면을 두 번 요청하지 않게) |
| `TEMPLATE.md` | 명세 틀 |
| `DES-0001-이름.md` … | 요청 명세 |
| `ref/` | 지금 화면 사진 · 본보기 |
