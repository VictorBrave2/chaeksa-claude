# 타로 카드 동작 개선 — 2026-10-31

요청: 「타로카드를 고르는 애니메이션이 재미가 없어」.
기준: main 4216a105(v1533). 상태: 구현·견본 작성, 라이브 미반영.

## 달라진 경험

- 카드 더미 자체를 누르면 13장의 뒷면이 부채처럼 펼쳐진다.
- 카드 사이를 눌러 세 번 나눈다. 누른 위치에 따라 좌우가 갈라지고 진행 표시가 찬다.
- 버튼으로도 같은 동작을 할 수 있다. 키보드 초점과 동작 줄이기 설정을 지원한다.
- 셔플 1.05초, 나누기 0.64초. 동작 중 입력을 잠그고 셋째 나누기도 끝난 뒤 요청한다.
- 질문이나 사람을 바꾸면 이전 동작의 늦은 콜백은 진행하지 않는다.
- 회색 대기 막대 대신 카드 뒷면으로 기다림을 이어간다.
- 열 장은 뒷면으로 각 자리에 들어와 차례로 뒤집힌다. 열째는 2.15초에 등장해 약 2.9초에 뒤집힘을 마친다.
- 설명과 결과 버튼은 3초 뒤 나타난다. 근거 안 정적 판은 기존 표시를 유지한다.

## 계산과의 경계

화면의 13장 부채는 77장 덱을 다루는 동작을 표현한 것이다. 눌린 위치는 분할 연출에만 쓰며 서버가 반환한 카드·순서·방향·길흉을 변경하지 않는다. 섞기 1회·나누기 3회, 필요한 경우 재펼침 1회 규칙을 유지한다. 캐시·기간·서버 호출 몸통·계산 코드 변경 없음. 새 삽화 생성 없음.

## 파일

- app/three.js — 카드 직접 누름, 완료 콜백, 뒤집기 마크업, 대기 표시.
- app/three.css — 부채·나누기·순차 뒤집기·동작 줄이기.
- app/three-pieces.js — 행동 안내 6칸만 추가.
- app/previews/tarot-touch/ — 실제 렌더러를 쓰는 독립 견본. 고정된 가상 카드, API 호출 없음. 외부판 iframe은 저장 접근을 막고, 화면만 열어도 매번 고유한 가상 프로필을 쓴다.

## 확인 범위와 인계

JavaScript 문법 확인만 수행. 자동 시험과 실제 구매자·사용자 프로필 검사는 실행하지 않았다. 계산 규칙은 이번 작업에서 고치지 않았다.
