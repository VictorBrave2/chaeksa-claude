## 무엇이 문제인가

- 사장님이 폰에서 보고 「디자인 부분은 GPT에게 맡기고 싶다」고 했습니다. 칸이 좁아 별 이름 · 밝기 · 변화(화록 등)가 빽빽하고, 한눈에 무엇이 중요한지 안 보입니다.
- 사진의 첫 판은 밝기 말이 칸 안에서 중간에 끊겼습니다(「제자리 못 / 얻음」). 10-22에 Claude Code가 임시로 「별마다 한 줄 · 밝기는 그 아래」로 고쳐 올렸습니다(v1401). 이 임시 판을 출발점으로 삼아 주세요.
- 밝기 일곱 말 가운데 「제자리 못 얻음」이 어색합니다(사장님).

## 바라는 것

- 폰(360~430px)에서 4×4 판이 한눈에 읽힙니다 — 칸마다 **궁 이름 · 그 궁이 보는 것(쉬운 이름) · 중심 별 · 밝기 · 변화 · 10년 운 나이**가 서로 섞이지 않게.
- 「나를 보는 칸(명궁)」이 판에서 바로 눈에 띕니다.
- 가운데 2×2 칸(설명 다섯 줄)과 판 아래 풀이 글이 판보다 시끄럽지 않습니다.
- 출산택일 보고서 판과 무료 명반 쪽 판이 같은 집안처럼 보입니다(무료 쪽은 궁 · 별을 누르는 단추가 있어 마크업이 다릅니다 — 단추는 그대로 두고 모양만).
- 낮(아침 한지) · 밤(새벽 인디고) 테마 둘 다.

## 화면에 오는 값(바꾸지 않음)

출산택일 보고서 판은 서버가 노드 하나로 보냅니다(`k: 'mb'`). 디자인 담당은 이것을 어떻게 보여 줄지만 정합니다.

```
{ k: 'mb', 머리: '1번 · 4월 12일(월) 오전 7시 33분 ~ 9시 32분',
  자리: ['巳','午','未','申','辰',null,'酉','卯','戌','寅','丑','子','亥'],   // 4×4 차례, null = 가운데 2×2
  칸: [ { 지:'子', 지말:'자', 궁:'명궁', 쉬운:'나', 나:true, 몸:false,
          주성:[ { 이름:'태양', 밝기:'빛 잃음', 화:'' } ],
          보조:[ { 이름:'좌보', 화:'' } ],
          대한:'3~12세' }, … 열둘 ],
  가운데: ['1번 아이의 명반', '나를 보는 칸(명궁) — 자 자리', '몸이 머무는 칸(신궁) — 재백궁(돈)', '오행국 — 목삼국', '10년 운(대한) — 3세에 형제궁에서 시작'],
  풀이: '칸마다 큰 글자는 …', 작게: '밝기 원문: 廟 · 旺 · …' }
```

- `화`는 `화록` · `화권` · `화과` · `화기` 넷 가운데 하나이거나 빈 칸입니다.
- `밝기`는 아래 일곱 말 가운데 하나이거나 빈 칸입니다.

## 말 제안 — 별 밝기 일곱 말

지금 말과, 그 말이 줄인 원래 뜻(무료 명반 쪽 글, 10-06 작가)입니다. **칸에 들어갈 짧은 말(네 글자 안팎)** 로 일곱 개 안을 내 주세요. 밝은 쪽에서 어두운 쪽으로 차례가 그대로 읽혀야 하고, 뜻을 더하거나 빼면 안 됩니다. 책사 쪽이 원문 뜻과 대 보고 넣습니다.

| 원문 | 지금 말 | 원래 뜻(무료 명반 쪽 글) |
|---|---|---|
| 廟 | 가장 밝음 | 내 명반에서 가장 밝은 자리(入廟) |
| 旺 | 밝음 | 밝은 자리 |
| 得地 | 밝은 쪽 | 제자리를 얻어 밝은 쪽에 선 자리 |
| 利益 | 조금 밝음 | 조금 밝은 자리 |
| 平和 | 보통 | 밝지도 어둡지도 않은 자리 |
| 不得地 | 제자리 못 얻음 | 제자리를 얻지 못한 자리 |
| 落陷 | 빛 잃음 | 빛을 잃은 자리(陷 · 落陷) |
