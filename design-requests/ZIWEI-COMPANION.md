# 정통자미두수 · 기존 화면에 캐릭터 추가 견본

사용자 요청: 정통사주 캐릭터 배치 견본과 같은 기준으로 정통자미두수 견본을 만든다.

견본: `app/previews/ziwei-companion/`. 양력 1992-04-21 00:20 대구 남성의 기존 엔진 응답을 고정한다. 서비스 화면을 교체하지 않는다.

## 유지한 것

- 명반이 맨 위에 나오는 순서, 열두 궁·별의 위치, 별·궁을 눌러 여는 풀이와 뒤로 가기.
- 기존 개인별 제목·본문·좋은 조건·같은 분야의 경계·누적 비율·고전 근거·열두 분야 전체 풀이.
- `myeongban-copy/prose/reading/editorial/filter`와 공통 스타일을 직접 재사용한다.
- `renderer.js`는 현행 `myeongban.js`의 견본 사본이다. 데이터 주소만 고정 JSON으로 바꾸고 같은 입력으로 처음 그리도록 연결했다. 기존 프로필을 읽거나 저장하지 않는다. 클릭 안내를 봤다는 서비스 설정도 저장하지 않는다.
- 서버 계산은 기존 `api/myeongban.응답` 호출. 개인 식별용 표 값은 공개 견본에서 제외한다. 판정·조건·표본을 새로 만들지 않는다.

## 캐릭터가 크게 등장하는 세 장면 (2026-10-28)

사용자 지적: 구석의 작은 캐릭터로는 존재감이 부족하다. 승인한 방향은 기존 구조 안의 큰 장면 세 곳이다.

- 명반과 계산 정보를 먼저 둔다. 그 다음 첫 개인별 제목과 큰 캐릭터를 한 장면으로 묶는다.
- 두 번째 이야기의 시작에서 기존 분야명과 제목 옆에 수첩에서 시선을 든 자세를 배치한다.
- 마지막 요약에서는 책을 덮어 든 자세와 기존 결론을 함께 보여 준다.
- 모바일에서도 얼굴과 표정이 보이는 크기(그림 폭 약 216~228px)로 배치한다. 본문 조건과 수치는 원래 폭을 유지한다.
- 명반 중앙, 팝업, 화면 옆 고정 레일의 작은 인물은 없앴다. 기존 별·궁 풀이 창을 그대로 사용한다.
- 제목과 본문은 새로 쓰거나 복제하지 않고 기존 DOM을 장면 안으로 옮긴다. 데이터와 계산은 변경하지 않는다.
- 캐릭터 숨기기를 누르면 장면 포장도 풀려 기존 본문 배치로 돌아간다.
- 스크롤로 장면에 닿으면 인물이 짧게 나타난다. 모션 줄이기 설정을 따른다. 제작용 신 이름은 손님 화면에 표시하지 않는다.
- 공개 견본 주소: https://chaeksa.kr/previews/ziwei-companion/?v=3#zd-reading

## 삽화 교체 (2026-10-28)

사용자 지적: 화질이 낮고 가슴이 과장되며 내려보는 눈이 감겨 보인다.

- 세 자세를 각각 1024×1536 RGBA 이미지로 재생성했다. 기존 시트는 보존한다.
- 가슴의 볼륨을 줄이고 눈동자가 보이는 열린 눈으로 수정했다. 얼굴·단발·의상·수첩의 정체성은 유지한다.
- 새 자산: art/notebook-reading-v3.png, notebook-explaining-v3.png, notebook-closing-v3.png.
- 도구는 built-in image_gen, 프롬프트 전문은 art/image-prompts-v3.txt에 기록한다.

## 실제 서비스 적용 (2026-10-28)

사용자가 견본 v3 승인 후 진행을 요청하여 정통자미두수 실제 화면에 적용한다.

- myeongban-companion.js/css를 서비스에 연결하고 매번 이용자 결과를 그린 직후 해당 제목과 조건 DOM에 장면을 붙인다.
- 견본의 생년월일이나 result.json은 서비스에서 사용하지 않는다.
- 이야기 2개 이상이면 세 장면, 1개면 첫 해석과 마지막 요약만 배치한다. 좋은 조건이 없거나 구형 결과라면 기존 결과를 유지한다.
- 삽화 숨기기/보기, 모션 줄이기, 장식 이미지의 빈 대체문자, 지연 로딩, 이미지 실패 시 본문 폭 복원을 적용한다.
- 이미지 경로: app/art/ziwei-companion/의 notebook-reading-v3.png, notebook-explaining-v3.png, notebook-closing-v3.png.
- 변경한 서비스 파일만 내용 지문을 갱신했다. tools_bust.py의 등록 목록에도 추가한다.
