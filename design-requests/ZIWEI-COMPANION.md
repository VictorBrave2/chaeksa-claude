# 정통자미두수 · 기존 화면에 캐릭터 추가 견본

사용자 요청: 정통사주 캐릭터 배치 견본과 같은 기준으로 정통자미두수 견본을 만든다.

견본: `app/previews/ziwei-companion/`. 양력 1992-04-21 00:20 대구 남성의 기존 엔진 응답을 고정한다. 서비스 화면을 교체하지 않는다.

## 유지한 것

- 명반이 맨 위에 나오는 순서, 열두 궁·별의 위치, 별·궁을 눌러 여는 풀이와 뒤로 가기.
- 기존 개인별 제목·본문·좋은 조건·같은 분야의 경계·누적 비율·고전 근거·열두 분야 전체 풀이.
- `myeongban-copy/prose/reading/editorial/filter`와 공통 스타일을 직접 재사용한다.
- `renderer.js`는 현행 `myeongban.js`의 견본 사본이다. 데이터 주소만 고정 JSON으로 바꾸고 같은 입력으로 처음 그리도록 연결했다. 기존 프로필을 읽거나 저장하지 않는다. 클릭 안내를 봤다는 서비스 설정도 저장하지 않는다.
- 서버 계산은 기존 `api/myeongban.응답` 호출. 개인 식별용 표 값은 공개 견본에서 제외한다. 판정·조건·표본을 새로 만들지 않는다.

## 더한 것

- 넓은 화면: 본문 폭을 유지하고 오른쪽에 담당 캐릭터를 둔다. 현재 읽는 분야에 따라 자세와 기존 제목 표시가 바뀐다.
- 모바일: 명반 중앙의 여백, 필터 입구, 결론에 작은 인물을 둔다. 별과 궁의 단추를 덮지 않는다.
- 별·궁 풀이: 기존 시트의 머리 옆에 작은 인물을 추가한다. 말풍선이나 새 해석은 추가하지 않는다.
- 캐릭터 숨기기로 원래 배치와 비교한다. 제작용 신 이름은 손님 화면에 표시하지 않는다.
- 수첩 읽기·명반 바라보기·책 덮어 들기. 집게손·손가락 하트·OK 손동작 금지. 모션 줄이기 설정을 따른다.
