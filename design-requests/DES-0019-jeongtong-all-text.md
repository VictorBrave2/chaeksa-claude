# DES-0019 정통사주 전체 문장 정리

## 요청

2026-10-26: 정통자미두수와 같은 기준으로 정통사주의 전체 문장을 정리한다. 강한 표현을 그대로 살리고 일반인이 쉽게 읽게 한다. 기존 실행·배포 위임에 따라 라이브까지 반영한다.

## 범위와 원칙

- 개인별 좋은 조건 필터: 고전별 짧은 뜻과 해당 조건을 구체적으로 표현한다.
- 이름·가능성·날짜별 흐름: 표시 문구만 다듬고 계산 조건을 유지한다.
- 펼쳐 읽는 열두 장 상세 풀이와 귀함의 추가 근거, 입력·빈 결과·오류·공유 안내를 함께 읽는다.
- 강도, 주체, 수량, 시기, 조건, 예외를 보존한다. 고전의 죽음·형벌·가난 등을 완곡하게 바꾸지 않는다. 원문에 없는 사건이나 성취를 추가하지 않는다.
- 쉬운 뜻 → 내 조건 → 정확한 원문 순서로 읽는다. 원문과 계산값은 보존한다.
- 공개 표시 모듈에서 문장을 바꾼다. 비공개 판정 코드·조건표를 공개하지 않는다.
- 개인화콘텐츠 스킬의 작가 → 교차 검수 순서로 진행한다. 별도 테스트 스위트는 실행하지 않는다.

## 구현 기록

- 고전 목록 882개와 기존 원고 362개를 읽고, 표시용 원고 456개를 구성했다. 기존 원고 342개를 고쳤고, 원고가 없던 실제 일치 가능 항목 94개에 각 원문 뜻을 넣었다. 적용이 불명확한 항목을 새로 성립시키지는 않는다.
- 전문은 공유 공급 파일을 바꾸지 않고 정통사주 전용 한국어 절·문장표 191개를 연결했다. 한자 원문·명식 표는 제외하며, 이미 고친 문장은 다시 치환하지 않는다.
- 개인별 표시 모델은 원본을 보존한 복사본에서 이름·풀이만 바꾼다. 본문과 공유 카드는 같은 복사본을 사용한다. 비공개 서버와 계산 코드는 수정하지 않는다.
- 소개 페이지는 분야 표의 소개 물음·차례를 읽도록 생성기를 보완했다. 예전 상세 열두 장만 나열하던 차례를 현재의 필터·운·심화 순서에 맞췄다.

## 교차 검수

- 성격을 모든 글자의 역할 발휘로 확대했던 문장을 기본 구성의 성립으로 좁혔다.
- 군자와 보통 사람의 주체 분기, 시각별 분기와 必, 多主·多為, 옛 수량 단위, 不利·惟可와 필수 월령 단서를 대조했다.
- 화개 一生不利財物, 괴강 秉權好殺, 건강 發狂·失眀의 강한 표현은 실제 원문에서 확인했다.
- 첫 화면의 기본 필터도 별도로 검수했다. 신약 자체를 좋은 조건으로 만들지 않고, 이인동심을 두 사람의 관계로 풀지 않는다.
- 같은 구절에 붙은 경계도 보존했다. SM06B-145의 아내에게 해가 됨·독약으로 목숨을 잃음은 숨기지 않고, 원문만으로 불명확한 독살 가해자는 새로 정하지 않는다. 최종 교차 검수에서 막는 것 0이다.
