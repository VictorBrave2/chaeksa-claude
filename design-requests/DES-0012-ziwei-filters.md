# DES-0012 · 자미두수 필터 콘텐츠

2026-10-26 · 사용자 요청: 정통사주처럼 자미두수도 필터식 콘텐츠로 만든다.

## 흐름

1. 내 명반의 명궁 주성을 한글로 보여 준다.
2. 《자미두수전서》가 좋게 본 조건 중 완전히 해당하는 조건만 쌓는다.
3. 이 줄까지 모두 해당하는 비교 명반 비율을 각 카드와 막대로 보여 준다.
4. 왜 해당하는지 펼치면 원문, 번역, 내 명반의 판정 근거와 출처가 나온다.
5. 「당신은 귀한 사람입니다.」로 마친다.
6. 기존 열두 궁과 전체 구절은 아래에서 펼친다.

## 엔진과 표본

- 기존 `wonmun-rules.js`의 길한 구절 중 준비한 65조건. 같은 의미의 여러 원문은 OR로 하나에 묶는다.
- 기존 조건 함수가 「걸림」을 반환할 때만. 「일부」, 방법, 후속 판정, 유년 전제가 필요한 줄은 누적 조건에서 제외.
- 사람마다 해당 항목 수가 다르며 임의의 다섯 칸을 채우지 않는다. 일치 항목이 없으면 없음 그대로 표시하고 명반으로 이어진다.
- 비교 자료 51,840개: 1950~2009년, 매월 1·11·21일, 홀수 시각 1~23시/분0, 남녀 각각, 서울. 기존 음력·진태양시 정책 그대로.
- 매 단계 같은 자료의 비트 집합 교집합. 각각의 비율을 곱하지 않는다. 같은 비율을 억지로 낮추지 않는다.
- 실제 인구 비율·능력 점수가 아니다. 자료에 없는 조합은 「비율 미산정」. 수치 방법은 접힘에서 설명한다.
- 계산·조건 원본 지문이 변하면 비교 자료를 다시 만들어야 한다. 구판 비율을 조용히 이어 쓰지 않는다.
- 길한 한 구절이 명반 전체 판정이나 실제 성취를 보장하지 않는다. 부정·혼합·부분 구절도 기존 명반에 남는다.
- 옛 책의 실제 격 이름만 전통 이름으로 표시. 편집 제목은 격국으로 지어 부르지 않는다.

## 구현

- 비공개 `jamidusu/ziwei-filter.js`, 비교 지수와 재생성 도구.
- 기존 `/api/myeongban`에 `filterStory` 추가. 기존 키 보존. 추가 AI 호출 없음.
- 공개 `app/myeongban-filter.js`, `app/myeongban-filter.css`, 기존 `myeongban.js/html`에 연결.
- 밝은 종이·먹·금색, 세로 스크롤, 카드마다 누적 비율, 본궁/전체 구절은 접힘.
- 가상 생년월일로 실제 API와 화면 제작을 확인. 별도 테스트 스위트는 실행하지 않았다.

## 결정

좋은 구절을 무조건 모두 자동 승격하지 않고 준비한 조건만 사용한다. 질병·가족 수 등은 이 강점 목록의 재료로 삼지 않는다. 장수 등이 함께 들어 있는 원문은 출처 펼침에서 뜻을 자르지 않는다.
