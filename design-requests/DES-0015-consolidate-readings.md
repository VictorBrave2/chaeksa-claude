# DES-0015 · 중복 콘텐츠 통합

2026-10-26 · 사용자: 정통사주와 귀함·고전 이름 콘텐츠가 겹치므로 정리한다.

## 대조 결과

- 고전 이름: 옛 희귀 목록 362항목 중 361항목이 정통사주 누적 필터의 비교 목록에 이미 포함된다. 남은 `SM06B-061`(正化見辰)은 합화 전제 문제로 정통사주에서 제외한 항목이므로 다시 살리지 않는다.
- 귀함: 정통사주의 「좋은 조건을 모아 귀함을 읽는다」는 질문과 입구가 겹친다. 다만 구판의 적천수 귀함 7·주의 4조건과 책사 구조 기준은 완전히 같은 판정이 아니다. 이 부분은 정통사주 아래 접힌 추가 근거로 옮긴다.
- 총명함: 정통사주의 재능·배움 구절과 부분적으로 겹친다. 고전 34조건 및 자미두수 집중 분석은 별도 근거가 있으므로 없애지 않고 정통사주 안의 심화 링크로 연결한다.

## 적용

1. 홈·전체 목록·내 사주 선택 목록에서 귀함·고전 이름·총명함 세 개의 독립 입구를 뺀다.
2. 고전 이름은 기존 정통사주 필터에서 읽는다.
3. 귀함의 별도 기준은 정통사주 「근거를 더 살펴보고 싶다면」에서 필요할 때만 기존 `/api/gwi`로 불러온다. 기존 계산·출처를 재사용하고 누적 비율에 합산하지 않는다.
4. 실제로 해당하는 고전의 긍정 조건과 주의 조건을 함께 보존한다. 불일치 조건도 접어서 확인할 수 있다. 사람의 우열을 새로 판정하지 않는다.
5. 머리 집중 분석은 같은 절의 링크로 연결한다. 그 페이지의 돌아가는 길도 정통사주로 둔다.
6. 기존 `gwi.html`, `gyeokgi.html` 주소는 정통사주로 안내·이동한다. 검색 중복을 막기 위해 noindex와 canonical을 넣고 사이트맵에서 제외한다.

## 남기는 입구

- 정통사주: 고전 이름·좋은 조건·귀함의 근거·나의 흐름.
- 정통자미두수: 별의 배치로 읽는 별도 체계.
- 내 운은 언제 풀릴까: 지난 해 확인과 자미두수 기준의 앞으로 10년 집중 보기. 나를 알아보기 묶음에 둔다.
- 정통궁합: 두 명식의 고전 조건 비교. 연애궁합은 바람과 행동이 만나는 이야기로 구분한다.
- 나와 잘 맞는 사람: 저장한 여러 사람 비교. 연애의 나·상대 콘텐츠는 각 한 사람의 행동 풀이로 구분한다.
- 유료 콘텐츠·출산택일·읽는 글은 대상과 받는 결과가 달라 유지한다.

홈 독립 콘텐츠는 15개에서 12개로 줄인다. 계산 엔진 변경 없음. 기존 추가 근거만 필요할 때 읽는다. 별도 테스트 스위트 실행 없음.
