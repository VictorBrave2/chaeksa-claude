# DES-0013 · 재방문 홈은 전체 목록

2026-10-26 · 사용자: 「내 사주를 이어서 본다는 게 타당하지 않음. 재방문 시 없어지거나 전체 목록이 나와야 한다」.

## 적용

- 저장한 생년월일을 이용한 단일 「이어서 보기」 카드를 제거한다. 읽던 위치를 확인하지 않았으므로 이어 보기라는 설명이 맞지 않는다.
- 재방문 홈은 전체 콘텐츠 목록을 바로 보여 준다. 생년월일은 콘텐츠를 고른 뒤 기존 입력 경로에서 활용한다.
- 정통사주 · 정통자미두수를 첫 묶음 「나를 알아보기」에 둔다.
- 첫 방문의 목적별 입구 앞에도 두 정통 풀이 입구를 둔다.
- 전체 보기 역시 같은 콘텐츠 순서를 쓴다. 홈·전체 보기의 섹션 ID는 구분한다.
- 「내 명반에는 무엇이 적혀 있을까」를 「정통자미두수」로 바꾸고 페이지·공유 이름도 통일한다.
- 상품 약속 장부에서 이름과 소개 문구를 관리한다.

## 문구

정통사주: 사주팔자에서 찾은 당신의 귀한 조건.

정통자미두수: 별의 배치에서 찾은 당신의 귀한 조건.

## 범위

홈과 콘텐츠 이름·소개·순서 변경. 명리 엔진 변경 없음. 별도 테스트 스위트 실행 없음.
