# DES-0020 정통사주 짧게 읽는 결과

## 요청과 확정

- 사용자는 본인의 첫 화면·필터 다섯 장 견본을 검수하고, 다섯 제목을 직접 교정했다.
- 오행의 많고 적음·없음·필요함은 이용자에게 익숙한 말이다. 목·화·토·금·수로 대상을 구체화하고 배움·직업·재물 등 생활의 뜻으로 이어 쓴다.
- 이번 요청: 다른 무작위 가상 명식으로 견본을 만들고 승인된 구성을 라이브에 반영한다.

## 구현 범위

- 첫 화면에 개인 대표 문장·고전 이름을 앞세운다.
- 첫 다섯 조건은 짧은 결론·고전 이름·누적 비율로 표시하고, 나머지 조건도 펼쳐 읽을 수 있게 보존한다. 사람마다 조건 수는 달라진다.
- 전체 조건의 최종 비율과 앞의 다섯 조건까지의 누적 비율을 구분한다. 모든 값과 순서는 기존 API 결과를 사용한다.
- 개인 조건·뜻·출처·정확한 원문은 펼침에 둔다. 결론을 바꾸는 강한 경계·한정은 짧은 본문에도 남긴다.
- 이전의 운 흐름·상세 풀이·공유 카드·시간 미상·오류 경로를 연결한다.
- 무작위 가상 명식 세 벌을 공개 견본으로 제공한다. 실제 사용자의 출생 정보와 기존 개인 견본은 공개하지 않는다.
- 기존 판정에서 개인별 표시 근거가 필요한 경우 API 응답에 그 결과만 보충한다. 판정 규칙·조건·누적 집계는 수정하지 않는다.

## 사용자 확정 문장

- 사주팔자에 필요한 기운이 있습니다.
- 배운 것이 곧 직업이 될 수 있습니다.
- 팔자가 갖춰야 할 필수조건을 갖췄습니다.
- 배움이 나를 돕습니다.
- 두 가지 기운이 서로 돕습니다.

각 문장은 해당하는 조건에만 사용한다. 다른 격이나 다른 명식에 같은 풀이를 고정하지 않는다.

## 진행

- [ ] 무작위 가상 명식 세 벌 생성
- [ ] 개인별 문구·조건·경계의 작성 및 교차 검수
- [ ] 승인된 첫 화면·필터 표시 연결
- [ ] 가상 견본 및 실제 화면 수동 확인
- [ ] 운영 배포와 증거 저장

별도 테스트 스위트는 사용자가 요청하지 않아 실행하지 않는다.
