# IMG-0139 정통타로 홈 표지

- 내장 image_gen으로 생성. 정통사주 표지와 킹(P14), 세 관점 표지를 얼굴·화풍 참고.
- 최종 원본: tarot-cover.png (1024×1536). 웹용: app/art/menu-guides-v1/tarot.webp, tarot-s.webp (360×540).
- 장면: 남신이 펼친 켈틱 십자형 카드 아홉 장과 손에 든 한 장. 십자 중앙 겹친 두 장, 주변 네 장, 오른쪽 세 장, 든 카드 한 장.
- 375px 실제 홈 견본: home-row.png. 기존 홈 화면을 띄운 뒤 정통타로 그림 주소와 그림 위치만 브라우저에서 임시 교체하여 찍었습니다. 홈 코드에는 적용하지 않았습니다.
- 합칠 때 홈 그림 위치 제안: 50% 42%. 가로로 잘리는 홈 칸에서는 얼굴과 카드판이 함께 보이지만, 아래 카드 일부는 잘려 열 장을 모두 세기는 어렵고 옆 표지보다 얼굴이 작습니다. 완전한 열 장은 세로 원본에서 확인할 수 있습니다.
- 생성 지시: 기존 킹 얼굴과 홈 표지 화풍을 유지해 자연광 아래 열 장 켈틱 십자 펼침, 아홉 장은 책상에 두고 마지막 한 장을 드는 장면. 가로 중앙 자르기에서도 얼굴과 카드판이 함께 들어오도록 구도 조정. 글자·숫자·현대 기기·바깥 테두리 제외.
