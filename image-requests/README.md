# 삽화 요청 — 책사(chaeksa.kr) × 이미지 생성 담당

2026-10-22 사장님이 정한 협업 길입니다. 이 폴더는 **공개 저장소**(github.com/VictorBrave2/chaeksa-claude)에 있고, 웹사이트(chaeksa.kr)에는 나가지 않습니다(사이트는 `app/` 폴더만 내보냅니다).

## 흐름

1. **Claude Code(책사 쪽)** — 삽화가 필요하면 이 폴더에 요청 명세 한 장(`IMG-0001-이름.md`)을 쓰고, `INDEX.md` 목록에 한 줄을 더해 커밋합니다.
2. **GitHub** — 명세와 목록이 저장소에 올라갑니다.
3. **이미지 생성 담당(Codex 등)** — `INDEX.md`에서 상태가 `요청`인 줄을 골라 명세대로 그림을 만듭니다.
4. **GitHub** — 만든 원본을 `image-requests/out/<작업 ID>.png`로 올리고, 그 줄의 상태를 `생성됨`으로 바꿉니다.
5. **Claude Code** — 원본을 받아 사이트 꼴(webp · 작은 판 `-s.webp`)로 바꿔 명세의 「최종 경로」에 두고, 화면에 연결하고, 화면을 확인한 뒤 상태를 `적용됨`으로 바꿉니다.

저장소에 새 요청이 올라와도 생성 담당이 저절로 알아채지는 않습니다. 사장님이 「요청 확인해」라고 한 마디 전해 주시면 됩니다.

## 규칙

- **이미지 생성 API를 부르지 않습니다.** 유료 API를 새로 붙이지 않습니다. 책사 쪽은 명세까지만 씁니다.
- **같은 그림을 두 번 요청하지 않습니다.** 새 요청을 쓰기 전에 `INDEX.md`에서 같은 쓰임 · 같은 최종 경로가 있는지 봅니다. 있으면 그 줄을 고칩니다.
- **작업 ID**는 `IMG-` + 네 자리 차례 번호입니다(`IMG-0001`부터). 한 번 쓴 번호는 다시 쓰지 않습니다.
- **상태**는 넷뿐입니다: `요청` → `생성됨` → `적용됨`, 그만두면 `취소`.
- 원본은 **PNG**, 명세의 비율 · 크기 그대로. 글자 · 로고 · 워터마크를 넣지 않습니다.
- 실존 인물 · 손님 사진 · 남의 상표 · 다른 작품의 캐릭터를 쓰지 않습니다. 모든 인물은 지어낸 사람입니다.
- 손님의 생년월일 · 이름 · 사연을 프롬프트에 넣지 않습니다.

## 화풍(지금 사이트 삽화)

- 2020년대 한국 로맨스 · 일상 웹툰 표지 느낌 — 부드러운 채색, 맑은 피부 표현, 섬세한 선, 따뜻한 빛.
- 기본 비율은 세로 2:3(1024×1536). 가로 띠가 필요하면 명세에 따로 적습니다.
- 맞출 본보기: `app/art/story-sanggyeonrye.webp`(상견례) · `app/art/story-propose.webp` · `app/art/taekil-main.webp`(출산택일 머리 그림). 새 그림은 이 그림들 옆에 놓여도 어색하지 않아야 합니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `INDEX.md` | 요청 목록 — 상태를 보는 곳(중복 막기) |
| `TEMPLATE.md` | 명세 틀 — 새 요청은 이것을 복사해 씁니다 |
| `IMG-0001-이름.md` … | 요청 명세 한 장씩 |
| `out/` | 생성 담당이 원본 PNG를 올리는 곳 |
