# 사건 삽화 24장 추가

상태: 생성·연결 완료, Claude 통합·배포 대기

사장님 요청: 사건 종류가 많으니 적극적으로 추가.

- 새 12장면 × 남녀 각 1장 = 24장. 기존 38장 보존, 사건 삽화 총 31장면 62장.
- 새 장면: 돌아감·대접·돈 받기·판매·도움 요청·감사·서류 제출·서류 누락·오해 설명·내 몫 지키기·재작업·직접 만들기.
- 기존 80개 문장 중 20개 그림 연결을 세분화. 고객 문장·계산·분류 규칙·CSS·성별 선택 방식은 변경하지 않음.
- 기존 인물·화풍 유지. 휴대폰·카드·계산기·전자기기 제외. 편지·책·도자기·천 주머니·고전 소품 사용.
- 내장 image_gen으로 생성. 원본 PNG 로컬 보존, 원본 크기 및 480px WebP 저장.
- 프롬프트와 참조는 IMG-0078~0101 각각 기록. 기존 매핑과 크기 표에 추가하여 바로 연결.
- 생성 이미지와 소스 변경 내용을 직접 검토. 테스트·브라우저 실행 검증은 수행하지 않음.
- Claude 통합 시 이미지 경로·캐시 갱신 및 배포 확인 필요.
