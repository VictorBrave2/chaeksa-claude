# 사건 삽화 32장 추가

상태: 생성·연결 완료, Claude 통합·배포 대기

사장님 요청: 「더더더 뽑아내」 — 기존 사건에서 장면을 더 잘게 구분하고 삽화를 적극적으로 추가.

- 새 16장면 × 남녀 각 1장 = 32장. 기존 31장면 62장 유지, 총 47장면 94장.
- 새 장면: 모임이 흩어짐 · 사람과 거리 두기 · 맡을 일이 늘어남 · 맡은 일이 바뀜 · 배우는 데 돈을 씀 · 하고 싶던 일에 지출 · 도움에 대가를 건넴 · 들어올 돈이 끊김 · 비용부터 정함 · 내 이야기를 많이 함 · 내 편이 되어 줌 · 맡은 일을 나눔 · 허락받지 못함 · 조언으로 방법을 바꿈 · 정해진 시간에 마무리 · 충고를 듣고 말을 멈춤.
- 기존 80개 문장 중 17개 그림 연결만 세분화. 새 사건·새 문장·새 분류를 만들지 않음.
- 기존 31장면도 각각 최소 한 문장에 연결되도록 유지.
- 고객 문장·계산·분류 규칙·CSS·성별 선택 방식 변경 없음.
- 얼굴과 의상 정체성을 유지하고 몸 방향·팔 동작·소품의 큰 윤곽을 장면마다 달리함. 한 인물만 등장.
- 휴대폰·계산기·카드·전자기기·현대 장비·집게손 제외. 보호와 충돌은 무기나 폭력 없이 표현.
- 내장 image_gen으로 생성. PNG 원본 로컬 보존, 원본 크기와 480px WebP 저장. 원본 화소 확대 없음.
- 최종 프롬프트·참조·출력 경로는 IMG-0102~0133 개별 문서에 기록.
- 견본 갤러리에서 새 16장면을 맨 앞에 배치. 기존 CSS와 조작 방식 유지.
- 테스트 및 브라우저 실행 검증은 수행하지 않음. Claude 통합 시 이미지 경로·캐시 갱신·배포 확인 필요.

## 문장 연결

- 결과|국충|비겁 → disband — 함께하던 모임이 흩어집니다.
- 생각|극함|비겁 → distance — 함께하던 사람과 거리를 두기로 합니다.
- 결과|생받음|재성 → workload — 돈을 받는 대신 맡을 일이 늘어납니다.
- 결과|국충|관성 → reassignment — 맡고 있던 일이 한꺼번에 바뀝니다.
- 끌림|재성|인성 → tuition — 배우고 싶던 것을 배우는 데 돈을 냅니다.
- 끌림|재성|식상 → self-reward — 하고 싶었던 일에 돈을 씁니다.
- 끌림|인성|재성 → repay — 도움받은 대가로 돈을 건넵니다.
- 결과|국충|재성 → income-stop — 들어오기로 한 돈이 끊깁니다.
- 끌림|관성|재성 → budget — 맡은 일을 진행하려고 비용부터 정합니다.
- 결과|생함|식상 → storytelling — 평소보다 내 이야기를 많이 합니다.
- 결과|생받음|비겁 → ally — 함께하던 사람이 내 편을 들어 줍니다.
- 생각|생받음|비겁 → ally — 함께하는 사람이 내 편이라는 생각이 듭니다.
- 끌림|관성|비겁 → delegation — 혼자 맡았던 일을 나눠 하기로 합니다.
- 결과|극받음|관성 → permission-denied — 하려던 일을 허락받지 못합니다.
- 끌림|식상|인성 → change-method — 조언을 듣고 하던 방법을 바꿉니다.
- 끌림|식상|관성 → deadline — 하려던 일을 상대가 정한 시간에 맞춰 끝냅니다.
- 결과|극받음|인성 → hold-tongue — 하지 말라는 충고를 듣고 말을 멈춥니다.
