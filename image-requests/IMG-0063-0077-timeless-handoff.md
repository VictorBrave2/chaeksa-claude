# 오늘의 운세 — 시대가 드러나는 소품 교체

상태: 이미지 생성·연결 완료, Claude 통합·배포 대기

- 7장 교체: 연락 2장(휴대폰→편지), 지출 2장(카드·지갑→천 주머니), 금액 확인 2장(계산기·영수증→동전·주머니), 홈 표지 1장(휴대폰→편지·책·모래시계).
- 8장 추가: 취소·거절·마무리·나눔, 남녀 각 1장.
- 사건 삽화는 19장면 38장. 기존 문장 80개의 열쇠와 문구는 그대로, 9개의 그림 연결만 새 장면으로 세분화.
- app/today.js 그림 대응표·경로 버전과 app/home-cats.js 표지 경로만 변경. 엔진·계산·시간 표시·CSS는 변경하지 않음.
- 원본 PNG는 삽화원본/에 로컬 보관. 배포 WebP는 원본 크기와 작은 판 제공.
- 기존 7장(14 WebP 파일)은 사용 목록과 갤러리에서 제거. 옛 원본 PNG 및 Git 이력 보존.
- 모든 생성 결과를 눈으로 검토. 요청하지 않은 테스트·브라우저 검증은 실행하지 않음.
- Claude 통합 시 정적 자산 캐시 갱신 및 배포 필요.
